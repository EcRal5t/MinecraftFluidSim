## Registry 与功能配置

颗粒功能依赖材料功能，沉淀还依赖化学功能。
世界能力包保存材料、载体和反应的稳定身份、整数批次及依赖指纹，区域载荷采用相同功能布局。
定义或身份不匹配时保留原存档并锁定。

`ParticulateMaterial` 定义密度、代表粒径、孔隙率、安息角、摩擦、恢复、临界 Shields 数及侵蚀率。
数据定义的 `reference_density_kg_per_m3` 使用 kg/m³，注册表快照以 `ReferenceDensityKgPerM3Bits` 保存原始位。
`GranularCarrier` 保存液相材料对应的阻力标定范围；动态黏度由材料注册表提供。
载体、组成、沉积组和单步工作量具有容量限制，具体常量由对应库存与配置代码维护。
容量不足时保留待处理库存，材料和组成身份随物质交接。

## 独立保存的数据

- 活动颗粒保存位置、速度、材料、整数 SVQ、kg 质量、组成、内能、确定性身份及支撑接触状态。
- 沉积组按单元保存材料、SVQ、kg 质量、组成和内能，床层形状与混合孔隙率由库存派生。
- 连续凝固相由相变层的 coherent store 保存，具有独立库存与容量。
- 外部源汇、边界冲量及反应审计分别记账。

同代数组索引连接载体、组成与内能，拆并和移除共同更新。
质量和内能总账按实际存储值汇总，存储顺序变化应保持账本一致。
活动颗粒体积改变后重新判定接触和沉积资格。

合并按实际质量汇总位置和动量，联合准备占容、势能及热状态。
未解析的相对运动可随代表合并耗散，动能损失与实际势能变化交接到内能；宏观旋转按区域运动和可观察衰减评价。
转换中采用的空间与速度近似按宏观动量、势能及耗散评价，精度要求见[整合计划](../roadmap/solver-consolidation-plan.md#精度与物理取舍)。

## 数量、布局与容量

固体库存采用整数 SVQ，`1 m³ = 2^27 SVQ`，默认 `0.5 m` 单元为 `2^24 SVQ`。
颗粒与沉积质量使用[统一质量整数](system-overview.md#units)，拆分以 SVQ 比例分配整数并保留余数；随后的内能分配使用实际整数质量份额，覆盖抽取、沉积唤醒和床层移动。
活动颗粒采用结构分离数组；沉积采用按单元组织的有限规范组。

材料孔隙率 `phi_i` 描述静止松散床中的空隙比例。
混合床采用各材料松散体积可加的近似：

```text
Vbulk = sum_i(Vs_i / (1 - phi_i))
Vpore = Vbulk - sum_i(Vs_i)
phi_effective = 1 - sum_i(Vs_i) / Vbulk
```

床体积计算后统一向上取整到 SVQ，用于床高、静态装填和孔隙阻力。
液体容量由几何开放体积减固体骨架体积得到，孔隙水继续由普通液体载体保存。
床体形成和孔隙率变化通过联合占容计划交接液体。

## 生产模型

活动代表颗粒承担重力、阻力、压力和碰撞，平静库存转为单元床层。
液体几何、质量与动量输运、压力和黏性使用共同主干，颗粒和床层通过惯性、占容与阻力项耦合。
床层以安息角松弛、有限侵蚀和局部休眠控制成本。

### Active parcel 力学

每个机械子步先预测重力，从源滑移准备有限质量阻力，再通过同一惯性和阻力响应求解液体与颗粒的共同压力和最终速度。
接触与位置预测读取本步共同投影后的速度，实际整数占容由共同有界输运结算。
浸没比例和液体物性按连续位置采样，阻力采用球形颗粒关系：

```text
Re = rho_f * d * |u_f - u_p| / mu
Cd = max(24/Re * (1 + 0.15*Re^0.687), 0.44)
```

零滑移采用有限 Stokes 系数，高 Reynolds 数沿牛顿阻力近似推进。
每个机械子步以初始滑移计算阻力系数，随后按该正系数隐式求解有限质量的液固速度。
液固反作用等大反向，阻力消耗相对动能；系数的时间滞后是一阶近似，误差由代表沉降速度、阻力响应和正常时间步收敛评价。
该关系的精度受球形代表粒径和阻力相关式适用条件限制。

代表球与固定微盒、实际床体及其他代表球共用预测接触集合。
球间候选由平衡扫掠包围盒树按可能碰撞时刻和空间距离查询。每个代表按主法向保留局部接触流形，密集多体接触以有限邻域传递压缩应力；固定平面接触按所属颗粒索引，随局部接触集合共同更新。
固定几何保留连续碰撞检测，将实际轨迹经过的接触平面交给质量加权位置投影；球间接触按共同终点约束求解。
位置采用固定成本的局部质量加权 PBD 投影，每轮从当前候选位置更新球间接触流形，固定几何接触持续保留。
实际轨迹执行一次 CCD，接触位置修正直接投影到共同外壳、固定微盒和床体；固定接触锥采用有限次法向投影。
每颗代表沿完整步长执行有限次接触事件，盒体查询按最近外壳碰撞时刻截短扫掠范围。
余下未解析位移停留在已解析的合法接触位置，保留已计算速度供下一步推进；颗粒速度通过真实轨迹与最终整数占容共同处理。
球间采用软代表接触，有限邻域保留主要排斥方向；密集碎粒的未解析交叠与回弹由后续正常步骤继续松弛，整数真实占容负责最终容量。
固定外壳、床体接触与静止支撑识别沿用同一代表位置尺度；查询范围、接触距离和接触平面合并共同处理该尺度内的间隙。
整数容量使部分代表保留原位时，支撑关系按最终保留位置重新沿局部粒间接触传播，静止接触时间随该实际支撑更新。
受支撑的静止代表持续积累接触时间，沉积几何闭合可将相互阻挡的一组代表共同转入床体。
每行按实际质量施加等大反向冲量，固定接触承担外壳或床体反冲。
球间速度冲量沿最终代表连心线施加。自由接触组件按实际质量和普通浮点惯性张量保留整体平移与可解析旋转，位置投影引起的轨道角动量偏移通过同一组件的速度分解交接；剩余形变运动在实际入射动能预算内保留。
退化的密集位置表示按其实际惯性和动能容纳旋转，未解析自旋可以耗散；外壳与床体接触沿真实反冲承担角动量交换。
速度响应先准备压缩候选，再在同一固定次数的累计冲量扫描中处理法向恢复与固定表面的 Coulomb 摩擦。
反弹总能量受压缩释放动能约束，球间法向冲量成对守恒，固定表面承担完整反作用。
接触流形行数随实际代表数线性增长，几何查询在既有操作预算内分配局部解析量；固定几何连续碰撞保留其完整轨迹处理。
材料恢复以压缩阶段释放的动能限定回弹，切向运动按 Coulomb 摩擦处理。
本步实际参与求解的球间接触累计到同一个机械体连通关系。摩擦、非弹性碰撞及未解析多体压缩的实际动能损失，与该机械体的压力、阻力交换一起结算到内能。
表示转换中的质量混合、反应入床已通过对应转移计划交接动能损失、实际势能差与内能。
每个已解析接触分量的数值计算量与接触行数及固定扫描次数成正比，细尺度残余运动由后续正常步骤推进。
位置发布与冷恢复核对固定外壳、床体、坐标表示和整数真实容量，直接交接已提交的软接触状态。
代表球相互排斥负责粗尺度运动与堆积，空间解析目标和存档库存完整性分别评价。

接触模块分工：

- `GranularActiveContacts`：预测接触、局部位置约束与轨迹发布。
- `GranularContactCompression`：固定成本的成对法向冲量。
- `GranularComponentResponse`：接触组件的压缩、恢复、摩擦和回弹能量预算。
- `GranularSpawnAdmission`：新代表的空间放置与共同接触解析尺度。
- `GranularCollisionGeometry`：固定微盒与当前候选床体的共同位置准入。
- `GranularReactionStage.precipitate` / `depositPrecipitate`：析出代表合并、共同生成及未解析析出物入床的物质、动量与能量交接。

接触组件的具体迭代、索引、缓存与收敛阈值由这些实现维护。
正常密集场景的连续推进与完整步成本由[验证指南](../maintenance/validation.md)检查。

### 载体属性工作区

`LiquidCarrierProperties` 为液体黏性、颗粒阻力、床面剪切与 Darcy 阻力提供共同物性。自由面上的 Darcy 液体速度采用实际湿侧物性；两侧均无液体时跳过。空液格的有限占位值供工作区和无液体样本使用，气腔压力与热学读取自身混合物状态。
密度来自实际质量与体积；温度来自真实载体内能；黏度来自已绑定材料的 `mu(T)`。
热学启用时，湿格必须提供有效温度；无热布局使用标准温度。
独立基础液体域的湿格由实际库存质量和体积判定，沿用实际密度与标准温度；未绑定材料时采用零黏度、零热膨胀。绑定材料后的温度与热浮力按该材料的热膨胀定义派生，黏度数据的可选性保持独立。

工作区按阶段批量构建，库存、组成、内能或位置改变后重建。
温度观察保持载体内能，候选和恢复从各自状态派生工作区。
单格黏度采用主导材料近似；材料温区外取声明端点值，并发布越域诊断。

### 统一排水与压力

每子步从活动颗粒、沉积和连续固相建立共同固体占容。
活动颗粒以归一化三线性核分摊至最多八格，沉积和连续固相按所属单元计入。
共同压力使用同代颗粒位置和有限质量，固相预测体积散度与液体散度参加同一个方程。
两相速度同时投影后，接触处理器准备本步位置和整数 SVQ 终点，实际孔容偏差由共同有界容量投影处理。

`GranularFaceVolumes` 提供同一有界流体面孔隙率 `Af`，`PressureFaceGraph` 用它构造体积散度与压力梯度的转置。
固定床与连续固相的面孔隙率采用相邻双单元的实际孔容平均：`epsilon_face = 1 − (Vfixed_left + Vfixed_right)/(Vopen_left + Vopen_right)`。
这与 MAC 双单元实际液体质量的平均保持一致，使饱和孔隙水的压力梯度与重力平衡；占满的单元及固定碰撞封面继续阻断流动。
颗粒通过互补面份额形成固相体积散度 `B`，两相压力作用分别使用对应散度的转置：

```text
q = (u, v), H = [C, B], M = diag(M_face, M_solid)
R = (M + dt * D)^-1
q_next = R * (M q_star + dt * f_known + dt * h^3 * H^T p)
H q_next = gas_volume_response
A_pressure = rho_reference * h^3 * H R H^T + A_gas_storage
```

`M_face` 使用实际液体质量。
低填充单元的压力有效面积受相邻控制体实际液量约束，两侧载荷同比缩放，几何接触支撑保持原面积。已知气压、静水载荷与压力增量均经过同一有限质量和阻力响应。预测列采用 binary64，最终合并实际压力后一次计算并发布速度。
`D` 是本子步按源滑移准备的正半定成对阻力矩阵。`GranularImplicitDrag` 每轴分解一次粒子消元后的正定格面矩阵，预测、压力矩阵乘与最终速度共用其三角回代；`D=0` 时自然退化为原质量惯性响应。
共同压力通过同一 `PressureLinearSolver` 和 `PressurePreconditioner` 求解液体、固体惯性与气腔储容。
固体项采用原始数组的局部汇总与散布，沿每粒各轴至多八个格面准备一次，矩阵迭代复用这些系数与阻力因子。显式无阻力稀疏压力矩阵提供 IC(0) 预条件，含阻力的实际算子通过同一响应直接应用。

液体面压力承担 `Af` 的份额，活动颗粒承担固定孔隙面积与 `Af` 之间的互补份额。
同一面上的颗粒按代表体积权重分配该冲量，液体与颗粒合计恢复完整开放面压力载荷。
这种体积平均离散保持内部成对冲量，并在代表尺度上提供静水浮力。
固定固体和围墙承担其对应的外部反力。
液固力积分的实际动能变化、接受位置势能变化与气腔绝热功沿共同机械体一次结算，按材料热容与可用显热交给实际液体和颗粒库存。阻力算子集中负责有限质量速度响应，具体规则见[共同机械能交接](fluid-solver.md#单元库存与-mac-动量)。

`ConservativeLiquidFlux` 将同一 `Af*u*dt/h` 粗面通量按固定开放微孔分配，PLIC 积分提供液体相通量偏好。
微盒描述界面形状与气体来源，物理数值容量由粗格的固定开放连通分量统一结算。
一次完整输运以真实供体库存、颗粒终点孔容和有限气体正容量约束推进，实际质量通量同时驱动动量输运。
微盒形状从最终粗分量库存统一重建。

实际位置的整数 SVQ 分配保持总量精确和逐格真实容量，并随位置保存和恢复。
液体、气腔和颗粒的联合提交使用同一固体终点。
容量与连续推进要求见[精度与物理取舍](../roadmap/solver-consolidation-plan.md#精度与物理取舍)。

### Deposit 松弛与局部唤醒

持续低速受支撑的颗粒可以转入沉积。
计划先确认到接收床面的可达路径，再按完整候选的未来床高选择接收层，联合核对活动球相容性和液固容量。
沉积后由重力驱动的安息角松弛形成稳定坡面，投放过程允许瞬态陡坡；局部地貌和显式静止球共同表示最终沙堆。
接收床是从所在单元底面起、覆盖该单元横截面的长方体。

沉积与松弛共同交接整数体积、质量、组成和内能。
液体排开与气腔后继采用相同未来占容；转换前后的宏观重心与势能同时检查。
转换开始时准备源液体物性、占容与 MAC 视图；床层候选变化期间的剪切采样和起动功读取这份液体视图。起动支付的动量变化立即更新对应 MAC 面，全部固体转换完成后统一排开液体并发布气腔后继。
床层松弛采用局部水平移动加竖直下落路径，障碍物决定接收位置是否可达。

`GranularLiquidDisplacement.prepare` 准备液体排开，`GranularInventory.WakePlan` 准备床库存取出与活动颗粒追加。
来源、目标位置、组成、能量及账本全部预检后提交。
起动势能变化由 `GranularBedPotential` 按实际整数质量、床层形状与目标高度计算。
`GranularBedShear` 读取床格及上方格开放水平 MAC 面的实际 SI 质量和持久动量，以统一缩放支付该势能变化。
全部来源在首次颗粒写入前预检，再提交零初速颗粒与预备格面动量；实际动量差作为床面反冲。
实际动能变化与势能变化之差进入 `GranularDepositDynamics.Stats.mechanicalRounding`，热库存保持原有交接规则。
颗粒随后由共同压力与阻力加速。

脏列及相邻列执行有限的安息角松弛，安静后休眠。
静止代表的床层转换同时考虑本列与实际路径可达的下坡邻列；跨列转换遵守同一材料安息角、实际床高和非增重力势能，完整批次统一交接整数物质、反冲与内能。
混合表示的宏观坡度按共同体积分配观察；显式代表球附近的表面高度误差以球半径量化，纯床体区域沿用静态安息角要求。
真实流动步仍检查暴露床面的剪切，几何变化、沉积和反应唤醒局部邻域。
操作预算耗尽后保留库存和待处理列；冷恢复从已提交床层重建调度状态。

该床层采用单元地貌近似，代表颗粒转为床层时的细尺度运动会耗散。
转换耗散、联合提交和代表性床面流程的整合要求见[计划 M07](../roadmap/solver-consolidation-plan.md)。

### 水流起动与床面输运

`GranularBedShear` 从床面上方液流、材料黏度和床面距离估计剪切，应力通过 Shields 判据判断起动：

```text
theta = tau / ((rho_s-rho_f)*g*d)
```

壁面关系采用 Spalding 模型，侵蚀量受超临界程度、注册表速率、可用 SVQ 和几何容量约束。
几何与能量条件通过后释放零初速颗粒，液流通过共同阻力和压力传递动量。
静止或亚临界水流保持床库存，薄床上方的自由流动按层状近似保留。

### 薄沙床与孔隙阻力

`BodyForceStage` 使用 Kozeny–Carman 渗透率：

```text
Kp = d²*phi³ / (180*(1-phi)²)
H = (1-f)*h
Kt = f*Kp + (1-f)*H²/3
u_next = u / (1 + dt*mu/rho*resistance)
```

`f` 为床层占格比例，切向按床层与自由层平行流动近似，法向叠加实际床厚的阻力。
每面统一执行隐式 Darcy 更新，再进入压力投影。
该模型覆盖薄床自由流与满床孔隙流，精度由单元内层状流动假设限制。

## 固液相转移

析出与溶解按注册表完整反应批次规划，联合验证液体物种、固体组成、真实质量、内能及未来占容。
活动固体使用连续位置的核份额，沉积和连续固相使用各自空间归属。
目标载体或组成容量不足时保留原库存和待处理单元。

转移物质携带原速度：液体、活动固体取实际速度，沉积取静止速度。
液体物种按实际质量份额分配，固液转移的整数质量按同一实际质量权重交接；组成质量余量重新计算并保持整组精确闭合。
物种量子数与数值样本数分别结算，空物种样本保留正的实际质量及对应内能。
接收载体按实际质量合并输入动量，最终速度的存储误差独立评价。
新析出物优先按实际质量合并到同组成的活动代表，独立代表共用干颗粒创建的生成与准入规则。
独立球缺少空间时，未解析析出物可加入同格的合法床库存，按组成合并，并核对未来床高、固定几何、活动代表和真实容量。
转入床层的动量由床体承担反冲，来流动能及实际床体势能差交接到内能。
混合床的每种反应组成均参与后续溶解，反应读取同一候选中的活动颗粒和床体几何。
这种单元尺度空间近似允许细尺度重心和旋转发生变化，整数物种、质量及内能随同一候选交接。

反应计划在首次写入前准备物种、固体、能量、审计及相变后的机械推进标记。
部分 extent 保持完整，预算耗尽后由后续步骤继续扫描。
连续凝固与熔化由 coherent store 处理。冻结先准备未来固相和液体数量，再复用 `ConservativeLiquidFlux` 的连通容量分配将膨胀排开的液体移往可达格；动量、携带内能、位移势能和气体后继共同准备后发布。可达孔容限制整数批次，无处排液时保留原库存。热力学规则见[热学参考](thermal-state.md#相变)。

## 容器与清空

干颗粒容器保存完整 SVQ、逐材料质量及可选固相组成。
玩家和发射器作用于区域实际目标格，并通过容器 WAL 联合提交区域与物品。
部分提取先规划剩余颗粒的合法占容与热状态，再准备气腔容量和功的后继。

凝聚相清空联合提交液体、活动颗粒、沉积和连续固相的移出账，气体由独立排气操作处理。

## 审计与可观察量

体积、逐材料质量和可选物种分别满足：

```text
initial + external_source - escaped_sink
= active + deposit + coherent + transferred_inventory
```

机械质量、组成质量余量和内能使用各自实际存储列汇总；冲量与热能在对应账本中闭合。
`status` 的颗粒数、沉积组数、床高、孔隙率和休眠列数均为只读摘要。
恢复使用完整库存和接触状态，再重建几何与派生属性。

固液饱和参数 `saturation_concentration_mol_per_m3` 以反应进度的 mol/m³ 表示；内部每个 extent 对应 1 μmol，计量系数作用于各真实物种。
精确批次的 extent、物种 μmol 和 SVQ 由注册表共同定义。
