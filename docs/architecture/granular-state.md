## Registry 与功能配置

颗粒功能默认关闭并依赖材料功能；沉淀还依赖化学功能。world granular registry snapshot 保存 stable material/carrier/reaction ID、exact extent/SVQ batch、化学依赖和 fingerprint。未知、损坏或 identity mismatch 保留并 LOCKED。

区域载荷中的 granular 与 chemistry presence 必须与启动时确定的功能配置一致；不从其他布局构造空颗粒层。

`ParticulateMaterial` 至少固定以下计算定义：颗粒密度、代表粒径、孔隙率、安息角、静/动摩擦系数、恢复系数、临界 Shields 数、侵蚀率、单 parcel 容量、显示信息和 reactive 标志。`GranularCarrier` 把液相材料绑定到颗粒阻力标定用的 Reynolds 上限；动态黏度不在这里，它由 world material registry 的 `mu(T)` 提供。注册表验证所有范围和引用后冻结；运行时只使用冻结 ordinal，不按数据包名称重复解析。

当前硬上限为：256 个 particulate material、512 个 carrier、512 个 reaction；单 region 16384 个 active parcel、单 server 65536 个；单 cell 8 个 deposit group、单 region 65536 个、单 server 262144 个；solid composition 最多 16 项；每 logical step 131072 次颗粒操作。

单 active parcel 最大为 `cell SVQ / 64`。预算不足时延期、拒绝或暂停，不能合并不同 truth 来腾位置。

## 独立保存的数据

- solid volume 使用整数 SVQ；每种材料质量以 kg 独立保存。
- active/deposit 的 binary64 kg 总账在 snapshot、handoff 与清空计划边界按精确二进制和归约、最后只舍入一次；稀疏槽位分配顺序、cell 规范排序和 parcel swap-remove 不能改变总账 raw bits。
- reactive solid composition/species 与机械材料身份分开保存。
- active parcel、deposit group 和 coherent condensed phase 是不同载体，不互相替代；active parcel 的连续支撑接触年龄与支撑标志是沉积状态机的权威侧列。
- 活动颗粒的 SVQ 改变后，清除接触年龄与支撑标志，由后续机械计算按新体积重新判定代表球的接触几何；拆分、合并、部分取出和溶解共用此规则。同 SVQ 的机械写回保留本次计算出的接触状态。
- 活动颗粒合并及析出加入已有颗粒时，位置与速度均按实际 kg 加权；位置的质量一阶矩误差限于最终 binary32 坐标舍入。两份输入的相对位移与相对速度叉积为零时，单一代表点可保留角动量；该条件按原始 binary32 值精确判定，共址与同速输入直接满足。存在相对旋转的活动颗粒保留两份载体，析出沿用新增颗粒流程。直接合并、活动库存压缩和析出合并共用此条件。生产合并候选先按合并后的实际质量、组成与拟存储内能校验正温，再预留几何与占容；有限精度无法表示有效热状态时保留两份来源。整批配对在首次写入前完成库存与热状态复核。
- deposit 保存 cell、材料、SVQ、质量、组成、porosity 和孔隙水相关状态。
- external source、escaped sink、boundary impulse 与反应审计独立闭合。

显示高度、颜色、active sample、bulk fraction 和 porosity tooltip 都是只读派生，不能结算库存。

## 数量、布局与容量

- `1 BV` 是一个 Minecraft 方块体积；生产子格边长为 `0.5 m`，所以每格为 `0.125 BV`。
- solid volume 以 `SVQ` 整数记账；SVQ 与 BV 的换算常量在存储、网络和容器中一致，禁止先转 `double` 再结算。
- active parcel 使用结构分离数组保存位置、速度、材料 ordinal、SVQ、逐材料 kg 质量、组成 handle、连续支撑接触年龄、支撑标志、内能和确定性身份。数组 ordinal 是同代 side column 的共同键。
- deposit 以 cell 为定位键，cell 内是有硬上限的规范化 group 列表；相同机械身份和组成的 group 合并，孔隙率按 cell 混合派生。
- coherent condensed group 属于相变层，具有自己的 cell、SVQ、质量、组成和内能；它不占 active parcel 或 deposit 的容量。

材料静止孔隙率 `phi_i` 描述松散床体中孔隙所占比例。混合床采用各材料静止松散体积可加的近似，由各组骨架体积 `Vs_i` 派生床体体积：

```text
Vbulk_exact = sum_i(Vs_i / (1 - phi_i))
Vbulk_SVQ = ceil(Vbulk_exact)
Vpore_exact = Vbulk_exact - sum_i(Vs_i)
phi_effective = 1 - sum_i(Vs_i) / Vbulk_exact
```

`GranularDepositStore` 用精确有理数相加，最后统一向上取整到 SVQ。有效孔隙率由未取整床体体积派生，再四舍五入到百万分之一。库存变更和快照恢复时重建每格床体体积与孔隙率缓存，添加预检使用相同公式。床体体积用于床高、静态床装填容量和 Darcy 阻力派生；固体骨架体积参与统一液体/固体占容与压力耦合。孔隙水由普通液体 marker 保存，允许占据床体内部空隙；每格液体容量为几何开放体积减去固体骨架体积。

## 生产模型

生产模型是低成本 active parcel + deposit cell：

- active parcel 接受重力、浮力、阻力、压力和 cut-cell 碰撞；
- solid occupancy 与 liquid marker occupancy 共享统一容量、排水和压力耦合；
- 沉积使用材料安息角、邻域支撑与确定性转移；
- deposit porosity 决定孔隙水空间，但不会隐式创建或删除液体；
- 平静库存可休眠，局部碰撞、液流、边界变化或反应只唤醒受影响邻域。

不预建 MPM 或通用刚体/弹性框架。只有量化证明当前模型越过既定成本或质量适用条件，才单独评审替代模型。

### Active parcel 力学

parcel 的物理质量列使用 kg，SVQ 通过 `SVQ_PER_BV` 给出 m³。每个机械子步先积分重力，再联合求解液体、颗粒阻力与压力。浸没比例、液体密度和黏度按颗粒连续位置的八格支撑采样；中心穿过单元面时，接触随位置连续改变。每份载体的标定滑移范围取交集，并转换为混合物的 Reynolds 标度，保留作诊断。

### 载体属性工作区

`LiquidCarrierProperties` 同时服务于连续液体黏性应力、活动颗粒阻力、Darcy 与床面剪切。液体物性绑定由 `bindMaterialDefinitions` 独立提供，空颗粒能力与纯材料域读取相同物性。

液体密度、温度和黏度只在一处派生：`LiquidCarrierProperties` 按格保存「是否有液体、液体材料 handle、实际密度、温度、`mu(T)`、Reynolds 上限」。三个使用方都读同一份派生值——活动颗粒阻力、Darcy 孔隙阻力、床面剪切（Spalding 壁面关系）。因此一格在每个 revision 内只反演一次温度，不再按 parcel 支撑点或阻力面重复求值。

- 每个力学子步在气体更新后预建一次属性。载体结构、化学组成与热学 revision 改变、marker 网格重建都会使缓存失效；平流只改变位置时也必须重建。化学编辑或反应在总内能保持不变时仍会改变状态函数与派生温度。床面检查在热化学轴之后读取当前属性。
- 温度取该格凝聚相载体的 LTE 温度，由液体、活动颗粒、沉积与连续固相的质量、组成和内能共同反演，走热学既有的批量入口（一次建格、多格读取），只更新派生工作区，不重新分配也不修改载体 `U`。
- 热区域的液体组成密度按与热浮力相同的连通单相三线性支撑，从真实质量/体积推导；无热状态时沿用所属单元密度。活动颗粒的支撑继续采样该工作区，并使用与压力相同的面惯性。空间采样范围见[材料状态](material-state.md#求解器边界)。
- 没有热学能力的布局使用 `MaterialRegistry.STANDARD_TEMPERATURE_K` 的等温计算约定。**热学已启用而湿格取不到温度是状态失败，直接停止候选，不静默改用常温。**
- 干格不计算液体黏度、不产生越域记录，沿用既有的空气常数行为。
- 工作区是固定容量 scratch，不进 `FluidDomainState`、不进存档；恢复或候选域从自己的状态重建。
- 格内材料选择沿用「该格体积最大的 marker，同体积取更小 handle」的既有规则，它是单元内单一主导材料的近似，不解析同格多材料混合黏度。
- 材料身份由液体 marker 确定，颗粒库存为空时也更新；是否有活动颗粒或沉积仅决定是否执行对应耦合。

温度超出材料声明黏度域时，黏度取最近端点的声明值（见 [材料状态](material-state.md#黏度求值)），并按「格 × 属性构建批次」计数。计数通过成功步的 `StepStats.carrierViscosity` 发布，`/mmm status` 只在该步确有越域时显示格数与一个确定性样例（材料 ID、实际温度、声明温区）。重复读取同一批次不重复计数；失败或细化重算的候选不污染已发布统计。

球形颗粒的相对 Reynolds 数与阻力相关式为：

```text
Re = rho_f * d * |u_f - u_p| / mu
Cd = max(24/Re * (1 + 0.15 Re^0.687), 0.44)
```

低 Reynolds 分支与高 Reynolds 极限在交点连续连接。零滑移使用有限的 Stokes 阻力系数；代表颗粒数按实际浸没比例缩放。超过 Reynolds 标定上限时，继续使用已有 `Cd=0.44` 的牛顿阻力分支；这是高 Reynolds 近似，不刻画阻力危机。检查保留对非有限 Reynolds 的拒绝，不因有限高滑移暂停。隐式迭代使用步末滑移求解，反作用保持等大反向，阻力保持耗散。

`GranularImplicitDrag` 对所有 parcel 共用的载体同时求解。速度采样使用归一化的三线性权重乘 P2G 面质量，反作用使用同一采样矩阵的转置；零 P2G 质量面不参与阻力交换。液体面的惯性与压力算子一致，为 `rho_reference * cellVolume * openArea / mobilityScale`，颗粒惯性为其物理质量。尚未形成压力单元的薄液滴使用实际 P2G 面质量参与阻力交换。这样阻力交换与后续压力响应使用同一个质量矩阵。

耦合面建立后，`GranularImplicitDrag` 预计算 27 邻域的面索引，PCG 矩阵乘法读取系数和邻接索引。邻接索引属于候选域的派生工作区，每次重新建立耦合面后更新，不写入区域状态。

### 统一排水与压力

每个子步从 active、deposit 的骨架 SVQ 和 coherent store 构造统一 solid occupancy。可用体积为几何开放体积减去 solid occupancy。压力分类、孔隙面面积和颗粒占据率的空间导数均在子步初态上建立，在线性求解期间保持不变。

`GranularPressureCoupling` 使用归一化三线性固体占据率的位置导数 `G`。设 `D u` 为液体孔隙面通量散度、`v` 为颗粒速度，连续性为 `D u = G v`。令联合速度 `q = (u, v)`、连续性矩阵 `C = (D, -G)`，`B q` 为各颗粒相对载体的滑移。每次非线性迭代固定正阻力系数 `K` 后，联立系统为：

```text
L = M + dt * B^T K B
q_next = L^-1 (M q_star + dt * cellVolume * C^T p)
A_pressure = rho_reference * cellVolume * C L^-1 C^T + A_gas_storage
```

`M` 包含液体面与活动颗粒的有限惯性。每个颗粒速度先精确消元，再用预条件共轭梯度求解液体面上的正定 Schur 系统。每轮非线性迭代将重复接触汇总到同轴面的 27 邻域稀疏系数，内层矩阵乘法不再逐个扫描 parcel。压力矩阵使用相同的阻力响应，压力修正与阻力反作用一起保留在最终速度中。给定的气压与界面压差参与同一个速度响应；同一密闭节点的多格支撑先合并导数。

总压力动量守恒还要求空间离散满足同步平移条件：在无固定固体的内部，液体与活动颗粒沿同轴以相同速度运动时，`C t_axis = 0`。当前孔隙面面积由相邻单元可用体积分数的较小值派生，颗粒响应使用连续核导数，两者存在空间不一致。紧支撑的内部压力可以产生非零液固总冲量，且外壳压力为零；这一误差随 `dt` 成比例，减小时间步保留其力误差。压力矩阵的对称性与同一 `C/C^T` 保证离散压力功一致，总动量仍需统一体积核、面通量与力算子。该项完成条件见[产品路线的物理缺口](../roadmap/product-roadmap.md#物理缺口的依赖安排)。

统一空间表示还需同时满足正体积与质量一阶矩的可表示性。当前满容量初态可以通过逐格体积检查，同时液固实际质心与共同填满开放几何所要求的质心不一致；同密度时，这些库存无法在保持全部实际一阶矩的条件下形成互补的正空间体积分布。共同几何、库存准入和重建须联合处理该差额。外壳附近归一化核仅覆盖同一层单元时，其对应轴的体积导数为零，静水压力响应会遗漏浮力；该误差同样需要共同空间表示与压力虚功离散处理。

阻力系数按子步末滑移迭代更新，采用阻尼 Picard 迭代检查液体面和颗粒两侧的动量方程残差；按惯性与阻力对角量换算的速度残差须小于当前速度标度的 32 个 binary32 ULP。每次迭代从同一预测速度重建右端项；压力沿用本子步上一轮迭代的解作为初值，并重新计算实际残差。压力预条件器以液体与气腔的稀疏相邻连接进行不完全 Cholesky（IC(0)）分解及对称三角求解；颗粒对角量使用阻力消元后的惯性响应，随阻力系数一起更新。`GranularCoupledPressureSolver` 用 binary64 直接计算联立压力算子的作用并检查实际残差。液体与气腔使用同一压力参考，气腔初始压力直接进入储存项的右端项；有限气腔的压力响应通过联立矩阵计算，减少先施加大气压速度、再由压力修正抵消的精度损失。最终速度只舍入写入一次，避免大压力响应与阻力修正分次写入时的精度损失。阻力矩阵对称半正定、惯性矩阵正定；在无外力和无压力做功的封闭系统中，隐式时间离散耗散相对动能。内域完整核支撑上的静水压力梯度给出阿基米德浮力。

这是一阶时间离散：沿预测扫掠路径积分归一化核的空间导数，形成当前子步的体积变化算子，压力修正后预览颗粒碰撞与精确容量，最后和液体平流一起提交位置。归一化三线性核的导数总和为零，整数 SVQ 仍由实际新位置重新分配。碰撞使用流体的几何快照。代表球沿压力求解后的三维直线漂移，对局部占据微方块的面、棱与顶点计算最早接触；首碰时刻按浮点运算误差包络归并同时接触，后续位移投影到全部当前接触面的可行锥并继续扫掠。生成位置校验与运动预览共用球心到 AABB 的最近距离判定。

接触漂移与步末速度分别求解。法向响应先求共同接触锥上的压缩投影，再按材料恢复系数返回压缩冲量并重新投影，保证多面接触的动能非增。摩擦沿共同切空间作用，切向冲量受材料 Coulomb 摩擦系数与合成法向冲量约束；静摩擦可消除锥内切向速度。步末速度参与下一子步漂移。颗粒碰撞与容量暂停提交时，将动量差累计为几何与未解析占容约束接收的边界冲量，符号为提交前减提交后。容量暂停恢复原位置和零速度后，按原位置的真实固定几何或床体接触重新判定支撑；只有实际支撑才累计接触年龄并取得沉积资格。端点在最近的相邻 binary32 坐标中选择几何合法位置；静息接触按该位置表示误差恢复支撑。无法表达端点或接触计算超过操作上限时请求时间细分。沉积单元按实际 bulk SVQ 表示为从所在单元底面起、高度为 `bulkSVQ / SVQ_PER_CELL * h` 的长方体，和碰撞微方块共用三维球体扫掠、生成位置校验及冷恢复支撑查询。局部床体的顶面、侧面、棱与顶点均参与最早接触；分离床层之间的实际空腔保留通行空间。

扫掠积分的采样坐标恰落在核结点时，按预测运动方向选择单侧导数；负向扫掠采用左侧核支撑，包括采样位置因 binary64 舍入回到结点的情况。压力求解期间保持这条预测路径。初态处于三线性核结点且压力使运动方向翻转时，预测与实际运动可能使用不同的单侧导数；其容量差不能统一视为二阶时间余项。实际容量校验继续决定是否细化或暂停。接近满容量、且原始供给或化学份额限制保守重分配的场景，可能耗尽累计子步预算；核结点反向运动的非光滑联合收敛仍需完善。

整数占容按每个颗粒的最大余数分配重建，当前选择独立于液体库存。余数顺序翻转时，即使位置仅变化一个相邻 binary32 值，也可能向满液单元增加一个 SVQ。该格仅有一份可表示化学载体、且没有可反向抵扣的已分配通量时，液体无法部分搬出；局部表示误差额度充足也会拒绝候选。重复缩步不能保证消除这一离散跳变。预览、压力初态、恢复和增删规划使用同一整数分配，后续修复须保持这些入口的一致性。

活动颗粒的 float 位置与整数 SVQ 核分配会产生可计算的局部容量残差。`GranularQuantizationError` 用 exact dyadic 重建 0.5 m 网格上的归一化核；自由运动轴使用未舍入的 `p + v * dt`，碰撞或容量响应修改的轴使用实际端点。实际核体积增量与参考增量的精确带符号差，先与液体面通量量化的精确带符号误差相加。核误差非零时，将合计正差一次向上取整到整数 SVQ，额外包络严格小于一个 SVQ，作为本子步的逐格表示误差上限；核误差为零时保留液体面正差的精确额度。共享液体通量只在整份超容量落入剩余上限时，沿开放几何面保守重分配，并按实际转移量扣除来源格预算。反向抵扣可以回收原供给格已经分配的库存；前向到达液体保持本子步的原始供给限制。多材料、化学、能量与动量仍由同一单元重映射候选提交，既有速度扫掠与新增几何份额按体积混合。超过表示误差上限的连续几何残差继续细化时间步。

压力后的颗粒位移必须满足配置中的 Courant 限制。高压差造成初始速度预测不足时，后端从原始状态细化重算。压力、阻力、位置候选和相变几何同步属于同一完整计算候选，失败时保留上一代状态。细化重算与单次提交规则见 [CPU 后端候选接口](fluid-solver.md#后端候选接口)。

backend/checkpoint handoff 保存 active parcel 的接触年龄与支撑标志。恢复、相变、沉积与运动的容量检查共用 `GranularCouplingFields` 的连续位置整数 SVQ 归属：active parcel 分摊到最多八格，deposit 与 coherent 按所属单元计入。热状态恢复与 coherent 占用更新共同重建 active、deposit 和 coherent 的总占用；液体有限体积输运使用同一可用容量，逐格检查原始液体体积。

非线性外层每个子步最多求解 32 轮。未达到上述动量残差要求时，后端从原始完整请求重新计算，将子步时长至少减半；较小的 `dt K / M` 降低阻力与惯性的刚性比例。重算沿用力学时间细化的统一次数上限，保留相变预算、总推进时间和外部冲量的一次提交语义。

### Deposit 松弛与局部唤醒

- active parcel 连续受到支撑且速度低于阈值满 3 次接触后，才原子转入 deposit。转换保持整数 SVQ 与 species 量；质量、成分质量余数和内能按最终组分别求精确和，再各舍入一次。计划提供实际质量存储差额及每个最终组 `0.5 ULP` 累加的上界，最终质量与成分满足既有审计契约，内能舍入差记入热账本。
- 沉积在容量预检前验证到接收床面的竖直路径；邻列松弛先验证从源床面上方到接收列中心的水平直线路径，再验证竖直下落路径。跨格面保持连通，代表球沿途与碰撞微单元、实际单元床长方体无内部相交；纯支撑相切允许转换。球与长方体的线段距离使用精确二进制有理数判定，保持面、棱和角相切的分类。路径检查与三维球碰撞共用局部几何，逐床单元候选访问预先计入逻辑工作额度。受阻的下层不能接收上层库存，分离床层之间的开放空腔按实际位置判定。当前松弛采用水平直线与竖直下落组成的路径，绕障碍的其他路径需后续搜索。
- 沉积与松弛提交前按真实混合 bulk SVQ 推导接收床长方体，检查附近仍活动的代表球。沉积对所有候选床体接触的颗粒求成员闭包：新增成员必须满足接触年龄，并保留自身最低可达、容量合法的接收单元。每次成员增长后重新规划各接收单元的最终床体，直到所有床体与剩余活动球均相容。完整计划按共同的最终邻列高度验证每份来源材料的安息角；各来源、接收单元与相邻列的高度首次扫描计入逻辑工作额度，并在本计划内复用。整批通过区域组容量、组成、质量、内能与重力势能预检后，先从占容候选移出全部原核，再加入每个接收单元的总床库存，按同一计划原子提交。
- 正重力下，沉积、邻列松弛和侵蚀起动按单元内均匀床层假设精确比较转换前后的质量一阶矩。床质量取各组原始 kg 的精确和，转移质量取实际预检的原始 kg；剩余床和接收床使用概念质量，存储舍入单独核对。转移抬高整体重心时保留库存和待处理列，零重力允许该转换。取出后的混合床高预览与实际删除共用精确装填公式。
- 每步重建单元空间索引，局部访问、成员资格与目标检查、候选成员处理、反应性组成的区域句柄归属检查及形态转换共用逻辑工作额度；材料组和组成处理还受注册表定义上限约束。预算耗尽保留待处理颗粒和 dirty 列。
- deposit 只在 dirty column 及相邻列执行确定性安息角松弛；邻居起点按 generation/cell 旋转，避免固定方向偏置。
- 单次形态转移有严格 SVQ 上限，直到局部坡度不超过材料安息角或预算耗尽；预算耗尽保留 dirty 状态到后续 step，不丢库存。
- 受支撑活动颗粒在沉积受限时，可将已有速度转向当前沉积表面更低的相邻列，保持速度模长到 binary32 舍入精度。静止颗粒和等高邻列等待后续床体松弛或容量变化；重力已在力学子步积分，沉积阶段保持已有动能。此处沿用局部安息角与水平转向的低成本近似。
- 液流的床面剪切应力以 Shields 判据与材料阈值比较；越阈值时按注册表侵蚀率和超临界程度生成待起动的 exact SVQ，几何、容量和势能条件通过后转为零初速 active parcel。
- 无扰动列连续 20 个 logical step 后休眠，暂停坡度松弛。每次真实运动步仍检查未排队列的暴露床面受力，超临界的列重新排队；亚临界水流保持原安静年龄。几何变化、颗粒沉积及反应也会标脏局部邻域。

dirty queue、安静年龄和邻居轮转步属于调度瞬态运行数据。它们控制有界局部工作收敛与休眠状态，随 immutable backend handoff 移交私有候选；region HEAD 冷恢复从 committed deposit 重新标脏并执行安全重检。

沉积层采用地貌松弛模型，计算几何休止角与孔隙水，不包含连续介质颗粒力链求解。若安息角、排水或侵蚀误差超出范围，需结合具体失败机制量化评估。

代表颗粒位置与标量床高之间转换时，质量的竖直分布会改变。当前三种床层转换采用重力势能不增加的必要条件。均匀同质床在床面上方释放代表球会抬高整体重心，正重力下保持待处理；完成起动需要液体受力与释放位移的成对做功。密集的重叠颗粒云还需满足活动空间分布与静止装填的共同约束。较低的重心可伴随机械能耗散；这些转换的完整做功与耗散热模型尚需完善，质量、组成和内能审计各自保持原有闭合契约。

代表颗粒之间允许空间重叠。候选床体互相遮挡的合格颗粒可共同转入各自接收单元；接触年龄不足、缺少合法接收单元，或联合几何、容量、组成与势能条件无法满足时，保留活动库存。这些状态可观察为活动颗粒持续受支撑而未转入床体。

格内沉积几何采用从单元底面起堆积、横向覆盖整个单元的长方体。最低接收层选择、联合计划的最终床高和邻列松弛接收床都要求该长方体与所在单元的八个碰撞微单元无内部相交，纯面相切允许；固定局部检查计入候选目标的逻辑工作额度。部分碰撞格同时满足实际床体空间与到床面的代表球路径时可接收沉积，开放体积由同一几何提供。无法表达的悬空平台与分离格内空腔保留活动颗粒。成功沉积把原颗粒动量交给固定床，床面转向把颗粒动量变化的反作用计入本步颗粒约束冲量。

### 水流起动与床面输运

`GranularBedShear` 在沉积单元上方的第一层自由液体单元中心采样水平速度，使用真实床高到采样点的距离。床高由所在层高度和沉积 bulk SVQ 推导。沿途必须存在实际液体 marker，且中心采样路径不能穿过 cut-cell 固体；空气中的外推速度不产生侵蚀。

未解析近壁层使用 [Spalding 连续壁面关系](https://doc.openfoam.com/2312/tools/processing/boundary-conditions/rtm/derived/wall/nutUSpaldingWallFunction/)，取 `kappa=0.41`、`E=9.8`。从 `Re_y=U*y/nu=u+*y+` 单调求解摩擦速度 `u*=U/u+`，得到 `tau=rho*u*²`，再按液体支撑比例加权。低 Reynolds 数下连续退化为 `tau=mu*U/y`；小量指数余项使用级数，避免相消误差。Shields 数为 `tau / ((rho_s-rho_l)*g*d)`。无水平流速时为零；有水流且有效沉降重量非正时按无重力起动阻力处理。

对正的临界值，计划侵蚀量为 `floor(rate*dt*(theta/theta_c-1))`，再受可用库存、单 parcel 容量和几何约束限制。`rate` 表示无量纲超额为 1 时的 SVQ/s；不足一个 SVQ 的量不提交。临界值为零时，有正剪切即可尝试最大可容纳批次。无法精确拆分的反应性组成继续延期。

起动颗粒从静止床体释放，初速度为零，内能随库存搬运。下一次现有液体—颗粒联合压力/阻力求解提供加速及液体反作用。释放位置使用与运动碰撞相同的代表 parcel 半径，先验证墙体、顶部和固体容量，避免在沙床或顶板内生成颗粒。这个半径是宏观代表颗粒的碰撞尺寸；注册表的真实粒径仍用于阻力和 Shields 判据。

床面检查沿有限网格列寻找最高沉积层，仅在有库存的表面采样液流，不增加持久调度列。独立热轴、暂停和未到期 tick 不执行该检查。

这是一项平缓、非黏聚性颗粒床面的平衡近壁近似。当前采用水力光滑壁面关系，尚未包含粗糙度修正、湍流扩散或随机升力；起动后由已解析流场、重力和阻力决定搬运与再沉积。它不保证静水中或停止驱动后仍能维持悬浮颗粒云。采样要求床上相邻单元有水，尚未覆盖仅在沉积单元内流动的浅水薄层。

### 薄沙床与孔隙阻力

`BodyForceStage` 保留孔隙率和粒径给出的 Kozeny–Carman 渗透率 `Kp=d²*phi³/[180*(1-phi)²]`。沉积 bulk 占格比例为 `f`，床上自由层厚度为 `H=(1-f)*h`。切向采用平行流动近似 `Kt=f*Kp+(1-f)*H²/3`；`H²/3` 来自下侧无滑移、上侧零剪切的层流速度剖面。法向按两侧实际床层厚度叠加阻力。无沉积侧的阻力为零。

两侧渗透率形成同一面上的阻力后，只执行一次隐式 Darcy 更新 `u_next=u/(1+dt*mu/rho*resistance)`。因此薄床保留床上自由流动，满床恢复孔隙阻力，细化时间步不会反复把自由流速度与停滞孔隙速度混合。更新仍在重力与压力投影之前，保留静水平衡。该处理是单元内层状流动近似，未扩展为全域黏性或湍流求解器。

## 固液相转移

- precipitation/dissolution 由 registry 的 exact reaction extent 规划，同时验证 liquid species、solid composition、质量和体积容量。
- 液体计划按拟写入的实际 solver mass 换算 kg，精确汇总与原库存的质量差，再与固体转移份额核对。已有固体的接收增量和溶解扣量也按实际存储差预检；暂时不可表示时保留原库存与 dirty 调度。
- 液体质量从原始 solver mass 加上 exact species 质量差推导，复用化学反应的精确单位换算。组成分配后 species 质量保持原值的载体保留原始质量位模式。
- commit 必须联合更新 chemistry、solid inventory、source/sink、热能和相变 volume/work；任一候选失败则整批不落地。
- 析出与溶解按每份载体的实际质量差搬运动量。移出的液体质量携带原速度，溶解的活动固体携带自身速度，沉积固体以静止速度参与；接收质量的载体和新析出颗粒取得质量加权的输入动量。格内 species 重分配造成的质量转移使用同一计划，逐载体速度在提交前验证，动量误差受 binary32 速度舍入限制。质量混合耗散的动能沿用热机械收支的适用范围。
- 连续凝固相由 coherent store 保存；熔化后恢复到液体 marker。它不借用 active/deposit 表示。
- pending phase volume/work 由下一次 pressure projection 结算一次；未结算时拒绝 `empty` 和不安全 checkpoint 操作。

reaction/phase candidate 必须先在不可变快照上规划 exact extent，再一次提交所有 side column。规划预算以 cell、reaction 和 batch 操作计数，有硬上限；预算耗尽保留当前及未扫描 cell 的 dirty 状态并延期，不允许把半个 extent 留在液相、另一半留在固相。

析出新增活动颗粒前先验证完整候选热库存，再分配固体组成 handle；组成 handle 分配后、物质提交前的候选失败会释放该临时 handle。

marker 的 binary32 体积列也是候选表示格：规划器按完整 reaction batch 确定性分配体积与 species，逐个验证 marker 正质量、物种槽位和量子容量。候选受限时缩小整批，保持原库存与 dirty 调度等待下一次求值。单向规则只生成沉淀候选；每步表面额度只结算完整批次。

沉淀与溶解提交前共同检查可用内能、区域量子容量和载体表示。沉淀和溶解同时验证候选液体原始体积与候选固体整数 SVQ：每个核支撑格的总占容须满足 cut-cell 几何容量。沉淀首先由逐液体载体的实际 kg 有符号质量变化和位置，精确求出新固体应承接的质量一阶矩，并以新固体实际 kg 推导首选位置。该位置在源格内且碰撞、联合占容和载体容量可用时，按它生成或合并颗粒，保留整体质量一阶矩至坐标存储舍入。表示受限时沿用确定性生成位置与碰撞合法的源格中心作为备用候选，以支持满液池中的等体积转换。溶解按旧颗粒核实际释放的各格空间检查源格新增液体。载体位置、active/composition 容量或联合占容暂时无法表示完整批次时，保留原库存与 cell dirty，空间条件满足后重试。

当前同格质量混合保存总线动量，来自不同位置、不同速度的输入还携带内部角动量。单一析出代表颗粒与同格液体接收尚未承接这部分空间运动信息；备用生成位置也可能改变整体质量一阶矩与重力势能。共同速度且首选位置可用的析出保持角动量，其余空间转移的共同表示与做功需进一步完善。

没有可溶 solid 且液相连一个完整 aqueous stoichiometric extent 都不具备时，按 exact species quanta 直接判定为无候选，不进入完整 planner；这不改变任何正向或反向可表示反应。

## 容器与清空

- 干颗粒容器一次只保存一个可完整表示的 SVQ 库存，包含逐材料质量和可选固相组成。
- 玩家和发射器只作用于 controller 内实际目标格，使用与区域 checkpoint 联合的容器 WAL。
- `empty` 先联合预检液体、化学、coherent、active 和 deposit sink candidate，再一次提交；气体库存不属于凝聚相清空。
- reactive solid 的 transfer/audit group 对 mechanical kg mass 与 composition kg residual 分列按输入 `double` 的精确二进制值聚合，最后各自只舍入一次；不得由 species 质量反算机械质量，也不得让 parcel 顺序制造虚假的 composition/mass 审计差额。

## 审计与可观察量

颗粒审计至少验证：

```text
initial + external source - escaped sink
= active + deposit + coherent + transferred inventory
```

等式分别对 SVQ、逐材料质量和可选 species/composition 成立；冲量和热能在各自账本中闭合。`status` 的 active 数、deposit group 数、solid SVQ、bulk occupancy 和休眠列数都是从权威列聚合的只读摘要，不得作为恢复来源。
