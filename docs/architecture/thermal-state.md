## 计算边界与单位

热学随液体、颗粒、沉积、连续固相和逐格气体保存总内能。
内能使用 J；质量用 kg、温度用 K，热容用 J/K，导热率用 W/(m·K)。
参考态允许总内能为负，实际温度须有限且为正。

`ThermalDomainState` 统一管理各载体内能、审计和派生热网格。
`LiquidEnergyColumn` 从单元库存访问液体内能并缓存派生热学数据，批库存操作携带同一份内能。
`ThermalCellOperations` 处理局部平衡与批能量分配，`FluidThermalBinding` 连接流体候选和热状态。
全部载体与有限设备保存[统一质量整数](system-overview.md#units)，热学计算从中派生 kg。液体求解质量权重由 kg 除 `cellSize³` 得到。

单位约定统一见[设计书](system-overview.md#units)。
物种参考能字段为 `reference_internal_energy_j_per_mol`，材料参考能、比热、导热率分别使用 `reference_specific_energy_j_per_kg`、`specific_heat_j_per_kg_k`、`conductivity_w_per_m_k`。
相变批次质量字段为 `mass_kg_per_batch`，热注册表单位身份为 `mmm:si_mol`。

### 热化学尺度依据

| 数据 | 当前取值与处理依据 |
|---|---|
| CO₂ 水中相对气相参考能 | −19400 J/mol；旧数据 −19400000 以每千 mol 表示，除以 1000 保持原有溶解热效应 |
| 中和生成水的物种参考能 | −57300 J/mol；沿用玩法的强酸强碱近似，纠正原先把 J/mol 数值写入每千 mol 字段造成的千倍缩小 |
| Na⁺、Cl⁻ 固相参考能 | 各 −1950 J/mol，盐析出参考能差为 −3900 J/mol；同样纠正原先千倍缩小，反向溶解吸热 |
| 固液、气液潜热及比热 | 已按 J/kg 与 J/(kg·K) 定义，保留数值；同一物种跨相的参考能一致时严格相消 |
| 气液相变的容量变化 | 每个 SVQ 对应 2⁻²⁷ m³，按接受的完整批次修改参考体积 |

盐溶解量级参照 [NIST-JANAF 的 NaCl 溶解焓资料](https://janaf.nist.gov/pdf/JANAF-FourthEd-1998-Chlorine.pdf)，采用玩法精度 3.9 kJ/mol。
反应在当前集总状态函数中按参考内能差处理；溶液体积变化及其压力功沿现有近似忽略。
纯换算与尺度纠错分别验证，纠错后的温升由实际 mol 数、参考能差和载体热容共同决定。

气液交换统一处理已登记物种的挥发、凝结和 CO₂ 溶解／逸出，按实际接受量交接库存与内能。

## 权威数据

- 各液体 `LiquidCellInventory.Stock`、active parcel、deposit group、coherent group 和 sealed gas node 保存总内能 `U`。
- 世界热学注册表保存材料参考能、分段比热、导热率、物种能量偏移、相变和恒温面定义。
- 外部热源、热汇、机械功、有限设备交换及舍入差分别记账。
- 温度、热容、焓、颜色与界面摘要从实际库存和 `U` 派生。

液体质量、组成与内能位于同一单元记录，颗粒与逐格气体内能绑定各自库存索引和代次。
拆分、合并、沉积、提取和相变必须联合交接物质与内能；空载体内能为零。
所有相关库存、目标容量、热状态及账本在首次写入前完成预检，过期计划失效，失败保留原状态。

部分搬运先完成实际整数质量与物种分配，再由材料状态函数分配内能。
设来源参考能为 `B_source`、显热为 `S_source = U_source − B_source`，每个正质量份额按实际组成计算 `B_part`，并携带 `B_part + (m_part / m_source) * S_source`。

原版水桶及仅记录材料的容器，在启用化学的世界中使用 `RegionChemistry.defaultRecord` 的默认组成计算参考能。生成容器、部分转移和注入库存共用该组成；给定温度的外部来源按这一组成计算总内能，保持转移前后温度基准一致。
内能份额采用浮点计算，最大质量份额承接数值余量，目标以补偿求和合并携带内能与实际机械热。账本对已存储来源和目标内能作一次精确汇总，库存差额扣除实际机械热后计入数值舍入。
余量由单元库存统一赋值，材料热学模型提供其余正质量份额的内能。
液体面流、固体排液、外部提取与碰撞拆分共用这一规则，库存与内能沿同一候选一次提交。
零质量几何尾项保存 `U=0`，可保留整数物种及负质量残量，保持其内能随保留、转移和并入正质量记录守恒，热平衡计算读取正质量记录。
颗粒抽取、床层移动及唤醒使用相同的质量份额，热学交接接口明确接收质量整数。
多来源合并先汇总实际内能，再写入目标；最终存储舍入差独立入账。
各载体拟存储的内能都须能反演为有效状态，有效的单元平均值不能掩盖无效载体。

注册表与功能布局随世界能力包固定。缺失物性、引用错误或指纹不一致按恢复规则报告并保留原存档。
显示协议对温度和压力的量化、饱和只影响展示，模拟继续使用实际状态。

## 状态函数

对材料 `h`、质量 `m` 和物种数量 `n_s`：

```text
U_h(T) = m * u_ref,h
       + sum_s(n_s * epsilon_h,s)
       + m * integral(T_ref,h .. T) cv,h(theta) dtheta
```

每个 caloric segment 内比热为常量，积分与温度反演共用分段线性曲线。
温度、热容及分段曲线采用浮点解析计算，混合库存以补偿求和汇总；恒热容材料直接求解共同线性关系。
组成参考能、载体内能及收支继续按既有精确数量契约结算，温度反演误差按浮点传播评价。
物种参考能定义保留有理数和 J/mol 单位，注册时一次换算为每微摩尔的浮点系数；实际整数物种数量直接乘该系数派生参考能。
内能搬运及所有者分配采用同一系数，实际库存与守恒剩余量按精确账本提交，派生参考能的舍入按宏观温度误差评价。
物性观察与反应、相变候选使用凝聚相局部热平衡温度（LTE），按完整质量、组成和总内能求解。
局部能量分配按共同温度与浮点状态函数一次生成各载体内能，最大热容载体承接总量余数。每项保持有限内能与有效正温，实际存储值作精确汇总，存储差额进入原舍入账；局部温度微差按宏观热响应评价。
首尾段向标定温区外连续延拓；外推的相态精度受物性模型限制。
恒温设备等外部设定值仍受已提交注册表的标定范围约束。

相变平台由上下相在平衡温度处的状态能差决定。
候选必须满足有效正温、正热容、正密度、相变定义的适用条件以及库存和能量审计。
温度从实际写入的内能重新推导；舍入差进入账本。

参考能和热网格可以缓存。缓存绑定材料定义、实际质量、完整组成和相关代次，输入改变后重新求值。
缓存布局、求和实现与数值搜索策略见本节入口代码。

### 批量格温度观察

黏性和颗粒载体属性使用一次建格、多格读取的批量观察。
该过程只更新派生工作区，保留所有载体 `U`；反应按受影响单元分配能量，设备按接触到的实际载体逐项写回。
库存、组成、位置或内能变化后重建工作区，候选和冷恢复各自重新派生。
冷恢复先在私有目标中核验全部热量所有者、逐格气体及完整热账，再共同发布液体内能和热状态。
待推进格的内存与存档恢复共用有序格集合定义，格内完全汽化后仍保留机械同步需求。

连续空间温度观察使用连通单相区域中的正三线性权重。
开放支撑被外壳截断时归一化；切割单元和同格多相采用所属单元近似。
质量、体积、内能和参考能沿同一权重采样，实际物种库存及内能归属保持原样。
热浮力与组成密度使用一致的空间支撑，避免采样差异产生虚假体力。

## 热输运

导热以有限热导接触交换实际载体内能。接触两侧的能量变化等大反向；导热率趋零时通量连续趋零。
映射为有限热载体的普通完整方块按自身热库存传热；其余普通外壳绝热。注册表声明的恒温方块与 `thermal_reservoir` 按相邻面热流计入外部源汇。
世界采样得到的面温度是本次计算输入，下一次采样替换。

热导接触读取同代材料、质量、内能与温度，按有限交换量同时更新两侧载体。全部载体共用局部守恒推进，热浴交换和浮点舍入分别进入已有账本。

### 共同凝聚相有限体积导热

`VulkanThermalContacts` 按实际库存体积和固定开放连通分量，为液体与固相建立正对称热接触。
相邻单元按共享开放微面和各载体占据份额分配热导；全开满液单元得到标准有限体积面热导。
同格载体使用单元尺度的混合长度，切格隔墙隔离接触；恒温面按对应固壁面积与半格热阻换热。
同格气液接触与相间传质共用 PLIC 内部界面面积。面积按液体行在界面微盒中的实际覆盖分配，热阻由两相到界面的距离及各自导热率相加得到。
恒温面与有限设备端口读取同代 PLIC 单侧面积。热浴按外侧微面、固定实壁和载体支持集求交，液体与气体分别取得实际湿面和干面，同类载体按覆盖份额分配；颗粒与连续固体沿占据覆盖近似。共同 MAC 开口用于排除全开放面，薄液层保留实际热接触面积。
绝热外壳保持零外部热流，材料导热率采用调和平均。
代表性验证检查热扩散、线性恒温场、冷热尖峰和异质材料，具体误差值留在测试与验证证据中。
液体热容按材料分段曲线与实际质量计算；物种提供各自的参考能。输运先确定各份整数质量与物种，再按来源温度计算各份内能，最大质量份承接浮点余数。接触交换按实际内能和物性重新推导温度。

### GPU 常驻有限热交换

`VulkanThermalContacts` 按真实接触生成正对称热导，每条接触向两端载体累计同一热导。`VulkanThermalConduction` 从当前质量和材料分段曲线求最小正热容 `Cmin_i`，按全部接触热导之和 `D_i = Σ_j G_ij` 得到连接率 `λ_i = D_i / Cmin_i`。每条接触采用同一份有限热量更新两端：

```text
q_ij = dt G_ij (T_j - T_i) / (1 + dt (λ_i + λ_j))
U_i(new) = U_i(old) + Σ_j q_ij
q_ji = -q_ij
```

恒温环境使用规定温度和 `λ_j = 0`，实际接收或放出的热量进入环境账；有限墙保存自身内能、热容和全部接触的连接率。每个载体的交换权重总和小于其最小热容，温度保持在本步自身与接触邻居的温度范围内。分段状态函数仍按最终内能反演温度，材料、物种和质量在导热阶段保持不变。

接触按统一方向枚举：首遍求真实连接热导，连接率准备后再求一次热量，并向两端载体累计同一份反号结果。载体准备、热交换和发布在一次候选提交内完成。小时间步趋近原有限体积导热；强接触和粗时间步下均温较慢。每步仍推进完整请求时长，有限库存与环境收支使用实际交换量，浮点存储差进入舍入账。相变继续沿实际物料和潜热链结算。

`thermal_reservoir` 的设定温度由世界 BlockEntity 保存。调整温度会刷新相邻区域的恒温面并唤醒热学，能量通过实际接触热量进入区域。

### 有限热墙与设备

`FiniteThermalBodyState` 保存设备材料、质量、总内能、注册表指纹和代次。
设备定位信息由 `FiniteThermalDeviceState` 保存；完整设备库存随 region HEAD 提交。
世界对象负责定位和接触，设备内能由区域库存持有。

`VulkanThermalContacts` 将有限设备与流体端口纳入同一接触图，`VulkanThermalConduction` 依据各载体的质量、参考能、内能及比热曲线计算换热。设备和流体内能随完整设备候选一起提交，外部设备交接沿 HEAD 与 WAL 协调。
每个有限热载体归属一个区域，所有接触共同使用该区域持有的唯一内能。

`OrdinaryThermalWalls` 按方块位置与材料建立有限墙库存。石、金属和玻璃通过数据包标签及有限热载体定义配置；多个接触面共享同一份质量与内能。新增墙体按定义初始化，移除或替换按完整内能记入环境源汇。普通墙与有限换热器共用设备库存、接触图、导热和存档流程。工业装置的世界建造与验证共用墙体识别和接触端口，预热、冷却及表面装填的能量进入设备账。

`FiniteHeatExchangerOperations` 将有限换热器安装到已启用区域的围墙槽位，区域定位与热接触均读取定义中的端口方向；默认设备具有北／南端口。`HostFluidState.finiteThermalPortContacts` 提供宿主端口视图，设备端口与载体内能随 GPU 完整候选共同提交。区域成功步采用同一逻辑时长推进设备，暂停、不可用或有待恢复事务时保留库存；设备成本纳入区域原有完整步调度。

`FiniteHeatExchangerBlockEntity` 只保存区域和世界槽位定位；区域库存保存已安装设备的质量、内能、材料、指纹与代次。拆卸物品经 `FiniteThermalDeviceItemCodec` 携带完整设备状态，再安装按目标槽位定位，保持原热库存。创造栏空硬件首次安装按世界定义初始化。安装、拆卸和破坏交接见[世界与容器事务](world-ownership-and-containers.md#有限换热器安装与拆卸)。

### 固定表面吸附与催化

固定表面绑定有限墙的一面，保存材料身份、装填质量、已吸附物种与分数量子交换进度。表面材料由世界数据定义容量、温压适用范围、有效面积、交换速率、吸附物参考能和热容，以及适用的催化反应。墙体、装填材料和吸附物共享一份总内能；温度由共同状态函数反演。安装时表面载荷的内能进入墙体，拆卸时按当前墙温分出载荷内能，设备、物品和区域事务使用同一份库存。同一面补充相同材料时合并装填质量、吸附物、未决交换量和内能；更换材料先取出原载荷。

每种吸附物按局部分压和温度得到竞争占位比例。有限速率交换由实际接触面积、占位差与请求时长决定，并受气体库存、空位点和两侧可用热量约束；整数接受量同步改变气体和表面库存及两侧内能。低分压或升温可促使物种解吸。固定表面与筛分别使用相应真实接触面积，筛的实体比例参与面积计算。液体催化接触使用相同面几何，将面积对应的倍率同时作用于已有有限速率反应的正逆方向，再进入原有竞争与参考能结算。

`FiniteThermalDeviceInventory` 汇总吸附物种、元素和质量；`FiniteThermalDeviceCodec` 与 `FiniteThermalDeviceItemCodec` 保存表面状态。`VulkanThermalDeviceLayout` 在候选中保存每种吸附物及其热状态，`VulkanGasLiquidMassTransfer` 按稳定表面及端口顺序完成有限交换，`VulkanLiquidReactions` 处理实际接触催化。

### 有限体积离散

`VulkanThermalContacts` 建立接触图，`VulkanThermalConduction` 推进实际载体内能。接触图和数值求解使用同代材料、质量、参考能、内能与温度；终态、源汇和舍入账随候选共同提交。
热导使用材料调和平均、固定开放面积及实际库存占据份额；同格与固壁采用半格混合长度，相邻格采用一格长度：

```text
k_pq = harmonic(k_p, k_q)
G = k_pq * A_effective / length
Delta U_p = G*(T_q-T_p)*dt / (1 + dt*(lambda_p+lambda_q))
Delta U_q = -Delta U_p
```

接触求解期间保持位置、质量、材料和组成不变，直接推进对应载体内能。
零导热载体随物质搬运内能；同格温差按有限速率消散。
气体逐格库存随共同面流输运。气体、液体与有限设备的热交换进入共同热载体接触图，气格按实际干容与开放面分配接触面积；每份热量在接触两侧等量结算。气体组分比热与参考能共同决定温度，导热率按标准体积分数混合。

内置物性的数值与采样分段以数据定义为准。
N₂、O₂、CO₂ 的热容由 [NIST Shomate 系数](https://webbook.nist.gov/chemistry/)积分，H₂O 蒸气采用 [JANAF 气态水焓表](https://janaf.nist.gov/tables/H-064.html)。分段保存 100–1700 K 的平均定容质量比热 `Cv=(ΔHm/ΔT−R)/M`，模型摩尔质量与气体库存一致；CO₂ 在 298 K 以下沿用端点 Cp，温区外按现有端点热容延拓。导热率保持各组分 300 K 稀薄气体参考值的常数近似，混合物按标准体积分数加权。生成工具同时推导水蒸气相变批次体积、保持常压汽化潜焓和液水参考能关系，见[Python 工具](../maintenance/pytool.md)。

### 热浮力

液体采用线性体膨胀的正密度近似，在重力项中使用：

```text
rho(T) = rho_ref / (1 + beta*(T-T_ref))
Delta u_y = g * dt * thermal_density_correction_face / rho_face
```

参考密度来自实际单元质量与体积，温度复用同代单元的局部热平衡结果。
同格液相分别读取自身热膨胀物性，再按实际质量汇总浮力修正；物性、压力和体力共用单元及格面支撑。
这项体力修正保持质量与体积库存原样。

每种液体声明 `T_ref` 与 `beta`，定义随材料指纹保存。
逐载体核对正温、有限系数及正的膨胀体积，再进行空间平均。
参考态附近保持原线性浮力响应；大温差沿该粗尺度关系延拓，实际相态由相变模型处理。
该修正提供玩法所需的热浮力，液体真实几何体积继续由共同占容与相变交接维护。

### 自然对流的宏观增长

常物性、自由滑移受热液池使用 Rayleigh 数与解析增长率参照评价宏观对流：

```text
nu = mu/rho
alpha = k/(rho*cv)
Ra = g*beta*DeltaT*H³/(nu*alpha)
```

验证以一档普通扰动覆盖两档网格和临界点两侧，检查扰动衰减与增长方向。
各网格的增长率误差按空间离散尺度和共同时间步长评价，同时守住体积、质量、物种与内能账。
解析条件参见 [Rayleigh 原论文](https://doi.org/10.1080/14786441608635602)。
夹具尺寸、扰动与误差阈值由测试维护。

黏性应变行与床层 Darcy 阻力按各自局部离散计算不可逆损失，并登记到源液体单元。
本步热量沿实际整数质量通量搬运，与动量混合热汇入同一次库存计划；源单元完全搬空时，热量随其实际接收方交接。
黏性和颗粒阻力按实际动能损失结算热量；压力、重力、共同阻力和气体压缩功使用实际的机械能与热能变化。相间物质按真实接受量搬运动量和内能；格面的动量变化、动能差及势能差共同结算。格内多相按各自实际热容分担能量变化，负向变化受可用显热限制。
实际写入载体 U 的机械热和存储舍入分别入账；压力、重力与外部实体的可逆做功由机械审计记录。
实体接触逐面使用实际冲量 `I=mΔv`，外功为规定实体速度与冲量的点积；外功扣除局部实际动能变化得到接触阻力热，与墙面停动热共同提交。`MovingBodyFluidCoupling.Result.externalWorkJoules` 保存有符号外功，候选热账包含力学审计开始前的实体接触热。
黏性应变行直接给出局部指数衰减耗散；压力、重力、共同阻力的实际 K/PE 交换和气体功按载体实际库存结算。外部规定实体的压力功与剪切功进入同一实际内能提交，诊断分项包含外部约束功。MAC 写回舍入、压力离散及空间重建交换分别观测；温升按实际载体温度报告，有限振幅运动的总能量评价保留对应空间近似。

### 气体能量与功

各气格从组分、实际气容和总内能派生温度与压力。气体随开放面搬运实际组分及内能；压缩和膨胀的压力功与共同机械能按逐格状态结算。开放外侧的环境压力功使用实际气体净流入体积，加入共同机械能账。
状态方程、真空和容量功的完整规则见[气体参考](gas-state.md#共同液气状态方程)。

## 相变

相变依赖热学与化学功能，按注册表定义的完整守恒批次推进整数 extent。
批次数受可用物质、内能、容量、饱和条件和共享单步操作预算限制。
物质、组成、速度、内能、逐格气体后继和审计属于同一提交计划。
暂时无法表示完整批次时保留库存和待处理任务，定义与身份错误按具体原因报告。

试算使用未来实际载体的质量与组成求共同温度。
选定批次后按实际来源与接收方交接组成、内能及动量，更新相占容和局部状态。
提交后从实际载体重建受影响单元，其他单元保留原始内能。

### 固液

固液相变联合交接 kg、液体体积、coherent SVQ、组成与内能。
同格其他材料参与容量和局部热平衡，保持各自身份。
两相在固定区域体积内守恒交换内能，相界位移登记待机械推进标记。

平衡温度 `T_eq(p)` 使用同代局部共同状态方程的绝对压力。
注册表曲线在数据内线性插值，在数据外沿最近端点割线延伸；结果仍须为有效绝对温度。
冷恢复先按局部液气库存及状态方程派生压力，再执行需要压力的热学计算。
整批扫描先根据实际载体温区与区域压力上界排除无法发生的转换，再为候选单元准备局部热账；压力相关候选继续读取同代实际压力。
固液与气液相变各自只准备一份质量、体积和组分候选，动量交接读取该候选；热平衡求解完成后按库存键赋值最终内能，共享同一数量和几何后继，一次提交。实际整数转换为零时，阶段直接返回。

批次搜索选择更接近平衡温度的可提交整数状态。
凝聚相转换按真实质量、相占容及全单元正温下限能量限定批量，并结算动量和势能；实际液气占容由共同状态方程更新。
热容延拓使目标物相的低温能量高于来源时，转换消耗该单元相对于低温下限的实际能量余量。
剩余温差反映批次量化、库存或容量限制，避免连续步骤在相邻批次间反复冻融。
平衡能差与整数批次由 `VulkanCondensedPhaseChange` 维护。

内置冰/水使用固定体积批及单一固相载体。
熔化曲线采样自 [IAPWS 熔化曲线](https://iapws.org/public/documents/MdUFK/MeltSub2011.pdf)，
高压下各冰相的密度差异仍属于该表示的近似。

### 气液

挥发组分按 `p_i^eq = x_i p_i^sat(T)` 与气体分压的差异进行有限速率交换，纯物质对应摩尔分率为一。每条交换规则从当前载体库存和内能计算温度与热容，同一液体载体的全部物种共享热库存。半隐式响应包含共同压力、液相组成与汽化潜热对温度的反馈，接受一条规则后再求下一条需求。首批水和乙醇采用理想混合近似，饱和压力由材料平衡温度和相间参考能计算。CO₂ 使用 Henry 关系，并沿同一状态求值和库存结算执行，见[化学状态](chemistry-state.md#气液有限速率传质)。

实际液体、气体物种、质量和携带内能同时转移；挥发与凝结按批次修改液体参考体积，逐格混合物 EOS 重新计算真实占容和压力。每个跨格转移携带供体速度，前后动能和势能差回到内能账。相界变化标记待机械推进格；气体空行的内能余量交给实际接收液体。共享批次受真实供体、最低温度内能及相变预算限制。

## 反应热

反应先规划完整整数 extent，再联合提交物种、固体、内能与审计。
物种参考能随组成搬运；反应改变参考能后，总内能通过状态函数表现为温度变化。
外部注热才进入热源列，同一反应能量按一条账结算。

析出、溶解和合并使用完整未来载体库存预检热状态，再分配组成记录并提交物质。
固液反应按完整单元的实际内能、各物相正温下限和反应计量限定可转移批量，同时预留格内位置变化所需的势能。
有限能量允许的整数批次正常交接，其余物质继续参与后续传热和反应。
失败保留原库存及待处理任务。

## Logical step 顺序

完整计算步见[当前设计书](system-overview.md#physics)。热化学轴的顺序为：

1. 完成载体交接和有限导热。
2. 同相扩散、液相化学反应，再执行颗粒析出与溶解。
3. 统一气液交换，再以剩余共享预算执行凝聚相变。
4. 颗粒形态转换和局部唤醒，最后检查审计。

`PendingPhaseMotionWork` 保存待机械推进格集合，重复相变合并标记，随完整候选和存档保留。
单元库存已经保存相变后的体积，下一次真实压力投影完成力学同步后清除记录。
该记录标记同步需求，相界内部交换的能量已在相变步骤结算。
内部转换按真实接受量更新逐格库存和内能；相变后的几何与 EOS 在机械推进前更新。外部载体编辑和碰撞位移按实际局部容量变化结算气体压缩功。

外部物质转移前先完成已有相变几何同步。
管理员、玩家容器和发射器共用这一流程，具体入口见[相变几何同步](runtime-and-lifecycle.md#phase-work)。
失败保留待处理记录和原库存。

## 能量审计

每个可发布状态按下式核对实际内能：

```text
U_inventory
= U_initial + external_source - external_sink
 + mechanical_work + finite_device_exchange + roundoff_residual
```

库存汇总液体、活动颗粒、沉积、连续固相和逐格气体的实际内能。
载体间导热、反应交接和相变属于内部转移。
物质进出区域、恒温热浴和管理员注热按实际交接进入外部源汇。

有限设备与流体分别保存方向相反的交换账，双方实际内能变化与舍入账在区域内联合闭合。
管理员清空同样记录真实移出内能；排气使密闭节点成为零库存、零内能的真空。
实际存储的舍入差进入精确账本，温度保持为派生观察。

质量和物种继续使用精确整数守恒。内能使用浮点数，统一由 `ThermalAuditLedger.acceptsInventory` 按实际库存、预期库存和能量交接规模判断数值误差；超出容差的差额拒绝发布。允许的残差保持原样，库存、存档总能量和来源／汇均保存实际值。舍入归约可精确记录已有浮点结果，运行和恢复采用相同的工程误差口径。

## 持久化与容器

液体总内能随 `Stock` 保存，颗粒、沉积和连续固相内能随各自库存保存；逐格气体内能随空间气体状态保存。
普通后端交接沿用已验证快照，复制可变内能列与审计；液体不可变行保持共享。
冷恢复从保存的库存和内能核验正温、状态方程与完整能量账，再建立派生温度工作区。

区域 section 直接编码液体记录的 `internalEnergyBits`，热扩展保存非液体内能。
manifest 的逐 section 热总账汇总液体与非液体内能，`PendingPhaseMotionWork`、最近真实压力场和热交换输入随同代状态恢复。

`ThermalContents` 将物品完整物质库存、注册表指纹与总内能绑定，桶内采用一个平衡温度。
部分倾倒按实际材料、物种和状态函数拆分，两份内能共同保存源能量，存储舍入纳入区域事务。
抽取多载体时先汇总真实移出能量，在物品存储处统一舍入，差额进入区域舍入账。

容器 WAL 同时保存物质量、物品前后状态和耦合能量；物品耐久存盘后才清理事务。
缺少能量结算能力的配方不能剥离带热量的物品数据。
字段和提交顺序见[存档参考](region-state.md)与[容器事务](world-ownership-and-containers.md)。

## 调度与观察

力学与热学是独立活动轴。导热、反应、相变、气体变化、设备交换与载体运动按实际变化唤醒对应计算。
内部热流也可能改变浮力或气压，因此热学推进后可唤醒力学；玩家暂停优先。
休眠保持库存，恢复条件由调度模块维护。

查询与界面只读实际库存派生的温度、总内能及气体状态。
运行时物理状态失败归入数值暂停；持久格式、定义或身份损坏归入锁定，恢复依据保留的权威状态与事务记录。

### 耕地吸水的内能交接

耕地每增加一档湿度，区域提取实际接触水相的1 L库存及其质量、species和携带内能，作为对原版土壤的外部汇一次提交。土壤以原版MOISTURE保存量化水库存，原版环境负责其补水与散失；区域热账保存离开模拟域的实际U。事务失败保留源内能，恢复按区域HEAD及耕地方块前后态判定，避免重试重复扣热。完整契约见[耕地湿润](world-ownership-and-containers.md#耕地湿润)。
