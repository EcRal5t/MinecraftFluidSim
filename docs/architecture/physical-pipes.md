# 单方块物理管道

MMM 管道使用现有区域库存、MAC 动量、气液压力、颗粒与共享热场。管件定义真实碰撞和开放截面，管内物料保存在区域单元中；管道本身不另存一份液体。Create 的管道继续采用其运输规则，双方交接由适配层负责。

## 管件与操作

| 方块 | 用途 |
|---|---|
| `metal_pipe` | 普通金属管，参与管内外换热 |
| `insulated_pipe` | 使用绝热材料定义的保温管 |
| `glass_pipe` | 中空透明观察管，可看实际液面和物料 |
| `pipe_valve` | 轴向管阀，关闭、半开、全开，可由红石控制 |
| `pipe_screen` | 带金属壳体的筛网，沿用筛孔和开放率配置 |

三种普通管共用六面连接规则；直管、弯头、三通和更多分支由实际开放口组成。潜行空手点击某面依次选择手动开放、封口、恢复自动连接。自动连接匹配相邻管件，手动开放用于向水箱或区域内空间开口。换热器只连接南北换热面，恒温源允许六面接触，容器接口仅连接朝向区域的内侧，外侧继续连接物料箱。

使用探针选区激活第一段区域后，连接到区域的管路会沿实际兼容口纳入同一模拟范围；连接同类型的另一已激活区域时执行守恒合并；选区和原版水池分别连接，保留各自的原版水归还方式。未接入模拟区域的方块保留几何与连接状态。自动探测按方块拓扑变化失效，稳定管网复用发现结果。封口及管阀调整先准备私有碰撞候选；无法安置被挤占的库存时保留原几何与方块状态。

拆除管段只改变世界几何，原有物料仍留在模拟区域中，随后按开放空间运动。关闭支路后保留统一库存区域和各自密闭空间；不存在通过删除管段方块实体清空物料的路径。整个区域的移除继续走已有生命周期和物质交接规则。

## 几何与精度

方块尺度为 1 m，中心内腔为 `[0.25, 0.75]³`，连接臂将同截面延伸到相应方块面。直管截面积 0.25 m²，每米有效容积 0.25 m³（250 L）；弯头、分支和封端的容积按各自内腔计算。

`PipeGeometry` 共用 64 种物理开口掩码，模型采用可复用的框体和六面端盖。三种材质的模型与实际碰撞均落在 0.25 m 微盒格线上。每个端口有自动断开、自动连接、手动开放、封口四种状态，自动断开和封口共用关闭几何；物理形状缓存按 64 种开口复用。

管阀使用三档实际可解析截面：0、2、4 个开放微面。液气压力和输运使用同一开放面；筛网附着在轴向中心面，管壳的几何继续阻隔外部空间。每格仅允许一个连通开放空间，因此同一方块内的两条独立交叉细管不属于本组管件。

现有求解格长仍为 0.5 m，管内速度剖面及弯头损失采用粗网格近似。验证检查守恒、通流、压差流向及长度／黏度趋势；额定流量与工程阻力系数需按具体工况测量。长管网按现有稀疏 8³ 计算块和区域预算计费。

## 区域合并与恢复

`PipeNetworkPlan` 沿实际对向开口收集管件及端点所属区域，实墙、封口和设备侧面阻断拓扑连接。`RegionMerge` 将所有源状态映射到共同世界坐标网格，并将新增空间的空气从共享环境移交到区域。

`FluidDomainMerge` 保留液体、气体、物种、颗粒、固相、热库存、未决计算和面动量，调色板按稳定物料身份合并。重复实体在平移后状态相同时去重，冲突时拒绝。选区区域和原版水池分别使用原有归还规则，自动合并要求源区域种类相同。源区域的求解配置、物理定义和能力必须一致；实际占用重叠、缺失库存格及资源超限均拒绝合并。

主区域保留原 ID、递增网络代，其他源区域退役。世界 HEAD 一次发布主区域新状态及退役记录，区域文件作为可恢复镜像。被接管的原版水记录随主区域 ownership WAL 转移；世界 HEAD 发布前保留旧区域，发布后恢复新区域并清理退役 ownership。区域目录同步替换全部源的预算和选中状态，客户端接收退役通知与新区域快照。

已归还的原版水格只在管路实际重新触及时接管；未触及的位置继续由原版世界管理。对端暂停、恢复或处理相变期间保留各自区域运行，待条件就绪后再合并。

共享墙体的区域设备记录属于接触投影；合并时移除旧投影、保留世界唯一热库存，再为新区域重建接触。其他有限设备及其表面库存一并保留。

## 管壁热库存

普通管与管阀将端盖和闸板视为收纳在同一管体内的部件，名义实体体积固定为 0.875 m³；切换开口仅改变接触几何，保持管体质量、内能和温度。材料热物性由世界定义和相应方块标签加载。

管筛包含两个独立有限热节点：component 0 是按真实体积计算的金属壳体，component 1 是截面积缩小为原筛四分之一的筛膜。两者分别投影，筛膜热接触限于实际中心通道；固定／运动结构交接保留两个节点的质量、内能和表面库存。

## 沉积与观察

沉积床沿开放微盒自下而上填充，体积、高度、碰撞和冲刷使用同一管腔几何。清理通过现有颗粒提取路径取走实际物料并释放占容；观察管同步显示接受后的床体。颗粒显示快照携带每格一个字节的固定微盒掩码，客户端按该快照裁剪床体并更新几何缓存。筛网堵塞由所在通道的实际开放容量计算。

床层渗流阻力使用材料粒径、实际孔隙率和液体黏度计算 Kozeny–Carman 渗透率，作为独立床层阻力进入压力求解的有效面惯量与预测速度；按接受后的流速计算耗散热，沿现有热输运和机械能账结算。未填满的床层按水平绕流、竖直穿床组合有效渗透率；液体润湿采用格内平均饱和度，属于当前粗网格近似。

## 验证入口

- `:fabric:runHostValidation -PhostValidation=shape,pipe-network,region-merge,ownership,environment,structure-handoff,protocol`：真实形状采样、64 种开口、六向管阀、封口受阻、设备接口、管网发现、提交前后恢复、热库存及结构交接。
- `:solver:runFluidDomainMergeValidation`：多源库存／账本、材料表、实体与稀疏空间映射。
- `:app:runApplicationValidation`：区域目录预算、重叠、过期源与选中状态。
- `:gpu-kernel:runGpuPipeFlowValidation`：直管、弯头、三通、长度／黏度趋势、闭阀零跨越及重开通流，逐步核对质量、物种和热账。
- `:gpu-kernel:runGpuPipeThermalValidation`：金属管与绝热管的有限热交换和共享环境热账。
- `:gpu-kernel:runGpuPipeCondensationValidation`：初始无液态水的蒸汽经管壁冷却、生成凝结液并保持物种及热账。
- `:gpu-kernel:runGpuPipeDepositValidation`：管腔中的实际沉积、通流受限、提取清理及恢复，检查粒径趋势、压力耦合、热账、窄管床面采样和渗透率解析值。
- `:gpu-kernel:runGpuScreenGeometryValidation`：受限管口中筛网开放面积与沉积堵塞比例。
- `:gpu-kernel:runGpuSolidLiquidReactionsValidation`：开放微盒中的沉积质心、固液交接与重力功。

方块模型、物品、配方、解锁、掉落和工具提示随管件一并提供；材质沿用现有深钢、青色、金属盖板、绝热板和透明玻璃资源。
