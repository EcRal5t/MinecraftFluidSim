# 单方块薄壁管道

MMM 管道以独立有限管腔保存物质，普通区域负责管外三维流体。相邻管段与区域端口交换真实库存，管壁接入世界共享环境热场。Create 管道沿用 Create 的运输规则，双方交接由适配层负责。

## 修改入口

| 职责 | 代码入口 | 验证 |
|---|---|---|
| 管件几何 | [PipeGeometry](../../fabric/src/main/java/mmm/block/PipeGeometry.java) | `shape,pipe-network` |
| 管网输运、相变与管壁热 | [PipeNetworkSolver](../../solver/src/main/java/mmm/pipe/PipeNetworkSolver.java) | `:solver:runPipeLiquidTransportValidation`、`:solver:runPipeWallHeatValidation` |
| 区域端口 | [PipeEndpointResolver](../../fabric/src/main/java/mmm/simulation/PipeEndpointResolver.java) | `pipe-network,lifecycle,environment` |

宿主检查经 `:fabric:runHostValidation -PhostValidation=<选择器>` 执行，存档与客户端分片由 `protocol` 覆盖。

## 管件与布线

| 方块 | 用途 |
|---|---|
| `metal_pipe` | 普通金属管，参与管内外换热 |
| `insulated_pipe` | 绝热管，采用已有绝热材料热物性 |
| `glass_pipe` | 透明观察管，显示液层与床体 |
| `insulated_glass_pipe` | 透明绝热观察管 |
| `pipe_valve` | 轴向管阀，关闭、半开、全开，支持红石 |
| `pipe_screen` | 轴向管筛，配置粒径阈值与开放率 |

放置沿点击面轴线建立直管，其余四面封闭，并排管线各自独立。潜行空手点击单面，在手动开放、封闭、自动连接之间切换，可布置弯头、三通与多支路。四种管材的对向开放端可互连。探针读取管腔容量、实际液量、压力与床库存。

主体外宽 0.625 m，内径 0.5 m，壁厚 0.0625 m，模型与碰撞对齐 1/16 m，连接臂伸到方块边缘。直管开放截面 0.25 m²，容量 0.25 m³（250 L）；封端、弯头、三通与阀板按各自真实内腔计算。每面保存自动封端、自动连接、手动开放、收回支管四种状态，外包络、内腔与管壁由同一份几何生成。

## 物质归属与求解

每个管段保存气体组分、液体物料与组分、床库存及各自内能。管网液体体积用 m³，与区域库存交接时显式按 h³ 换算；质量、物种与固体体积保留原整数单位，能量舍入单独记账。

`PipeNetworkSolver` 按压力与高差推进有限容积输运。通流阻力由黏度、长度、开放面积与床层渗透率给出，管径阻力取等效 Poiseuille 形式。多出口从同一代库存统一分配，并受压力顺应性与可用库存限制，分支次序不影响结果。气体压缩功、重力势能、液体弹性能与耗散热一起闭合。

管腔采用段平均状态，速度剖面、湍流与弯头涡流按段平均近似。气液相变复用世界材料的饱和关系、物种定义与热参考能；冷凝可从零液量开始，气化消耗实际液体与相变能量。

床层按实际液体通量计算冲刷剪切，以材料起动阈值搬运颗粒；筛网按粒径截留。固体质量、物种、体积与内能随床载迁移，床层占容与渗透率影响后续通流。

普通区域把整段管道的壁体与管腔表达为静止实体包络，外部流体占据包络之外的真实空间。

## 区域端口与生命周期

`PipeEndpointResolver` 按真实管口的 8×8 像素面映射相邻区域格，剔除被实墙遮挡的微面。区域保持各自身份与求解范围，管道连接不合并区域。

区域接口作为有限库存临时段参与同一次候选：气体、液体与物种在同一轮计算后回写各自所有者，区域面动量随质量更新，移出动能进入相连管段的热库存。所有相关设备状态准备成功后统一交换，失败时各方保留原代次。

新建管腔从所在空间划分实际物质：已跟踪的环境空气保留原组成与内能，机械区域按管腔与源格相交体积划分库存，首次跟踪的空气采用世界环境初始条件。

拆除前须排空液体与床库存，剩余气体返回外部有限空气或相邻机械所有者，普通销毁与爆炸掉落前都执行该检查。调整管口或阀板时检查新容量并结算有限气体的压缩功。

区块卸载断开涉及该区块的边，相应段暂停物质、相变与热交换，已加载的独立段继续推进；恢复后按方块身份与端口重建连接。

## 共用环境热场

管壁按真实实体体积、材料密度与有限热容建模，四种材质由方块热标签与世界材料定义选择。内侧热阻使用半壁厚与管内载体热物性，外侧连接有限空气、普通区域流体或相邻固体节点。

管内、管壁与管外空气分别存储能量，墙体只保留一个世界热节点，热交换增量逐次互反；管内气体受热引起的液体弹性能变化同时结算。机械格上的外壁接触按真实 1/16 m 壳面聚合。运行时批量读取一代墙节点，管侧与环境侧候选共同采用；墙节点未全部加载时等待完整热拓扑。

## 存档与显示

每维管网、方块属性、能量账、世界环境与普通区域写入同一世界 HEAD 代次。服务端发布管腔库存与内腔形状，客户端按完整代次组装分片；液层按密度排序，床体按实际体积显示，透明排序与深度沿用流体渲染批次。
