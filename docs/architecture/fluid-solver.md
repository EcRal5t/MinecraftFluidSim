## 后端候选接口

`FluidDomainState` 包含液体载体布局、实际库存、已绑定能力、求解配置与预算。
`Layout` 固定网格、外壳、载体种类、注册表和功能身份。
材料物性独立于颗粒能力绑定，所有液体使用同一黏度定义。

计算交接还保留化学与颗粒调度进度、世界热交换面及最近真实压力投影。
这些运行输入与 checkpoint 字段分别定义，持久范围见[存档参考](region-state.md)。
热区域冷恢复后先执行力学重建压力，再允许独立热轴依此求相平衡。

力学使用 `FluidStepRequest` / `FluidStepCandidate`，独立热轴使用对应 thermal request / candidate。
请求中的实体运动输入只作用一次；相变几何同步走仅含力学的请求。
两类候选均返回紧邻后继，接管前核对后端身份、代次和完整布局。

CPU 从原始请求恢复私有域，完成全部阶段后返回。
子任务全部结束才传播结果或原始异常，失败保留活动区域。
成功的私有对象可交接一次；需要不可变快照时，在接管前调用候选的 `state()`。
提交顺序见[运行时参考](runtime-and-lifecycle.md#candidate)。

Courant 超限或颗粒非线性求解未收敛时，后端从原始请求细化重算完整力学步。
重算保持总推进时间、相变预算和外部输入的一次提交规则，累计重试受预算限制。
`mechanicalResolution()` 报告细化次数、累计预留子步和原因，`StepStats.substeps` 报告完成子步。
具体并行划分和子步选择规则由 `CpuWorkBatch` 与 CPU 后端维护。

`StepStats` 返回输运、化学、颗粒、相变和物性越域诊断，调度读取最后成功步的结果。
可选机械审计按实际 kg 记录各阶段动能变化及液体、活动颗粒、均匀床层的重力势能。
`closureResidualJoules` 核对阶段动能变化之和；连续固相和集总气腔的机械能尚未纳入该诊断。
热学内能审计采用[热学参考](thermal-state.md#能量审计)规定的完整载体范围。

## 网格与 marker

纯液体、含颗粒和沉积区域共用 MAC 压力、黏性和有限体积输运。
`PressureSystem` 组装液体与有限气腔储存项，颗粒通过惯性、隐式阻力和占容导数加入。
`GridToParticleStage` 按原有载体动能加实际网格做功限制 FLIP 增量，保留未被 P2G 采样的运动能量。

载体保存位置、体积、质量、速度、材料、相身份以及已启用的组成和内能。
`FlipPressurePhaseGeometry` 从库存、邻格相分数与固定碰撞连通分量重建 PLIC。
MAC 共用格面速度，同格断开液体采用共同速度近似。

`CellRemapVelocity` 以浮点协方差拟合局部梯度，未解析方向保留平均速度。
重采样保持质量加权动量并限制细尺度动能，表示转换损失进入对应局部热账。

### 空间积分误差与分布诊断

`MicroBoxPlaneVolume`、`MicroBoxPlaneMoments` 和 `GasGeometryOverlap` 使用浮点几何积分，
`PlicPlaneOffset` 求解平面偏移。几何提供权重，库存继续采用整数和精确数量结算。
验收检查体积、质量、宏观位移、动量与能量，亚格形状和高阶矩由当前表示能力决定。

现行 `FlipParticleReseeder` 仍通过 `MomentPreservingMergePlan` 与 `QuadratureMomentFit` 合并兼容载体，
包含协方差和最少样本限制。这些约束随重采样表示调整，相关旧测试同时迁移。
宏观精度与成本要求见[当前实施计划](../roadmap/solver-consolidation-plan.md#精度与物理取舍)。

### 内存布局

活动数据采用固定容量的结构分离数组：

- 单元：压力、散度、库存汇总、物相几何和材料属性。
- 格面：三轴 MAC 速度、P2G 权重、有效标志及切割开口。
- 载体：位置、速度、体积、质量、材料与相身份。
- 侧列：化学组成、颗粒信息、内能及气腔交接数据。

`ensureInventoryGrid` 重建库存几何，`ensureGrid` 还执行所需的速度传递和延拓。
两类工作区从当前载体派生，恢复后按需重建；位置、库存和速度更新由各自 dirty 标记跟踪。

所有侧列使用相同 append / swap-remove 顺序，载体修改在同次计划中更新已绑定列。
运行时 handle 绑定本次注册表，存盘、物品和网络采用稳定 ID 或规范索引。

### 液体黏性应力

`LiquidViscosityStage` 对所有区域使用 `ViscousMacDiscretization` 的 Newtonian 应力离散。
`ViscousStressOperator` 求解质量归一化后的后向 Euler 系统，黏度调和平均，墙面冲量独立记账。
颗粒和沉积通过耦合项影响运动，液体黏性算子保持一致。

### 时间步与 CFL

`timeStep` 是完整逻辑步的物理时间。
液体、颗粒速度和重力预测决定初始子步，压力后复检实际位移。
细化维持完整步总时间及库存审计，wall-time pacing 调整逻辑步的调度间隔。

### 单元有限体积输运

`ConservativeLiquidFlux` 从 MAC 和 PLIC 准备单值共享通量，联合限制供体库存与接收容量。
面通量量化余量在有界误差范围内沿开放通路守恒重分配。
`BallisticLiquidRemap` 处理缺少压力支撑的未解析载体。

两类运动汇入 `CellCarrierRemapPlan`，共同分配材料体积、质量、动量、物种和内能。
计划先生成正权重后继载体，再准备气腔和热账，全部预检后发布。
持久化保存实际载体数据，液面、气腔及接触几何从 PLIC 重建。

### 当前自由面的空间解析限制

未解析液滴和薄层采用单元尺度近似，允许形状扩散与细尺度运动耗散。
同格断开液体共用速度，整格气体压力查询要求唯一气体归属。
可观察误差与验收要求见[实施计划](../roadmap/solver-consolidation-plan.md#精度与物理取舍)，
实测结果见[验证证据](../maintenance/validation.md#当前验证证据)。

## 自由面与压力

压力位于单元中心，速度位于格面：

```text
div((1/rho) grad(p)) = (div(u*) - target_divergence) / dt
```

不可压目标由物理连续性、移动固体和界面条件决定。
载体聚集与容量问题由一致平流、碰撞和守恒重采样处理，库存误差单独检查。

- 开放环境与真空液面给定压力，有限气腔以集总储存项加入同一压力系统。
- 压力分类、PLIC、曲率和湿区通量从实际库存与共同几何推导。
- 切割开口、界面距离和密度面系数共同用于矩阵、预条件器与最终速度修正。
- 重力覆盖具有实际质量或输运支撑的开放面，热浮力读取相同载体属性。
- 不可互溶相共享宏观压力和速度，保留材料、密度分层与界面张力。

CPU 压力工作数组采用 binary64，矩阵按面压力差计算。
PCG 在本次固定算子上迭代，并重新计算实际 `b-Ap` 检查收敛；
误差判定同时考虑求值精度，具体数值公式由求解器与测试维护。
压力和气腔交接失败保留完整原状态，并报告具体原因。

封闭气腔接触可使用共同气压参考减小相消，观察压力和相平衡计算加回参考值。
颗粒压力与阻力联立离散见[颗粒排水与压力](granular-state.md#统一排水与压力)。

### 液体与可压缩气体的能力边界

空间动量网格承载凝聚相，气腔保存组分、质量与内能。
有限气腔的体积顺应性为 `V/p_abs`（等温）或 `V/(gamma*p_abs)`（热状态），
临时压力未知量只用于当次投影，后续仍从库存、容量和内能计算实际状态。
腔内声波与空间混合层属于集总近似的支持范围之外。

液气界面压力跳跃和面速度修正为：

```text
J = p_liquid(interface) - p_gas(interface) = sigma*kappa
m_f = rho_ref / (rho_l*d_l + rho_g*d_g)
u_next = u_star - dt/(rho_ref*h)*m_f*(p_g-p_l+J)
```

气腔采用单侧界面消元，取 `d_g=0`。
同一面向液体和气体行加入对称耦合，有限气腔另加状态方程导出的储存项。
实际库存和容量功见[气体参考](gas-state.md#状态方程)。

### PLIC、表面张力与润湿

液气已解析界面使用 sharp ghost-fluid 压力跳跃，缺少压力自由度的亚格界面采用互补 CSF。
`HeightFunctionCurvature` 在开放、单调、可解析的液列上使用高度函数，
切割、多界面和其他不适用区域采用平滑法向散度近似。
曲率验证观察平面、球面、墙面接触及寄生速度，具体准入条件与镜像规则由该模块维护。

液液界面按物相对计算 balanced-force CSF，两相缺失时相应作用归零。
润湿由 Young 表面能关系 `sigma_sl-sigma_sg=-sigma*cos(theta)` 的切向梯度产生，
墙面面积来自共同切割几何。
不可互溶液体的切向滑移、乳化与液滴破碎超出当前宏观单速度模型。

GPU 扩展范围和完成条件见[后端扩展参考](../roadmap/performance-and-backends.md)，
实现状态由[当前实施计划](../roadmap/solver-consolidation-plan.md)维护。

## 固体与碰撞

Fabric 将 `VoxelShape` 采样为不可变 `CollisionField`。
`FlipCutCellGeometry` 从每格 `2×2×2` 微盒掩码派生开放体积与面开口，
压力、速度投影、液体碰撞和颗粒接触使用同一几何输入。
checkpoint 和后端交接保存原始掩码，恢复得到相同开口。

`FlipParticleCollision` 沿轨迹求最早微盒接触，去除受阻法向速度并继续切向运动。
同时接触和坐标舍入处理保持轨迹位于已确认开放空间，具体算法由碰撞模块维护。
碰撞变化挤出的物质按真实载体库存计入转移或汇。

恢复在写入前核对格长、实际载体位置、固定连通分量和液固联合容量。
几何误差按单元解析度评价，物质库存继续精确结算。

实体输入由 Fabric 每 tick 捕获 AABB、响应速度和实际位姿差。
浸没观察按开放微层的水平液层近似，实体扰动按实际位移约束附近液体速度。
返回冲量由实际写入的速度计算，体积、质量、组成和内能保持原值。

运动输入在可运动且调度到期的真实逻辑步使用一次；暂停、独立热轴和跳过的 tick 保留输入规则。
当前实体作为外部运动物体参与扰动，完整排水与双向冲量的目标见[产品路线](../roadmap/product-roadmap.md#阶段-5实体双向边界)。

## Reseed 与传输不变量

- 拆分按共同权重分配体积、质量、动量、组成和内能；合并保持材料、物相及组成兼容性。
- 目标载体须能表示守恒库存，预算不足保留完整原状态。
- 插入和提取先准备容量、热状态与事务计划，再修改全部载体列。
- 数值清理由库存归零或显式转入汇结算，微小有效库存继续保存。
