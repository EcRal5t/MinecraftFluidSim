## 后端候选接口

`FluidDomainState` 保存液体单元库存、三轴 MAC 动量、固定碰撞掩码、材料和注册表身份，以及颗粒、气体和热学能力状态。
`Layout` 绑定网格、配置、容量预算、外壳模式和各注册表指纹。
化学待处理单元和轮转位置、颗粒床层调度、待同步相变体积、世界热交换面和最近真实压力场随完整状态交接。

力学使用 `FluidStepRequest` / `FluidStepCandidate`，独立热轴使用对应 thermal request / candidate。
CPU 根据请求建立私有域，完整执行各阶段后返回后继；接管时核对后端身份、紧邻代次和布局。
成功的私有对象可交接一次；需要不可变快照时，在接管前读取候选的 `state()`。
请求中的实体输入在完整逻辑步使用一次，失败保留活动区域。

普通交接直接共享已验证 `LiquidCellInventory.Snapshot` 的不可变行，复制 MAC 动量与可变非液体列。
气体网络通过独立的 `AirNetwork.RuntimeSnapshot` 恢复，几何 frame 保持不可变共享。
`ThermalOwnerSnapshot` 携带非液体内能和热账；其 prepared 来源使普通交接沿用已验证物性状态。
冷恢复按[区域格式](region-state.md)检查全部库存、容量、状态方程和审计后建立域。

Courant 超限或气腔压力求解未收敛时，后端从原始请求细化完整力学步。
细化保持总推进时间、相变预算和外部输入的一次提交规则。
`mechanicalResolution()` 报告细化次数、累计预留子步和原因，`StepStats.substeps` 报告完成子步。
调度和成本判定见[验证指南](../maintenance/validation.md#performance)。

## 单元库存与 MAC 动量

`LiquidCellInventory.Stock` 是液体唯一库存记录，键为 `(cell, material, supportMask)`。
`supportMask` 标识固定碰撞微盒图中的开放连通分量。
记录保存归一化体积 `SignedDyadic`、整数 `massUnits`、不可变物种组成、总内能 `U` 和指示剂状态。
同格不同材料分别保存记录，物质身份和质量余量随记录输运。

MAC 格面保存 SI 动量 `kg·m/s`。
`CellMacStage` 从单元整数质量构造相邻单元各半的双控制体积质量，再以 `u=P/m` 派生速度。
固定碰撞、活动颗粒、床层和连续固相共同决定可用容量与开放面。
纯液体与含固相区域使用相同液体库存、MAC 动量、黏性和输运职责链。

`CellMomentumTransport` 将实际整数质量通量提升到同一 MAC 双控制体积。
`MacMomentumAdvection` 采用隐式中点形式推进动量；共享质量输运保持均匀平移，并控制无外力平流的动量与动能误差。
双控制体积质量变化采用平方根质量中点，中心通量允许未解析湿干面上的局部速度超调，宏观评价采用动能、位移与旋转衰减。
压力、黏性、重力、浮力和实体作用更新速度后，按同一格面惯性发布动量。
表示能力和宏观验收要求见[当前实施计划](../roadmap/solver-consolidation-plan.md#精度与物理取舍)。

液体点样本按需要从库存和 MAC 派生，用于旧观察接口、显示或一次初始输入。
后端交接、热能和存盘均读取单元记录与格面动量。
恢复后 `ensureInventoryGrid` 重建库存派生量，`ensureGrid` 还准备所需几何与速度工作区。

### 液体黏性应力

`LiquidViscosityStage` 使用 `ViscousMacDiscretization` 的 Newtonian 应力离散。
`ViscousStressOperator` 求解质量归一化的后向 Euler 系统，黏度调和平均，墙面冲量独立记账。
颗粒和沉积通过耦合项影响运动，液体黏性算子保持一致。

### 时间步与 CFL

`timeStep` 是完整逻辑步的物理时间。
液体采用每个固定开放分量的真实供体总出流份额决定时间步，初估包含重力预测，投影后按同一孔口重新核对。
颗粒保留球体扫掠与固定几何所需的位移限制。
细化维持总时间与库存审计，wall-time pacing 调整逻辑步的调度间隔。

## 几何与单元输运

PLIC 从单元体积、邻格比例和固定碰撞连通分量重建。
`MicroBoxPlaneVolume`、`GasGeometryOverlap` 使用浮点积分，`PlicPlaneOffset` 求平面偏移。
几何误差按网格解析度和浮点误差评价；实际库存使用整数与精确数量结算。

`ConservativeLiquidFlux` 将固定开放连通分量建为同一稀疏分配图，邻格连边来自实际开放微面。
原始液体库存与有限气腔的体积提议共用供体和接收孔隙容量。
压力的固定孔口散度保持与流向无关，颗粒相对运动以单元 CIC 体积导数显式耦合。
物质输运读取有界实际流体孔口，由最终 MAC 速度选择真实供体，采用 `Q_liquid = theta_donor * A_pore * u * dt / h`，互补份额属于气相。
气腔储容提供混相压力的一阶预测，实际干容量由最终液体与固体库存派生。
完成分配后汇总单值共享面通量，`plan` 与固体挤排入口 `planDisplacement` 共用这套规则。
`LiquidCellInventory.planTransport` 按同一通量分配材料体积、质量、物种和内能，余数留在明确的来源或接收记录。
固体新增占容沿用共同残量网络，允许沿反向余量撤销并重新分配此前通量。
有限气腔的预测体积作为同一分配图中的气体供体，与液体联合满足未来真实孔容；气腔可压缩份额及实际热功结算见[气体参考](gas-state.md#压力与热耦合)。
实际排水必须经过开放通路并满足接收容量。
本步初态中气相不可达的内部饱和分量保持饱和，气相沿物理一跳可达的分量允许形成实际界面；共同分配图同时满足这些接收要求与未来孔容。
最终速度完成 Courant 检查后，一次分配材料整数份额；液体库存、MAC 动量及气腔后继在全部来源与物性预检后提交。

未解析液滴和薄层采用单元尺度形状，允许细尺度耗散与形状扩散。
同格断开液体采用共同 MAC 速度近似；同格独立气腔按实际接触面分别归属。
验收检查体积、整数质量、组成、宏观位移、动量、能量和恢复，具体场景见[验证指南](../maintenance/validation.md)。

## 自由面与压力

`PressureFaceGraph` 按固定开放微面与活动颗粒相对运动组装体积散度 `C`，压力作用采用同一矩阵的转置。
纯液体直接使用固定孔口散度；含颗粒时加入同一单元 CIC 导数及液体采样的局部稀疏耦合，方程见[颗粒参考](granular-state.md#统一排水与压力)。
每个 MAC 面的惯性来自相邻单元各半的实际整数质量，压力算子为 `C M⁻¹ Cᵀ` 与气体储容、颗粒响应之和。
共享面可同时连接多个独立气腔，其份额由同代几何中的开放微面决定。

满液开放分量参加容量约束，部分占液分量读取所接触气腔的压力及单元尺度静水、毛细压力修正。
同格多个满液分量共用单元压力，断开流路仍由固定碰撞开口限制。
浮点几何分辨率内、无有限气体库存的满液微隙继续使用容量方程，源项包含真实剩余容量，库存体积完整保留。
有限气腔的正体积和顺应性由实际库存、容量、温度与热容的状态方程曲线派生，采用共同压力算子的有界 Newton 迭代。
环境和真空采用对应状态方程压力。
仅含不可压缩满液分量的封闭连通域固定一个压力参考值。

压力工作区、预条件器和求解结果属于本步派生数据。
CPU 使用 binary64 压力数组，`PressureLinearSolver` 和 `PressurePreconditioner` 提供共同 PCG 与不完全 Cholesky 预条件。
求解后核对实际残差；压力和气腔后继失败报告具体原因并保留完整原状态。
颗粒压力与阻力离散见[颗粒参考](granular-state.md#统一排水与压力)。

### PLIC、表面张力与润湿

曲率、界面张力和压力几何读取同一单元库存。
`HeightFunctionCurvature` 在开放、单调的可解析液列上使用高度函数，其余情况采用平滑法向散度近似。
液液界面按物相对计算 balanced-force CSF；润湿采用 Young 表面能关系，面积来自共同切割几何。
宏观单速度近似的支持范围包括分层、惯性和可解析旋转；细尺度乳化、液滴破碎与腔内声波受当前空间模型限制。

## 固体与碰撞

Fabric 将 `VoxelShape` 采样为不可变 `CollisionField`。
`FlipCutCellGeometry` 从每格 `2×2×2` 微盒掩码派生开放体积、连通分量与面开口。
单元库存、压力、液体输运和颗粒接触读取同一几何输入；checkpoint 和后端交接保存原始掩码。

碰撞编辑批量规划被挤出的实际液体与固体库存，联合核对开放支撑、接收容量、组成、动量和内能后提交。
液体通过固定面开口与容量约束保持在开放空间，活动颗粒通过球体接触响应处理恢复和摩擦。

实体输入由 Fabric 每 tick 捕获 AABB、响应速度和实际位姿差。
浸没观察按开放微层液层近似，实体扰动约束附近 MAC 格面速度，再按实际格面惯性发布动量与返回冲量。
运动输入在调度到期的真实力学步使用一次。
完整双向实体作用的产品范围见[产品路线](../roadmap/product-roadmap.md#阶段-5实体双向边界)。

## 物质交接不变量

- 同一共享通量搬运体积、整数质量、物种与携带内能，MAC 动量读取实际质量通量。
- 来源、目标开放支撑、联合容量、注册表和账本在首次写入前完成预检。
- 合并汇总同键记录，整数与浮点存储余数按对应库存和热账结算。
- 插入、提取、反应、相变、碰撞编辑与恢复共用单元库存提交契约。
- 微量有效库存持续保存，数值清理由库存归零或显式源汇操作结算。
