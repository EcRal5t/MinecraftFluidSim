# 流体离散与后端字段参考

本文维护单元库存、MAC 动量、共同几何与压力的离散契约。职责链见[设计书](system-overview.md)，交付状态见[实施计划](../roadmap/solver-consolidation-plan.md)，性能与流程证据见[验证指南](../maintenance/validation.md)。

## 后端候选

`HostFluidState` 负责初始化、世界编辑与恢复，Vulkan 负责连续的机械、热学与化学推进。`FluidDomainState` 保存同代液体参考体积、整数质量、物种、内能、MAC 动量、固定几何，以及气体、颗粒、固相与有限热载体状态。

每次请求在私有候选中准备完整后继，成功后一次采用；失败保留已提交状态与原始原因。颗粒路径需要细分时从原请求重新准备候选，累计时长与外部输入只提交一次。相变登记的待机械同步格随状态保存，由后续机械步完成占容与动力交接。设备工作区、预条件器与几何缓存都是派生数据。

## 单元库存与 MAC 动量

`LiquidCellInventory.Stock` 以 `(cell, material, supportMask)` 为键，保存参考体积 `SignedDyadic`、整数质量、物种与内能。实际液体占容由参考体积、局部绝对压力与统一有限压缩性派生，公式见[共同液气状态方程](gas-state.md#共同液气状态方程)。

`SpatialGrid` 统一提供单元坐标、六邻接与 MAC 面：相邻块两侧引用同一个面，输运、压力、黏性、扩散与导热都读取这份邻接。

<a id="两级空间分辨率"></a>
### 空间分辨率

仿真统一使用 0.5 m 均匀格长与稀疏 8³ 计算块，端部块按域外形裁剪。库存、MAC 面、压力、热接触、颗粒与存档都以此格长组织，存档保存块地址并在恢复时重建紧凑索引。多重网格只作为压力求解的预条件器。

### 面动量与机械能

MAC 面保存 SI 动量，面惯性由两侧各半格的实际液体与气体质量构成，速度等于动量除以惯性。固定微盒开口、颗粒与实体占位决定可用面，压力与质量输运读取同一面关系。

供体的出流与保留份额共同分配整数质量、物种与质量余量：参考能随物种分配，显热随质量与供体温度分配，最大份额承接数值余差。实际液气面质量通量进入 MAC 双控制体，按供体速度搬运动量，混合速度由接收质量计算，面混合热按两侧质量分配到液气内能。

机械能交接汇总格面动能、实际路线的重力势能、液体弹性能、气体压缩功与颗粒动能和位置变化。受共同压力、输运或颗粒接触连接的机械体统一结算，按材料热容分配吸热、按可用显热分配供能。黏性、Darcy 阻力、壁面停止、动量混合与运动物体外功各记一次，存储舍入与实际机械能变化分别归约。

### 液体黏性应力

设备黏性阶段采用 Newtonian 应力离散，黏度由材料温度与组成决定（[VulkanLiquidViscosity](../../gpu-kernel/src/main/java/mmm/gpu/VulkanLiquidViscosity.java)）。设面质量 `m_f`、本步原始耦合权重之和 `A_f`，面接受系数：

```text
β_f = m_f / (m_f + A_f)
```

一条应变使用参与面中最小的 `β_f`，墙面与运动接触使用本面 `β_f`。接受后的耦合权重小于面质量，速度更新保持非负的动能混合权重；内应变使用互反冲量，动能变化与接触功沿同一系数结算为热。

普通固壁统一无滑移。每个湿壁片的切向导通量：

```text
G = μ A_wet / δ
δ = min(L, V_column / (2 A_wet))
```

`A_wet` 包含实际孔隙率，`δ` 是同一切向微盒柱中连通液量的等效层深，`L` 为该柱在本格内的开放长度：满格壁距为 `h/2`，半格通道为 `h/4`。导通量平均分给两侧 MAC 自由度，墙反冲按实际冲量登记，耗散动能进入相邻液体内能；运动物体使用相对速度。湿壁几何随同代库存派生。

通道截面建议至少跨四格（默认格长约 2 m）。更窄构型仍呈现压差输运，速度剖面与压降为粗网格近似。湍流与细管剖面需按工艺收益另行建模；[薄壁管道](physical-pipes.md)使用独立的有限管腔。

### 时间步与库存限流

液体与气体共用有限驻留时间的相邻格输运。每相以库存体积 `V` 与六面扫掠需求之和 `D` 求驻留系数 `V/(V+D)`，各出流按同一系数接受，保留量为 `V²/(V+D)`。这是供体流出的一阶隐式近似：高速流在粗格上传播偏慢、偏扩散，请求的物理时长保持不变。单面扫掠深度最多一格。

移动固体使孔容归零时，末份库存与内能沿开放面完整排出，接收格按目标姿态的孔容选择；排水受阻时按请求时段细分姿态。

## 几何与单元输运

每格固定碰撞保存八个微盒，支持一个连通开放空间；几何孔容再扣除活动颗粒、床层、连续固相与运动实体占位。

GPU 以单轴平面重建液体形状：取体积分数梯度绝对值最大的轴（平局取重力轴），沿该轴把开放微盒分为两层，按两层截面积直接求平面位置。微盒湿体积由一维区间长度计算，单侧相接触由矩形裁剪计算。单轴重建省去体积求根与多边形剪裁，代价是自由面阶梯化、斜向面积偏差与粗尺度形状扩散。

每个面的扫掠棱柱与上风 PLIC 平面、开放微盒求交，得到同一面上的液体与气体体积；两相出流分别受同代库存约束，未转移份额留在供体。开放域外侧使用环境状态，密封外侧由固定几何阻断。运动体关闭孔容时，先按源姿态结算压力与表面力，再沿源开放面的连通关系把液气库存重映射到目标孔容；无可达接收空间时保留原候选并报告受阻。气体输运与状态方程见[气体状态](gas-state.md)。

## 自由面与压力

共同压力以开放面散度及其转置作用于同一面惯性。预测速度包含重力、黏性、表面作用与当前状态方程压力，半隐式压力解给出面速度，液气接受量再确定实际速度与面通量。含活动颗粒时，同一压力方程加入颗粒有限质量与阻力耦合，见[颗粒统一压力](granular-state.md#统一压力)。

- 压力状态是绝对压力：PCG 求得增量，施加冲量前按非负绝对压与状态方程上限截取；查询可输出绝对压或表压。
- 开放外侧施加环境压力与对应半控制体惯性，密封面无流量。
- 压力增量、矩阵与归约使用双精度；残差按开放格散度与储容归一化，在一个有界 PCG 批次内完成并提交真实残差，预算由 `FluidStepBudget` 维护。
- 有限压缩性承担接收库存产生的体积偏差；压力预测、有限步交接与局部状态方程采用算子分裂，界面扩散与剩余压力误差按粗格尺度解释。

### 表面张力与润湿

表面张力、曲率与润湿读取同代体积分数与共同接触几何；液液表面力按材料对定义，壁面接触角影响界面法向。粗格曲率与接触角存在明显几何误差，支持范围是可解释的毛细与润湿趋势。可解析的分层、惯性与旋转沿 MAC 运动描述，细尺度乳化、液滴破碎、湍流与同面气液逆流属于近似范围。

## 固体与碰撞

Fabric 把选区内部及紧邻外侧面的 `VoxelShape` 采样为不可变 `CollisionField`。[FixedGeometrySnapshot](../../solver/src/main/java/mmm/fluid/FixedGeometrySnapshot.java) 保存每格 `2×2×2` 微盒掩码、外邻固体微面、开放体积、面开口与墙面积，外侧面按内外两侧真实开口计算通流。宿主编辑与 GPU 流动读取同一份快照，[FlipCutCellGeometry](../../solver/src/main/java/mmm/fluid/FlipCutCellGeometry.java) 是其可写编辑视图。checkpoint 保存内部掩码、外邻面与筛面。

碰撞编辑批量规划被挤出的液体与固体库存，联合核对开放支撑、接收容量、组成、动量与内能后提交。

实体按 AABB、响应速度与实际位姿差输入，细分时按源和目标姿态插值，新增或移除实体的体积在请求时段内连续交接，占容差进入共同压力与机械功账。双向实体作用的产品范围见[产品路线](../roadmap/product-roadmap.md#阶段-5实体双向边界)。

## 物质交接约定

- 同一共享通量搬运体积、整数质量、物种与携带内能，MAC 动量读取实际质量通量。
- 来源、目标开放支撑、联合容量、注册表与账本在首次写入前完成预检。
- 合并汇总同键记录，整数与浮点余数按对应库存与热账结算。
- 注入、抽取、反应、相变、碰撞编辑与恢复共用单元库存提交契约。
- 微量库存持续保存，清除只通过库存归零或显式源汇操作。
