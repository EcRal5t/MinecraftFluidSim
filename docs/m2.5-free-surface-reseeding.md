# M2.5 分数自由表面与守恒重采样

本文冻结 M2.5 的活动数值定义、守恒边界和自动门。第二增量已经把 runtime-only cut-cell 接入 CPU 权威核心；真实 Minecraft partial-shape smoke 签收前仍不宣告 M2.5 关闭。代码入口见 [`maintenance-routing.md`](maintenance-routing.md)。它不改变 `takeover-journal v1`、`region-state v1` 或 protocol v1，也不把 GPU probe 变为正式后端。

## 状态分层

- 物理真值仍是全部 marker `particleVolume` 的精确和。每格和只是把同一账本按 marker 当前所在格分组，不能从平滑 `volume[]`、PLIC 平面或渲染等值面反推总水量。
- 压力流体格仍严格由 `markerCount > 0` 决定。PLIC 不扩张或删除压力相区。
- PLIC 液相分数、平面法向、ghost-fluid `theta`、cut-cell 固体体积分数和共享面开口都是数值离散；它们不进入存档真值。
- 客户端仍使用 density + marker + binary-full-solid 重建。此次没有更改 payload、marker mask 或 mesh 阈值；Minecraft 自身仍渲染 partial block，客户端尚不把 2x2x2 runtime mask 复制成第二套水量或存档状态。
- reseeding 是 marker 表示的确定性拓扑维护。它只重新分配已有 `particleVolume`，不创建物理水源或汇。

## PLIC 与自由表面压力

`FlipFreeSurfaceGeometry` 在每次 P2G 重建时先计算：

```text
f_i = clamp(sum(particleVolume of markers whose containing cell is i) / openVolume_i, 0, 1)
```

对 marker 占据且邻接空气的格，用 `-grad(f)` 得到从液体指向空气的法向；solid 和域外邻居采用本格分数外推，避免把墙误当成自由表面。梯度退化时按实际空气邻居方向确定法向，完全退化才固定回退到 `+Y`。随后在单位立方体中求平面

```text
n dot x <= alpha
```

使被截取体积分数等于 `f_i`。立方体截取体积使用确定性的解析 inclusion-exclusion 公式，`alpha` 用固定 32 次二分求解。

流体格中心到相邻空气方向的平面交点给出 `theta`。由于长期不变量要求任意 marker 占据格都参与压力，即使极薄液层的 PLIC 平面位于格心以下，也不能把该格重新分类为空气。因此使用：

```text
theta = clamp(center-to-plane distance / h, 0.05, 1.0)
```

满格紧邻空气时界面位于共享面，明确取 `theta = 0.5`。`theta=0.05` 是已公开的条件数正则化，不代表格心以下界面被精确解析。0.25 格薄层门只要求守恒、有限残差和无爆发速度；定量静水压力门使用界面位于格心以上的 0.60、0.75 和 1.00 格液位。

流体—空气面的压力矩阵对角贡献与投影梯度严格配对；`a_face` 是同一共享 cut-cell 面开口：

```text
A_ii += a_face / theta
u_face -= dt / (rho h) * (p_air - p_i) / theta
p_air = 0
```

流体—流体面系数为 `a_face`，完全封闭 solid 面为零通量。散度也按同一个 `a_face * u_face` 求通量；投影更新的是开放部分的面速度，因此梯度本身不再乘一次面积。压力矩阵保持共享面对称，对角预条件器使用同一组系数，避免 RHS、求解矩阵、预条件器和投影各自解释边界。

## MAC 速度有效域与自由面外推

P2G 没有覆盖、且不属于压力相边界的空气 MAC 面没有物理上的“零速度”含义。旧 G2P 直接把数组的初始零值纳入三线性插值，会按缺失角点的数量稀释 PIC 速度和 FLIP 增量；体积仅 0.125 格的孤立水滴因此在重力下被持续人工减速。这是数值离散错误，不是黏度、空气阻力、渲染插值或调度降频。

`FlipVelocityExtrapolator` 现在以 `markerCount > 0` 压力相两侧且 cut-face 开放的 MAC 面为有效种子，在压力投影前和投影后分别向开放空气面确定性外推两层。两层覆盖 marker 三线性 G2P 的横向对角 stencil；封闭 cut-face 和域外面不参与。投影前的外推状态作为 FLIP 旧速度，投影后的外推状态作为 PIC 新速度与 FLIP 差分来源。G2P 随后只对有效面权重重新归一化，因此不会从未定义空气面制造阻尼，也没有增加经验重力或强制速度。

确定性门使用 `h=0.5`、`dt=0.05` 的 0.125 格孤立水滴，在进入 CFL 二次子步前运行 8 步。体积质心下降必须匹配半隐式欧拉离散弹道

```text
fall(n) = g * dt^2 * n * (n + 1) / 2
```

当前实测为 `0.88290024` 格，对应解析离散值 `0.88290006`；marker 速度为 `3.924`，精确 `particleVolume` 总和不变。客户端 200 ms 插值仍只影响观感，不反写这条物理轨迹。

## Runtime cut-cell solid

每个 0.5 方块 solver cell 在运行时持有 `2x2x2` occupancy byte；也就是每个 Minecraft 方块以 `4x4x4` 微体素保守采样当前 `VoxelShape`。格开放体积按 8 个 bit 计数，内部共享面按双方边界上的 4 对微面计算开放面积：只有两侧对应微体素都开放时该微面才通流。域外面关闭。该表示使常见 stair、post、pane 等形状在不把整个 solver cell 封死的情况下进入有限体积压力离散。

marker 仍是点携带的体积 parcel。逐轴 advection 把位移分成不超过微体素宽度四分之一的扫掠段；命中 occupied microcell 时只清零并截断该轴法向，另外两轴继续。完全 solid solver cell 仍保留既有 `0.45h` 接触半径。reseeding 的合并质心和 split 候选都经过 runtime occupancy 校验；不安全合并会计入 `reseedGeometrySkipped`，split 可退回同点等分而不改质心。

方块碰撞变化只按 marker `particleVolume` 结算：先移除中心落入新占据微体素的 marker，再按精确格内 marker 和强制满足 `exactVolume <= openVolume`，多出的体积同样从 marker 账本取出并交给附近开放容量恢复。平滑 density 不参与挤水。`/realwater status` 报告当前 partial/full collision cell 数，便于真实形状 smoke。

### `region-state v1` 兼容语义

cut-cell byte 是从当前世界重建的运行态缓存，不写入 v1。checkpoint 的原 solid slice 只把 `mask == 0xff` 写为 1；partial cell 写为 0，避免旧 reader 把其中合法 marker 判作“位于完整 solid”。`restoreSolver` 已有的 `collisionRefreshRequired` 门保持不变：metadata-only 恢复后，在快照、实体采样或 step 前同步读取完整 chunk 的当前 `VoxelShape` 并恢复 cut-cell。若 chunk 或闭合边界不可用，区域仍为 `UNLOADED`，不能拿 binary fallback 步进。相同形状重采样不得再次挤出 marker；自动门覆盖这一语义。因此没有存档迁移，也没有 silent transient geometry 参与恢复物理。

## 守恒 reseeding

`FlipParticleReseeder` 每个完整物理 step 只运行一次，位置在全部 CFL 子步和粒子碰撞之后、最终网格重建之前。顺序固定为先 merge、后 split，让过密格先释放 marker 硬预算。

### Merge

- 只有单格 marker 数 `>12` 时触发，并降到 8 个。
- 从原始 marker 顺序中的第一个代表开始，用确定性的 farthest-point 选择保留 8 个空间代表；其余 marker 合并到最近代表。
- 合并体积为两者 `particleVolume` 之和；位置和速度按体积加权，因此保持体积质心与动量。
- 所有合并都局限在原格；binary full-solid 邻面下安全半空间对凸组合封闭，partial cut-cell 下则显式复核合并质心。落入 occupied microcell 的候选不执行，保留原 marker 并记录几何跳过。

### Split

最低 marker 数只取决于该格 marker 精确体积和：

| 精确格体积 | marker 下限 |
|---:|---:|
| `< 0.125` | 1 |
| `[0.125, 0.5)` | 2 |
| `>= 0.5` | 4 |

每次选择该格体积最大的 marker 等分。两个子 marker 继承相同速度，并优先沿可用空间最大的轴作对称位移；域边界使用 `0.45h` 接触半径，完整 solid 邻面使用与 CCD 一致的 `0.451h` 安全内缩，两个候选还必须都落在 runtime cut-cell 的开放微体素。若候选不安全或原 marker 正好位于所有可行区间的角点，只能在同一点等分，仍保持账本并等待后续速度场分离，不能为了“看起来均匀”移动体积质心。

split 前同时检查实例数组容量和 `maximumParticleCount`。预算不足只增加 `reseedBudgetSkipped`，保留全部旧 marker 与水量。几何退化单独记为 `reseedGeometrySkipped`。`/realwater status` 在最近一步发生 merge/split 或跳过时显示这四项诊断和本步双精度 ledger 误差。

Java float 不能保证任意非二进制体积在减少 marker 数后逐 bit 保持同一个双精度求和值；验收边界因此是每次 reseed 的双精度 marker 和误差 `< 2e-7`，而二进制初始化体积的 split/merge 要求误差为零。物理真值仍是操作后的 marker 数组和，不引入 residual density 或第二套水量账本。

## 自动门与当前结果

```powershell
./gradlew.bat runFlipFreeSurfaceValidation runFlipReseedingValidation `
  runFlipCutCellValidation runFluidCutCellShapeValidation --offline --no-daemon
```

`runFlipFreeSurfaceValidation` 覆盖：

- 轴向、反向、二维斜面和三维斜面 PLIC 体积分数反演，误差 `<2e-6`；
- 0.60、0.75、1.00 格非整数自由面静水柱，压力相对误差 `<2e-4`、marker 寄生速度 `<2e-4`；
- 0.25 格格心以下薄层连续 40 步稳定；
- 0.125 格孤立水滴连续 8 步匹配半隐式欧拉重力位移与速度，且 marker 账本不变；
- 固定阶梯斜面 300 步下滑、体积守恒且 marker 不进入 solid。

`runFlipReseedingValidation` 覆盖：

- split/merge 的体积、动量和体积质心闭合，非二进制体积误差 `<2e-7`；
- marker 硬预算耗尽时无损跳过；
- 同输入逐 bit 确定性；
- 5,000 步三层剪切静水：最终 1,512 marker、192 个 marker 格、`y=1..3`，半格以上每格至少 4 marker，最大 12；累计 merge/split 为 93/69；
- 5,000 步动态 dam-break：最终 947 marker、148 个 marker 格、`y=1..3`，半格以上每格至少 4 marker，最大 11；累计 merge/split 为 2,336/1,555；两者总体积不变且无预算/几何跳过。

`runFlipCutCellValidation` 与 `runFluidCutCellShapeValidation` 覆盖：

- 1/8 格开放体积与 1/4 共享面开口，双方读取同一 face weight；
- partial wall 扫掠碰撞只截断法向，切向位移和速度不变；
- marker 中心占据和合并后单 marker 超容量两种 exact `particleVolume` 挤水；
- `region-state v1` 只保存完整 solid，恢复后相同 runtime mask 重采样为零二次挤水；
- partial obstacle 600 步 PCG 有限、marker 不穿入 occupied microcell、总 marker 水量不变；
- Minecraft slab/stair/post/pane `VoxelShape` 到每方块 `4x4x4` 保守采样。
- 文档固定的 24×16×24 demo stair 位置会挤出并完整恢复 6 格 marker 水量，marker 预算不受限。

活动核心回归另跑 `FlipFluidDomainValidation` 与 `FlipFluidSurfaceDiagnostic`；后者 160 步保持 `enclosed<.5 == 0`。动态 marker 与 runtime-only solid fallback 已通过 region-state、manager、lifecycle、boundary 和 protocol 回归。GPU shader 没有接入本增量；M1 的历史探针仍只读、可选，主 Mod CPU 结果是规范。2026-08-19 第一次真实 stair/pane smoke 已确认形状分类、有限 PCG 与运行稳定，但 exact 水量从 2,592 降到 2,587，且随后手动 refresh 的零变化覆盖了当次 collision 诊断。状态现在保留最近一次非零碰撞变化，仍需按 [`m2.5-cut-cell-smoke.md`](m2.5-cut-cell-smoke.md) 的固定坐标复核 exact 水量后才能关闭 M2.5。
