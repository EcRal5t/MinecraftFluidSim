## 一、背景与当前状态

当前工程处于 `26.2` 分支，提交基线为 `6e1f84a Record M2 persistence acceptance` 及 `9638353 Add atomic persistent fluid regions`。M0（世界恢复事务）、M1（GPU 能力与变密度探针）、M2（多区域管理、控制器闭合扫描、`region-state v1` 原子持久化与休眠）均已完整闭环并经受实机与自动化验证。

本阶段进入 **M2.5（几何自由液面与守恒重采样）**。当时的产品路线与维护路由现已归档为 [`../legacy-long-term-roadmap.md`](../legacy-long-term-roadmap.md) 与 [`../legacy-maintenance-routing.md`](../legacy-maintenance-routing.md)；M2.5 是 M3（变密度与多流体连通器）的关键前置物理基石。

### 必须坚守的物理与架构红线

1. **物理真值**：Marker 的 `particleVolume` 及其精确总和是水量的唯一物理真值。平滑 density/`volume[]`、截断界面分数 $\theta$ 和渲染 isosurface 体积均属数值重建或视觉呈现，**严禁从平滑密度中反向推断、猜测、补造或扣减水量**。
2. **离散与边界**：压力流体格依然由 `markerCount > 0` 严格决定；固体碰撞仅约束法向速度与穿透，切向沿墙与沿墙角滑移必须完全自由。
3. **渲染隔离**：客户端基于 density + marker + solid 提取等值面，Marker 是浅水可见的必要种子；严禁用渲染厚度补丁掩盖底层物理 Marker 结构的退化。
4. **状态与持久化兼容**：`FlipParticleState` 和 `region-state v1` 已天然支持可变数量与非均一体积的 Marker 列表。重采样过程严禁破坏 `particleVolume` 账本闭合，严禁突破单域 / 总服务器 Marker 硬预算。
5. **分步推进**：不跳步、不混淆。先独立建立数学模型与固定种子验证，再接入活动 `FlipFluidDomain`，最后跑通全量回归。

### Phase 1: 几何分数自由液面与自由表面压力权重 (Fractional Free Surface)

#### 1.1 问题分析与物理目标
目前 `FlipFluidDomain` 中，空气格压力简单作为 $p_{air}=0$ 放在相邻空气格中心（距离 $\Delta x$ 处），导致自由表面处的压力梯度离散误差为一阶大步长误差（对非满格自由表面，等效于将水面拔高或压低到整格网格面）。这使得：
- 任意液位静水柱底部压力只能呈现阶梯状，无法准确反应 $\rho g h_{actual}$；
- 自由表面表层粒子容易受到不均匀压力脉动而发生晃动或虚假压缩；
- 阻碍了 M3 变密度在界面距离加权通量下的精确静水平衡。

#### 1.2 数学模型设计 (Gibou-Fedkiw / Batty-Bridson Ghost Fluid Method)
设流体格 $i$ 与相邻空气格 $j$ 之间，实际自由液面距离流体格中心的无量纲距离分数为 $\theta_{i,j} \in [\theta_{min}, 1.0]$（实际物理距离为 $\theta_{i,j} \Delta x$），其中 $\theta_{min} = 0.05$ 作为正则化下限，防止矩阵条件数恶化。在自由液面处 $p=p_{atm}=0$。

1. **界面距离分数 $\theta_{i,j}$ 的几何测定**：
   - 沿法向或各轴向，根据流体格内粒子的局部几何高度/包围盒或由精确占据体积 $f_i = \text{clamp}(V_{exact,i}, 0.01, 1.0)$ 结合相邻空气拓扑派生出 $\theta_{i,j}$；
   - 垂直方向（Y轴向上出水面）：$\theta_{i, top} = \max(\theta_{min}, \min(1.0, \frac{y_{max} - y_i}{\Delta y}))$ 或根据格内体积 $f_i$ 确定有效高度；
   - 水平方向（X/Z轴侧向接触空气）：根据粒子侧向分布或局部自由表面法向插值确定 $\theta_{i, side}$。
2. **压力矩阵 (Poisson 算子) 修正**：
   - 对于流体格 $i$ 的空气邻居 $j$：
     标准离散中的通量项为 $\frac{p_i - 0}{\Delta x^2}$（贡献对角项 $+1$）；
     分数离散中的通量项修正为 $\frac{p_i - 0}{\theta_{i,j} \Delta x^2}$（贡献对角项 $+\frac{1}{\theta_{i,j}}$）。
   - 该修正保持了离散 Laplacian 矩阵的**对称正定性 (SPD)**，PCG 求解器收敛速度与稳定性不受影响。
3. **速度投影 (Velocity Projection) 修正**：
   - 跨流体-空气交界面的面速度更新：
     $$u_{face}^{n+1} = u_{face}^* - \frac{\Delta t}{\rho_0} \cdot \frac{0 - p_i}{\theta_{i,j} \Delta x} = u_{face}^* + \frac{\Delta t}{\rho_0 \Delta x} \cdot \frac{p_i}{\theta_{i,j}}$$
   - 保证流体表面精确承受真实几何高度的静水压强与重力加速度平衡。

#### 1.3 独立验证门 (Standalone Validation Suite)
新建 `FlipFluidFreeSurfaceExperiment.java` / `FreeSurfaceValidation.java`，包含以下确定性测试：
- **任意液位静水柱 (Continuous Hydrostatic Column)**：测试 $h = 0.25, 0.50, 0.75, 1.33, 2.50$ 等不同非整数格高下的底部压强，验证其与解析解 $\rho g h$ 相对误差 $< 1.0\times 10^{-4}$，且垂直速度漂移 $< 1.0\times 10^{-5}$。
- **薄水层平衡 (Thin Layer Puddle)**：0.25 格深度静水不发生跳动或爆发展开。
- **斜坡重力下滑 (Gravity Flow on Slope)**：台阶与斜面上的水流平滑流下，自由表面法向无异常反弹。

### Phase 2: 严格守恒 Marker 重采样 (Conservative Reseeding)

#### 2.1 问题分析与物理目标
在当前的 PIC/FLIP 循环中，由于流动变形、拉伸和重力沉降，Marker 会在部分区域过度聚集（如水底或墙角），而在流动拉伸区或表层变稀。
- GPU 长测（36,000 步）和 CPU 表面分析表明：在 5,000 步之后，尽管总物理体积 `particleVolume` 恒定不变，但部分网格内 Marker 计数降为 0 或聚集为单颗高密度团，导致压力网格出现空洞或表层坍缩。
- **必须通过守恒重采样（Reseeding）恢复均匀的 Marker 空间分布**。

#### 2.2 算法规则设计 (Merge & Split with Strict Invariants)

| 操作 | 触发条件 | 目标与守恒规则 |
|---|---|---|
| **Split (分裂)** | 网格内流体体积 $V_{cell} \ge 0.25$ 但粒子数 $N < N_{min}(V_{cell})$（如仅 1~2 个粒子），或单粒子体积 $V_p > 1.5 \times V_{standard}$ | 1. **体积守恒**：$V_A + V_B = V_p$（精确相等，$\Delta V \equiv 0$）<br>2. **动量守恒**：$\mathbf{u}_A = \mathbf{u}_B = \mathbf{u}_p$（保证 $V_A \mathbf{u}_A + V_B \mathbf{u}_B = V_p \mathbf{u}_p$）<br>3. **质心守恒**：$\mathbf{x}_A = \mathbf{x}_p + \boldsymbol{\delta}, \mathbf{x}_B = \mathbf{x}_p - \boldsymbol{\delta}$，满足 $\frac{V_A \mathbf{x}_A + V_B \mathbf{x}_B}{V_p} = \mathbf{x}_p$<br>4. **几何安全**：$\boldsymbol{\delta}$ 沿局域未饱和方向微小位移，且两子粒子均满足距固体 $\ge 0.45h$ 接触约束。 |
| **Merge (合并)** | 网格内粒子过密 $N > N_{max}$（如 $>12$ 颗/格），或两粒子距离 $d < d_{min}$ 且单体积较小 | 1. **体积守恒**：$V_{merged} = V_1 + V_2$（精确加和）<br>2. **动量守恒**：$\mathbf{u}_{merged} = \frac{V_1 \mathbf{u}_1 + V_2 \mathbf{u}_2}{V_{merged}}$<br>3. **质心守恒**：$\mathbf{x}_{merged} = \frac{V_1 \mathbf{x}_1 + V_2 \mathbf{x}_2}{V_{merged}}$<br>4. **几何安全**：合并后位置自动通过 `constrainToSolidFaces` 修正。 |

#### 2.3 预算与调度约束
- **硬预算保护**：分裂操作前必须检查 `particleCount + 1 <= maximumParticleCount`。若预算已耗尽，则跳过分裂并记录诊断，绝不抛出未经处理的越界异常，绝不丢失已有粒子。
- **频次控制**：重采样作为低开销的拓扑维护操作，可在每个完整 step 结束时执行（或每 $k$ 步执行一次），仅扫描偏离阈值的网格，保持毫秒级性能开销。
- **完全确定性**：遍历顺序固定（$z \to y \to x$），粒子配对与分裂扰动方向使用伪随机固定种子或主轴方向，保证跨步可复现。

#### 2.4 独立验证门 (Reseeding Validation Suite)
新建 `FlipFluidReseedingValidation.java`：
1. **百万次连续 Split/Merge 账本测试**：随机执行 $10^6$ 次分裂与合并，验证总 `particleVolume` 浮点误差累积 $< 1.0\times 10^{-7}$，总动量误差 $< 1.0\times 10^{-6}$。
2. **长时间静水与剪切流 Marker 密度稳定性**：运行 5,000 ~ 10,000 步闭合容器静水与波浪流动，检查：
   - 每格 Marker 数量稳定维持在 $[4, 12]$ 区间；
   - 无任何内部假空泡（`enclosedLow` 始终为 0）；
   - 水体总体积严格保持不变。

### Phase 3: 活动求解器 `FlipFluidDomain` 接入与综合回归

#### 3.1 接入活动求解器
将 Phase 1 与 Phase 2 成果整合进 `FlipFluidDomain.java`：
- 在 `rebuildGridFromParticles()` 与 `solvePressure(dt)` 中接入几何分数 $\theta$ 计算与对角项权重；
- 在 `projectVelocity(dt)` 中应用分数自由表面速度梯度更新；
- 在 `step()` 末尾（粒子 Advection 与固体碰撞之后）接入 `reseedParticles()`；
- 保持 `exportParticleState()` 与 `restoreParticleState()` 的接口与格式完全兼容（`FlipParticleState` 无需改动数据结构，天然支持动态体积粒子）。

#### 3.2 关键物理特性确认
- **墙面/墙角切向滑移**：重采样后的粒子在墙边和墙角依然严格遵循法向单轴 CCD 约束，验证粒子依然能够自由切向流入墙角，无粘墙、无卡死。
- **固体挤水与方块交互**：`setSolid()`、`addVolumeNearBudgeted()`、`removeVolumeNear()` 依然基于精确 `particleVolume` 结算，不受重采样影响。
