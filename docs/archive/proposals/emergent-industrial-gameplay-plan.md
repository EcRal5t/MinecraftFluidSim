# 自由构造工业玩法后续实施计划

近期目标是用少量基础方块形成连续的分离、换热、过滤、吸附与催化工艺。新增内容集中于阀门、筛、传感器、抽象物料箱及其交互；普通墙、填料和真实流道承担装置结构。活动机构由原版活塞或外部 Mod 提供，MMM 完成几何、流体作用、惯量响应和机械功交接。

当前实现与源码索引见[设计书](../../architecture/system-overview.md)，进度由[主实施计划](../../roadmap/solver-consolidation-plan.md)维护，验证方法与预算见[验证指南](../../maintenance/validation.md)。本计划对应的三维场景及操作规格见[工业装置仿真测试规格](industrial-simulation-test-plan.md)。

## 实施顺序

| 顺序 | 交付 | 玩家收益 | 依赖及复用 |
|---|---|---|---|
| P1 | 物料箱与真实端口进出料 | 无玩家值守的连续投料、收集和局部取样 | 复用容器载荷、发射器、公开转移及 HEAD/WAL |
| P2 | 真实开口阀门与测量控制 | 隔断、调流、液位／温度控制 | 复用固定几何、压力面响应、探针和红石 |
| P3 | 世界方块更新与活塞耦合 | 放拆方块、活塞开关与挤压能正确影响物料 | 复用批碰撞编辑和运动物体耦合，贯通惯量／冲量／功 |
| P4 | 筛分与有限滤渣 | 浆料过滤、截留、堵塞和清理 | 复用颗粒、沉积、床层阻力及 P2 的共享面数据 |
| P5 | 吸附剂与催化表面 | 固定床吸附再生、接触催化 | 复用有限热墙、气液库存和局部计量网络 |
| P6 | 三维组合装置交付 | 蒸馏、筛分结晶、吸附与催化连续流程 | 用正式方块和操作组合 P1—P5，按测试规格交付 |
| P0（下一轮） | 颗粒与长流程成本整理 | 持续工艺和颗粒场景稳定运行 | 整理颗粒、冷导入、编辑重建与长流程尖峰，恢复完整生产步预算 |

本轮依次完成 P1—P6 的实现、正常操作、持久恢复和旧路径清理。P0 专项耗时优化安排在功能流程全部交付后的下一轮。共享规则直接由生产入口承担，验证集中于新增的物理交接和装置流程，已有相关结果继续复用。具体进度由主实施计划维护。

近期保持已有热源与规定驱动的外部供能语义，机械外功仍完整记账。能源生产、消耗品能源、传动轴、电网、叶轮、风机、浮顶、涡轮及自研机构装配放在后续独立需求中。气固流化、燃烧／气化和炼油反应网络按目标工艺收益另行安排。

## 方块与物品清单

| 对象 | 近期实现 | 物理职责 |
|---|---|---|
| 阀门方块 | 手动／红石开度、方向、当前状态和受阻提示 | 改变真实通道开口；过渡几何挤出的物料沿共同容量交接 |
| 筛方块 | 方向、筛孔档位、截留量、排渣／清理 | 流体穿过带阻力的面，物理粒径决定固体通过或截留 |
| 传感器方块 | 选接触格或截面，读取压力、温度、液位、流量，阈值与滞环输出 | 从已提交状态派生读数，输出红石控制现有阀门和接口 |
| 物料箱方块 | 有限容量、批次列表、存取侧面和转移设置 | 保存物料载荷；本体空间采用抽象库存 |
| 现有容器接口 | 接物料箱／发射器，配置输入、输出、实际速率及红石启停 | 与实际相邻流体格进行有限物料交接 |
| 吸附剂／催化剂物品 | 应用于普通墙或筛的可接触表面，显示装填量、吸附量与适用材料 | 表面库存、有限位点、热量与反应速率条件 |
| 现有控制器、探针和机械驱动器 | 复用选择、取样、显示及诊断操作 | 控制器配置、只读观察和既有运动夹具入口 |

吸附与催化先使用静止固定表面，避免引入可运动填料管理。普通墙继续承担有限蓄热和两侧换热。每种装置由上述元件组合，构型和配方不注册为设备模型。

## P1 物料箱和持续进出料

### 库存表达

物料箱保存有限、静置的批次载荷。每批保存材料／物相身份、精确参考体积或气体标准数量、整数质量、物种、质量余量和内能。存储期间保持批次组成和相身份，回到仿真空间后再参与流动、反应和相变。同种兼容批次可以合并数量与 U，温度由状态函数派生；不兼容批次分别保存。箱内容量采用明确的参考体积／标准数量口径，界面标明单位。

首批液体、颗粒与现有容器共用载荷；气体转移沿已有逐格气体扩展相同协议。箱体内存数据与物品载荷的编码集中在现有库存／容器职责，库存唯一归属由箱的持久 actor 决定。

### 操作和事务

容器接口按真实内侧接触格执行输入或输出。箱只向紧邻且已配置的接口供料，或接收接口送来的物料；普通流体在同一区域内通过真实通道流动。输入可有用户选择的配方批次，输出按接触格的实际组成取样，禁止从整个区域挑选目标溶质。

流速设置表示每单位在线时间最多交接多少库存，由可用来源、箱容量、接触和真实区域状态共同限制。抽取、装填的动量变化和外部做功复用现有转移规则，不引入能源收费系统。

每次操作沿现有计划、WAL、HEAD 和持久回执提交，箱与区域记录同一笔接受量。两端不可用时等待；重复请求读取已有回执。空箱、满箱、暂停、卸载和重启保持物料及操作配置。到期投料可唤醒物理休眠，主动暂停保留运行意图。

完成条件： 箱到反应腔、反应腔到产物箱均能连续运行，输入输出后的质量、组成、U 和参考体积完整交接；真实物品装卸和发射器继续可用。持续投料统一由物料箱和端口承担。

## P2 阀门与传感控制

### 阀门

阀门保存方向与开度，提供手动交互、红石启停和连续开度输入。开度转换为可解析微盒或切面遮挡，压力、输运、湿壁和传热读取同一几何。首批开度档位按当前分辨率选择；低于解析尺度的开口使用统一的面面积／距离近似，并公开可用档位。

阀门形状变化沿批碰撞候选完成液体排水、局部气体转移／压缩和颗粒安置。封闭条件无法容纳目标形状时保留有效开度，显示受阻原因。与原版活塞相关的实际运动由 P3 接管，阀门本身复用同一几何与占容规则。

### 传感器

传感器读取指定接触格、指定高度截面或真实流道截面。压力、温度和液位按当前载体／区域定义给出，流量由接受的实际面转移除以仿真时长得到。一个截面由传感器设置选择，读数沿现有观察／摘要一次归集。

首批输出为阈值加滞环，并可将有界读数映射到 0—15 红石强度。阀门、进料、出料沿同一红石输入响应。扩展现有控制器与探针配置这些测点，控制过程使用已提交代；门限状态和设置随方块保存。

完成条件： 相同压差下开度改变流量，关闭后隔离并在重开后恢复；液位控制能停止／恢复进料，温度阈值能切换进出料。传感器观测保持区域库存和代次，拆除／重进后恢复设置。

## P3 世界更新和运动耦合

### 方块更新

将放置、破坏、方块状态变化、活塞伸缩及推拉的涉及位置按一次世界动作批量收集，复用 `FluidRegionWorldInteraction` 和 `LiquidCollisionEdit` 生成同代后继。变更后统一刷新固定形状、开放面、普通墙热载体和活动组。

静态改块按照明确的外部编辑结算占容与功。活塞运动期间读取实际移动形状、源／目标姿态和经过时段，通过表面速度及扫掠驱动流体；运动结束时移交静态碰撞。一个形状在同一时段只有一次占据和一次排水，替换中的活塞头、被推动方块及最终静态块按共同动作身份衔接。

原版世界已经采用的改动发生数值受阻时，区域暂停并保留最新碰撞刷新请求，世界条件恢复后重试。运动过程的停止、反向、卸载及区域手动单步沿相同时间采样；已经采用的冲量与功只发布一次。

### 表面速度和机械功

共同请求提供稳定身份、可解析形状、源／目标变换、中心、线速度和角速度。表面速度按 `u_surface = v + ω × r` 计算，压力和剪切使用相同运动面。当前原版活塞使用平移子集；未来外部旋转构件接入相同契约。

结果提供线冲量、关于声明中心的角冲量及带符号机械功。力矩通过实际作用位置归集，机械功按实际运动和离散受力结算，流体耗散进入对应热载体。模块分工为：外部机构提供姿态与受约束响应，MMM 计算流体反作用；功账连接两者的能流。

### 惯量的最小支持

请求提供允许运动方向和该方向的逆惯量响应。共同速度关系为 `q_new = q_free + R J_fluid`，其中 `R` 由提供方的约束确定。规定运动的原版活塞取零反馈响应，线性有限质量夹具取 `R = 1/m`；转动方向后续由对应转动惯量给出。压力散度和作用反作用读取同一响应，使有限惯量进入候选求解。

近期至少交付轴向有限质量的真实耦合及测试夹具，检查反压力导致的减速和动能变化。生产原版活塞继续遵循 Minecraft 的运动安排，质量数据不会改变其原版伸缩规则。质量、角惯量、姿态推进和反馈采用时点均在耦合协议声明；旋转数值能力随实际适配需求扩展。

### Create 等外部机构

核心代码依赖上述中立请求，版本适配器读取外部构件形状、运动和可提供的惯量响应，并返回其支持的负载信息。具体 Create 适配以匹配 Minecraft／加载器的发行版和公开接口为前提；核心功能由原版活塞及正式测试提供器交付。当前项目为 Fabric 26.2，[Create Fabric 仓库](https://github.com/Fabricators-of-Create/Create)与[Create 主仓库](https://github.com/Creators-of-Create/Create)分别维护，适配时单独选择匹配目标。

完成条件： 内部活塞伸缩和推块具有实际表面速度、真实排水与功，运动到静态交接后库存不再二次迁移；受阻、反向和重启可继续。有限质量夹具在同一压力耦合中受流体减速。实现清理重复的世界刷新／隐式运动路径，保留一个运动耦合入口。

## P4 筛分和滤渣

筛是一个有明确通流面的材料。筛孔参数影响物理粒径可否通过，筛面及已有滤渣提供流体阻力。对流体的法向阻力复用共同面速度响应，压降和耗散热沿当前压力／能量交接；筛的机械开放面积与流体通行语义由同一面描述给出。

颗粒在现有运动穿面／碰撞阶段判定通过或截留。粒径读取材料物理粒径，代表粒子数保持采样用途。截留量转为筛上游的既有沉积库存，保存真实材料、组成、体积、质量、动量和内能。滤渣只保存一次，筛的装填显示从该库存派生；孔隙率和有效开放面积随沉积改变，空间不足时保留受限流动状态。

清理沿现有颗粒提取与箱转移执行。首批使用液体浆料，复用已有液固阻力；气固流化和空气除尘按后续需求扩展。

完成条件： 两档粒径在同一筛面上表现出不同的通过比例；截留持续增加阻力，清理后流量恢复；随滤渣搬走的组成和 U 完整守恒。扩散后的溶解物种随液体通过筛，普通筛只按实体颗粒筛分。

## P5 吸附剂与催化表面

### 一份固定表面数据

吸附／催化材料以物品附着在普通墙或筛的表面，绑定位置、朝向、装填量和唯一表面身份。固定表面复用当前有限热载体及接触列表，可用面积由真实接触面积和声明的有效面积系数派生。首批不引入活动催化颗粒、流化和再生机构。

### 吸附

仅对声明吸附能力的表面保存被吸附物种和有限位点。首批采用一种温压范围明确的竞争等温关系和有限交换率；气体侧按局部分压提供需求，液体侧可在实际数据需要时沿同一交换协议扩展。库存、空位点和载体热状态共同限制接受量。

吸附物的质量进入固体表面载体，气体扣除相同组分和内能；首批采用额外吸附占容忽略的近似。吸附热由表面组分参考能表达，温度由 U 推导；降压或升温使吸附物返回流体。拆卸物品携带实际吸附量和 U，复用有限设备及容器事务。

首批提供声明为玩法近似的 CO₂ 选择性代理吸附材料及其容量、速率和温度范围。定义使用现有 species 和参考能，不新增通用材料预测器。

### 催化

催化表面按真实液体接触面积，为已有局部反应网络提供速率乘子。首批选择已有可逆液相反应，正逆速率使用相同催化因子，平衡关系保持原定义；反应消耗真实液体物种，催化材料本身保持库存。局部反应提案继续参与共同整数批次竞争和热可行性结算。

测试先使用明确的代理催化材料，验证接触、有限速率和守恒。实际材料的适用反应与倍率在定义中声明，气固催化、催化剂失活、结焦及裂化网络另按实际工艺需求增加。

完成条件： 固定表面对 CO₂ 有限吸附并发生穿透，降压／升温后释放可回收物料；有／无催化接触的早期转化率不同，闭合体系的最终平衡趋势相同。拆装、补料及恢复保持表面库存，所有效果通过共享接触与局部反应执行。

## P6 三维装置与验收

按[测试规格](industrial-simulation-test-plan.md)依次加入：连续箱转移与液位控制、内部活塞泵、筛分结晶、有限壁换热、基础蒸馏、吸附再生和固定表面催化。每个装置通过真实几何、物料与正式方块入口产生结果。

先做共享规则的小型验证，再做三维生产流程。复用 `GpuProcessFlowsValidation`、区域生命周期和容器恢复入口；新增测试只覆盖新交接与装置因果，既有物理结果继续复用。设计书随实现登记职责与稳定公式，验证指南维护命令和预算，本文保留交付范围。
