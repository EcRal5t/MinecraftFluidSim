# M6.1a 无容器 crash-safe 世界 ownership（已完成）

2026-08-22 关闭。M6.0 决策（[`m6.0-ownership-review.md`](m6.0-ownership-review.md)）的"空气 + 独立 registry"路线在此落地为正式实现：控制器区域激活时通过可恢复事务一次性移除内部纯原版水，region-state HEAD 是唯一提交点，任何中断点恢复为旧完整或新完整状态。实现契约见 [`../architecture/fluid-solver.md`](../architecture/fluid-solver.md) 状态边界与 [`../roadmap/world-integration.md`](../roadmap/world-integration.md) 的 M6.1a 实现注记。

## 落地内容

- `server.properties` format v3 新增 `worldBridgeEnabled`（默认关闭，重启生效；v1/v2 读取时强制 false，v3 缺键 fail-closed）。
- `RegionStateFiles` 拆出 `prepare/commit/abort` 分段世代；prepare 只清理自家暂存残留（首次发布崩溃窗口可重试），未知内容仍锁定。
- `simulation/ownership/` 正式包：per-region `wal.nbt`/`WARNING.txt`/`committed.nbt`，`OwnershipCoordinator` 按冻结顺序执行 prepare→WAL→WARNING→世界修改→HEAD→committed→清理；恢复以 region HEAD 对比 WAL base/target 判定 PRE/POST-COMMIT，committed 缺失或落后时从 WAL 重建，损坏/超前/同代不一致则 LOCKED。
- 服务接线：激活 acquire（候选与移除同 tick，玩家不可能插入编辑）、`/realwater remove` 保守 release（marker 非零拒绝，UNLOADED 区域先恢复 solver 再释放）、restore 校验 ownership 一致性、启动扫描 + 恢复未完成事务并以 LOCKED 报告锁住新激活；`/realwater worldbridge` 与 `/realwater ownership` 命令；status 增加 bridge 段，remove 汇报 ownership 恢复计数。
- M6.0 的 `ownproto` 原型命令面与原型类已删除。

## 自动门

- `runM6OwnershipValidation`：18 场景，联合真实 `RegionStateFiles` 验证两个决定性崩溃点——HEAD 发布前崩溃世界全量回滚、HEAD 发布后崩溃完成 ownership 且绝不恢复原水——以及 release 中断撤销、corrupt/代次失配/领先 committed 各 LOCKED 路径、玩家方块优先、区域隔离、WAL 严格 codec。开发中该门抓出并修复了暂存残留下 base 读取时序缺陷。
- `runFluidRegionPersistenceValidation`：新增分段世代 4 场景（暂存不可见、abort 回退、moved-base 拒绝、幂等重暂存）与 config v3 迁移/缺键场景。
- 修复 Windows 杀毒句柄竞争导致的目录原子 rename 偶发 `AccessDeniedException`（两个文件层有界重试），修复后连续 4 次双门串行通过。

## 实机 Smoke A（2026-08-22，用户取证）

| 场景 | 结果 |
|---|---|
| 门开启后激活 5×5×4 控制器（内部 3×3×2=18 格纯水源） | 内部原版水移除、marker 保留并渲染；ownership 第 1 代持有 18 位置（air 18） |
| 玩家在 owned air 放置方块 | reconcile 报"玩家方块冲突 1" |
| 未排空 remove | 按预期拒绝（"仍持有水体"） |
| drain 排空后 remove | 成功释放：原水恢复、玩家方块保留、ownership 目录清理 |
| 走远 UNLOADED → 返回 | 同 UUID、同代次、marker 账本一致（water 17.00 blocks 往返不变） |
| 稳态强杀进程 → 重启 | committed 保留、无锁、水保持被持有、无复制、无 LOCKED |
| 关闭门重启后激活 | legacy 双表示（原版水保留），`/realwater ownership` 显示 legacy；remove 直接删除不恢复水 |

Smoke 暴露并已修复：ACTIVE status 缺 bridge 段；被拒绝的 remove 把消息写入持久 issues 列表并在成功移除后残留（现在操作拒绝只返回给命令，不进持久列表）；remove 成功消息缺 ownership 恢复计数（现在汇报恢复/跳过数）。

## 已知边界（进入 M6.1b）

- 排空只能靠 `/realwater drain`（开发命令，水无容器承接）；release 恢复的是被持有的原版 preimage。容器（满/部分桶、混合物）是 M6.1b 的真实转移路径。
- LEGACY 区域（门关闭期创建）不迁移：原版水保留在世界中，重新激活或重建才建立 ownership。
- 原版水经边界破口流入 owned air 时只被对账报告（"原版水回流"），不自动清除；控制器闭合外壳是第一道防线，流入策略留待 M6.1b 评审。
- committed.nbt 被外部删除与 region-state 目录被删除同属"存档被手动破坏"，不设防；损坏（可读出不合法）才 LOCKED。

M6.1a 不单独升版本；主 Mod 保持 0.11.0，M6.1 整体在 M6.1b 完成后升 0.12.0。
