# M7.0 守恒化学状态设计评审

2026-08-23 关闭设计门。本轮冻结化学真值、exact definition codec、registry fingerprint、硬预算、版本边界和验收门；
没有打开 gameplay gate，也没有改 v1/v2 格式或版本号。正式契约见
[`../architecture/chemistry-state.md`](../architecture/chemistry-state.md)。

## 选择结果

采用“absolute parcel record + packed handle”。handle 0 保留；每个 live marker 只增加一个 `int` handle 和一个共享 bitset
中的 indicator bit。pool 使用 primitive record metadata 与最多 16 个排序 entry，不为 marker 分配 map/object chain。
`massResidual` 保存 raw-double bits，从而把 exact-rational species mass 与既有 marker mass 解耦，并可逐位 checkpoint。

拒绝以下替代方案：按格库存会在 advection/reseeding 时失去 parcel provenance；每 marker `Map` 无法满足 73,728-marker
heap 门；把 species 塞入 `FluidMixture v1` 会破坏 M6 legacy component/WAL；把化学字段作为 v2 optional extension 会让旧 reader
误读不完整物理真值。

## M7.0 原型证据

- exact rational codec 接受整数、有限小数和分数，拒绝 JSON number 绕过 exact parsing、零分母和未知字段。
- 15 个首批 species、3 个 chemical phase、6 个完整解离和 1 个瞬时中和反应通过组成、charge、exact mass、零体积变化验证。
- 定义列表倒序/旋转后 canonical bytes 和 SHA-256 完全相同；当前内建 fingerprint 为
  `f6dcf366a816b403bf412b37f5791a49bf0463d367bba236704e37bd9a1d4b7a`。
- NaCl + KNO3 完整解离逐 species 等价；等量、酸过量、碱过量 fixture 正确；reaction/canonicalization 重复 10,000 次
  无一 quantum 漂移。`chemistry` 完整门耗时 0.151 s，其中 10,000 次循环远低于典型格 p95 10 ms 的设计预算。

## 冻结预算论证

默认最大域 73,728 marker 的最坏 primitive 常驻模型：1,179,664 packed entries 的 `short species + long amount`
约 11.25 MiB；handle 的 count/residual/refcount/free-list 约 1.20 MiB；per-marker handle、indicator/dirty bitset 约 0.30 MiB。
加 canonical table/persistence staging 一份与 reaction/cell scratch 的保守双倍上界仍小于 32 MiB，低于新增 64 MiB 门。
正式 pool 落地后该静态模型必须由 `cpuBytes()` 与最大域分配门复核。

默认 9,216-cell v3 display snapshot 冻结为 v2 几何字段加每格四个 `palette-index + weight` byte pair、pH byte、indicator
byte和 residual byte；即使按 3 个 material/phase fraction 字段计，固定 cell fields 为
`9,216 * (3 + 3 + 8 + 3) = 156,672` bytes，连同 256-entry palette、identity 与长度前缀仍保守小于 192 KiB，低于
512 KiB。真正 codec 完成后必须用编码后的 buffer 长度复核。

chemistry-on/no-dirty 的实现必须在 dirty bitset 为零时 O(1) 返回；接入 solver 后用同一 JVM 交替基线测中位 step 增量，
必须不超过 5%。这些是进入生产闭合的硬停止门，失败只优化化学实现，不改 40/200 ms pacing。
