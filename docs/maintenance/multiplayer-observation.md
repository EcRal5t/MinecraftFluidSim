# 多人观察验证

## 自动化范围

`protocol` 检查观察请求及回复的编解码、客户端打开会话、回复序号、基准样品与传感器历史。两个独立客户端状态对象分别保存基准和打开请求；测试覆盖不同会话、过期回复、界面变化、维度变化和断线清理。显示模式保存在客户端进程内，渲染读取本进程的设置。

`MultiplayerObservationGameTest.independentObservers` 在专用测试服务器的同一世界放置传感器，以两名 GameTest 模拟玩家调用网络接收器使用的正式请求处理。两人获得相同测点记录与各自的会话标识；测试还检查超出距离、维度不符、双方手持样品和不支持的物品。GameTest 模拟玩家直接调用请求处理；网络消息编解码由 `protocol` 验证。
