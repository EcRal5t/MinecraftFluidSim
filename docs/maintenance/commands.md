# 游戏内命令速查

`/mmm` 用于开发场景、管理员操作和故障诊断。正常创建区域的步骤见 [项目 README](../../README.md#在游戏里使用)。
命令树定义在 [MmmCommands](../../fabric/src/main/java/mmm/MmmCommands.java)，处理器入口见 [命令索引](../architecture/system-overview.md#gameplay)。

下表省略每项前面的 `/mmm`。

| 用途 | 命令或操作 |
|---|---|
| 打开演示面板 | `demo`、`demos`；快速入门手册中的“演示” |
| 创建空演示水箱 | `controllerdemo` |
| 大型溃坝与世界采样诊断 | `damdemo`、`capture`、`takeover` |
| 为当前区域命名 | `regionname <名称>` |
| 列出、选择和保存区域 | `regions list`、`regions select <uuid>`、`regions checkpoint` |
| 增减库存或刷新碰撞 | `pour [1-16]`、`drain [1-16]`、`refresh` |
| 清空开发区域 | `empty`；模拟区域使用下文的界面流程 |
| 运行与诊断 | `run`、`pause`、`step [1-20]`、`status` |
| 区域接入配置 | `regions-enabled [true/false]`；关闭后现有模拟区域暂停 |
| 世界交互配置 | `worldbridge`；重启后生效 |
| 油水配方与材料物品 | `materialdemo`、`materialbucket ...` |
| 酸碱配方与化学状态 | `chemistrydemo`、`reagent ...`、`chemstatus` |
| 放大毛细效应的进阶实验 | `tensiondemo [angle]` |
| 颗粒物品与状态 | `granularcontainer ...`、`granstatus` |
| 气压场景 | `airdemo [ambient/pressure/vacuum]` |
| 工业装置、驱动与取样 | `plant <场景>`、`process`、`process drive <秒数>`、`process sample`、`process stop` |
| 世界方块归属检查 | `ownership` |
| 调试显示、实体与日志 | `debug`、`entities`、`logpath` |
| 容器事务故障注入 | `transferwal [fault <point>]`；在事务恢复测试场景中使用 |

`run` 与手动 `step` 可以重试性能暂停。其他不可用状态先按 `status` 的具体原因排查，入口见 [故障定位](../architecture/system-overview.md#diagnosis)。

## 演示面板

管理员在空旷、区块已加载的位置打开面板，选择水箱、水流或气压。水箱的清水、油水和酸碱共用同一个真实模拟区域；水流池带池壁、障碍和入池台阶；气压管在同一几何中切换常压、加压和低压。开始后返回游戏画面，重置后保持暂停。

“开始”创建并运行所选场景，“暂停”和“单步”操作当前场景，“重置”在原位置恢复所选初态并暂停，“移除”清理演示区域及仍保持原样的演示外壳。材料、化学、控制器和气压快捷命令均打开这个面板，并准备相应的暂停场景。创建水箱时发放缺少的水桶、空桶、材料桶和探针；水箱通过实际接口交接库存。重置会清空原配方，恢复室温常压后投料。

每位玩家在每个维度维护一个演示；水箱身份随世界保存，重新进入可继续重置。临时水流／气压场景共用一个名额，创建前需移除其他玩家或命令留下的临时场景。操作需在演示附近进行。演示仍使用世界能力、Vulkan 求解和正常超时暂停规则。

## 清理模拟区域

管理员手持物质场探针点击选区内位置，依次预览并确认：

1. `EMPTY_CONDENSED`：清空液体与固体物质。
2. `VENT_SEALED_GAS`：排放密闭气体，形成真空。
3. `RELEASE_OWNERSHIP`：释放世界方块归属。
4. `REMOVE_EMPTY_REGION`：移除已经清空的区域。

界面列出实际移除量和当前阻止原因。每步完成后再进行下一步。`/mmm remove` 用于临时开发区域。实现与恢复规则见 [区域生命周期](../architecture/world-ownership-and-containers.md#区域生命周期)。

## 调节恒温源

用 `/give @s mmm:thermal_reservoir` 取得方块。放置后，手持物质场探针右击它，在服务器提供的界面中设置温度，单位为 K。调节要求创造模式和相应写权限，允许温区由当前世界保存的热学定义决定。

## 工艺操作

在容器接口朝外的一侧紧邻放置物料箱。九个槽位保存玩家放入的实际容器；持单个容器点击交换当前槽，空手点击取回，潜行空手点击切换槽位，探针打开选槽面板。出料箱须预先放入对应物相的空容器。探针打开接口后选择进料或出料、物相、最大速率和红石控制；青色箭头向内进料，黄铜箭头向外出料，中性标记表示停止。气体速率使用标准体积，实际接受量受接触格、来源库存与容器剩余容量限制。合成与获取顺序见[生存模式入门](../gameplay/survival-progression.md)。

空手点击阀门逐档切换开度，探针可直接选择关闭至全开的五档状态。红石强度映射到相同开度。传感器面板选择液位、液体温度、气体温度、绝对压力或液体流量，设置起止方块坐标及上下阈值，以滞环或连续输出驱动相邻红石线路。筛面板设置孔径和开放率，并显示相邻沉积库存；在进料侧安装颗粒出料口，将滤渣收集到箱中。

手持液体、颗粒或气体容器，潜行对空气右击打开样品分析。界面显示总量、已记录的物种组成和可用的温度；气体使用标准体积。滚轮浏览内容，点击“保存当前样品为基准”，再更换容器并重新打开界面，即可并排比较；“清除基准”移除对照。基准在切换维度或断线后清除。

空手潜行右击传感器打开工艺曲线，空手普通右击查看当前读数。曲线横轴为区域累计物理时间，单位为秒；窗口打开时自动刷新，关闭后停止刷新。区域暂停时曲线显示暂停状态，恢复后从新线段继续；测点不可用时曲线断开，恢复观测后重新连线。曲线保留最近的会话记录，传感器配置或关联区域变化时重新记录，卸载或重启后从新会话开始。

持吸附或催化材料点击已启用区域中的普通墙或筛表面完成装填。同面继续装填同种材料会合并装填量；空手潜行点击同一面取回材料，物品携带实际吸附量与内能。装有表面材料的墙先取回材料再拆除。

管理员在已加载的空地使用 `/mmm plant <场景>` 建造组合装置。命令补全列出双箱、筛分与结晶、逆流换热、单级与串级蒸馏、吸附和催化场景，以及对应的材料和温壁对照。主手单份实际容器可移入首个匹配的输入箱，后续供料通过物料箱完成。`catalysis` 与 `catalysis_partial` 使用相同流道，分别装填完整与部分催化表面。

双箱装置从第一箱高位进料，第二箱的液位测点控制进料口。两箱顶空由独立气道连通；暂停出料可使液位上升，恢复出料后进料随液位滞环继续。

`/mmm plant distillation_single` 建造一台批式蒸馏单元，`/mmm plant distillation` 并排建造两台。第一台从侧口以 10 L/s 装入 100 L、370 K 的等体积水—乙醇原料，池底和两侧热源为 600 K。蒸气经顶部通道进入冷凝段，普通有限冷墙吸热，侧面产品口以 0.5 L/s 收集实际液体。气口在绝对压力 100—110 kPa 间启停，排气进入有限气体箱，装满后换入空容器。

第一台收集约 20 L 时停止取料，把实际馏分桶放入第二台进料箱，再收集约 4 L，观察两次产品的乙醇摩尔分数。桶携带完整组成与内能；批末将进料口切换为输出即可回收残液。`distillation_warm` 使用相同装置和较暖冷墙，对照冷凝能力。

逆流换热装置的两条窄通道分别从两端同高度进料和出料。启动时关闭液体出口、开启顶部排气，两侧各装入 500 L 料液；装填完成后关闭排气，开启液体出口，将两侧进出口均设置为 2 L/s。热侧底部排空口常态设为停止模式；停止热侧进料时开启该排空口，冷侧持续流动并带走隔墙蓄热。

结晶装置的侧筛后阀门初始关闭，有限冷底板使池内料液冷却。通过固体端口投入晶种，结晶后将同一端口切换为输出以收集晶体；回投部分晶体时切回输入，打开筛后阀门并注入清水洗涤。

机械驱动器安装在已选择区域外壳，空手点击沿该面法线启动十秒往复运动，潜行点击停止。管理员也可对准内部开放格执行 `/mmm process drive 10`。`/mmm process sample` 读取对准格库存，`/mmm process stop` 停止规定驱动，`/mmm regions checkpoint` 保存区域。

## 切换流体显色

手持物质场探针点击选区内位置，打开“流体显色设置”。可选择组分、pH 或温度，并调整温度色带下限与上限（K）。选择保存在当前客户端，作用于全部可见流体区域，暂停时也立即换色。
组分使用材料和化学组分颜色；pH 色带为 0–14；温度使用单元凝聚相展示值。灰色代表不适用或无数据。
