# 工业流体模拟能力补全施工计划

本文规定 GPU 执行链完成主线化之后的能力设计、交付顺序和验收方式。当前实现由[设计书](../architecture/system-overview.md)维护，施工进度与下一轮范围由[实施计划](solver-consolidation-plan.md)维护，实际运行证据与预算由[验证指南](../maintenance/validation.md)维护。本文是可审阅的施工规格，不登记完成百分比和历史结果。改变稳定模型时同步修改设计书和相关专题；原有 [GPU 执行原则](../architecture/gpu-execution-principles.md)保持只读。

## 产品目标与依赖

玩家能用普通方块围出容器、通道和隔板，配置有限物料来源、动力及换热接触，通过真实的容量、压差、重力、传热、相平衡和反应，组合出储存、输送、加热冷却、混合、沉降、气液交换和基础分离过程。流体和过程状态应能观察、取样、保存、恢复；同样的基本规则适用于不同构型。方块设备主要提供真实几何、能量或物质接口，结果由材料和通量决定。

先完成 GPU 生产执行链主线化，再按以下阶段补能力。届时 Vulkan 是唯一生产数值路径；宿主保留世界交互、状态准备、事务和恢复，依赖 GPU 求解后的能力沿同一生产路径实现。可复用的模型、数量编码、几何、状态函数与事务规则按职责保留，不要求保留 CPU 运行求解器。每轮交付都覆盖输入、设备计算、状态提交、查询展示、持久恢复和旧路径删除，允许内部拆步开发；活动进度只写入主实施计划。

本目标强调 Minecraft 方块尺度下可玩且可解释的工业现象，允许明确适用范围的粗尺度近似。相邻项目 [Industrial Chemical Engineering](../../../Industrial-Chemical-Engineering/README.md) 用于启发热力学、传质和反应的工艺需求；其 README 开发状态与源码算法、游戏内可用功能应分别核对。本计划按宏观过程定义交付，不以预制件数量或设备名称衡量覆盖程度，也不宣称任意实际化工过程均可复现。

前置交付的具体要求见 [GPU 执行链主线化计划](gpu-mainline-execution-plan.md)。下文源码链接是主线化前的定位入口，迁移后由当前设计书提供新路径。

## 实施基线与依赖顺序

本计划采用以下默认设计进入详细离散设计。审阅若发现具体物理或成本反例，可整块替换对应方案，并同步修改受影响阶段；不将候选方案全部建设为生产分支。

| 次序 | 工作包 | 默认设计与交付范围 | 前置 |
|---|---|---|---|
| S1 | 共享几何与壁面作用 | 统一真实开口、墙面接触及无滑移应力；保留当前空间分辨率，先获得可解释的通道流动 | GPU 主线化完成 |
| S2 | 局部气体与共同压力 | 优先局部气体组分／内能和低 Mach 半隐式压力耦合；液气可解析连续流共用面关系和守恒交接 | S1 |
| S3 | 混合物性与有限热墙 | 混合物状态求值集中；区域持有有限墙热库存；真实液体热膨胀按收益决定 | S2 |
| S4 | 物种扩散与相间传质 | 同相守恒扩散；统一气液接触面积及有限速率传质，先采用简单物性数据 | S3 |
| S5 | 混合相平衡与固液溶解 | 双组分挥发／冷凝、温度相关溶解度和颗粒有限传质；共享相间转移与能量结算 | S4 |
| S6 | 一般反应与动力输入 | 竞争／可逆有限速率反应，共同局部积分；物理功输入驱动自由构造搅动与输送 | S5 |
| S7 | 组合工艺交付 | 连续投料、加热、接触、反应、沉降与冷凝收集贯通，同场景保存恢复 | S6 |
| S8 | 可选规模扩展 | 单区域工艺完成后评估增大规则网格、稀疏分块或独立区域端口；连续分块不产生人工流阻 | S7，且规模收益成立 |

正文按 S1—S8 单一工作包组织，实际施工先完成 S1—S7，S8 按规模收益另行安排。每个工作包完成输入、数值推进、提交、展示与恢复之后才交接下一包。S3 的组成物性定义可在 S1 先建立接口，避免 S2 自建另一份物性表。

### 基础能力与可延后能力

- 本轮目标所需：真实几何上的壁面作用、空间气体组分与热输运、有限热壁、混合物性、物种扩散、气液相平衡与传质、温度相关溶解、竞争反应、持续物质与功输入。
- 工程连续性所需：跨计算分块共享面、活动范围、恢复和显示，避免玩家工艺在计算区域边缘被人为截断。S1—S7 先在单一区域完成；原尺寸限制按实际预算调整，跨块联立不作为基础工艺前提。
- 按收益决定：真实液体热膨胀与有限压缩性、未解析湍混、未解析气泡滑移。先用已有低成本模型做目标场景，确有缺失才引入共享闭合项。
- 当前不安排：独立管网求解器、按设备身份给分离效率、通用高精度湍流模型、任意化学体系自动预测。

同一基础机制可以由多个阶段算子组成。是否精简，以共享状态、唯一物性规则与通量结算衡量，不要求把导热、化学和压力塞进一个巨型 shader 或每步全局联立。

## 共同状态与通量契约

1. **唯一库存与空间归属。** 每个区域／可解析开放空间保存各物相的质量、物种数量、内能及需要的相占容；液体和需要空间运动的气体持有对应动量。颗粒、沉积床、连续固体和有限热载体保有各自库存。温度、密度、压力、物性和接触面积从同代库存、几何和材料定义派生，展示和设备读取这些结果。保存或变更压力自由度的粒度，由气体方案裁定，不能据此复制一份竞争库存。
2. **一份实际交接。** 一次面或跨相转移先根据真实开口、库存、容量和状态决定接受量；质量、物种及其余量、携带内能、动量或相应冲量沿同一接受量交接。导热、做功、反应参考能和外部供能单独记录来源与去向，避免把焓、潜热和参考能重复记账。材料间的相对扩散以成对交换结算，整格与区域质量守恒，禁止通过独立裁剪丢失质量。
3. **可表达的体积变化。** 接受量决定未来占容；热膨胀、相变、溶解及反应引起的真实体积源与气体储容参加同一次容量／压力交接。质量和元素守恒，体积允许依据状态方程改变；封闭容器无法容纳变化时，由压力、可压缩性或物理受限状态承担，不用静默清除物质。整数物种、质量余数和完全排空沿实际份额结算；浮点力学、几何和热误差独立报告。
4. **私有候选与恢复。** 几何、物性、外部输入及源库存使用同代数据；计算先准备完整后继，成功后一次采用，失败保留已提交状态和原因。待处理时间、分数量余量与必要的相变力学同步状态随候选和存档交接，不能因卸载或恢复重复推进。外部容器、世界方块和跨区域转移采用可恢复事务，查询读取已提交代次。
5. **共同执行与活动范围。** 相邻计算复用开放面、接触、材料定义、实际通量和活动组；只对实际受影响的材料、相及接口计算。气体采用集总或局部方案须保留同一外部库存和事务语义；待替代链完整交付后删除旧生产算法，不长期同时维护两套求解器。

共同推进顺序为：捕获输入与真实几何 → 准备物性、占容和接触 → 力、压力与实际通量 → 质量、物种、动量和携带能量输运 → 导热与局部反应／相间转移 → 体积变化的力学交接 → 共同提交与观察。具体采用同一步联立还是有界分裂在相关阶段裁决；强耦合情况下要测分裂误差，整步始终推进约定时长。

## 各工作包的算法约束、替换范围与完成条件

### S1：让墙面与通道几何真正参加流动

固定几何一次给出开放体积、面通行面积、墙接触面积和方向；压力、黏性、输运、导热读取同一几何。普通固壁采用无滑移的粗尺度离散，滑移只作为明确材料属性。已有 `liquid-viscosity.comp` 的局部应变和墙耗散优先复用，动量反作用归入固定墙或运动物体，损失的机械能交给实际热载体。

实施前审查现有 `mu*h*wallArea/min(liquidVolume,poreVolume)` 的长度与润湿面积假设，不能仅开启默认 `NO_SLIP`。以 `G = μ A_wet/δ` 组织离散，`A_wet` 来自实际液体与墙接触，`δ` 反映所选速度自由度到壁面的有效距离；将满通道、部分充液和薄膜分别代入同一几何规则检查。现有墙面积累计遍历单元全部开放微盒，S1 改为排除未浸润干墙面积，并按实际接触面和速度位置计算特征距离，保留真实薄膜的黏性响应。圆管／平板充分发展流只作为对应几何的参照，不能统一塞入水力直径系数修补全部自由面。修正后的公式及适用尺度在 S1 交付前确定。

管道长度和转弯通过已解析空间内的运动、压力与应力发生作用。当前每格两微盒只决定几何采样，不增加速度自由度；一个微盒宽的通道不能自动得到充分解析的速度剖面。首先说明最小推荐通道尺度，再判断是否需要普适的未解析墙面剪切闭合。不得按“这是管道方块”切换到另一套管网算法，也不得承诺现有粗网格自然得到所有雷诺数下的实际压降。

完成条件：相同驱动下，增大可解析通道长度、减小截面或提高黏度产生合理流量趋势；静水不因墙面耗散主动发热；动墙外功、流体动量和热量去向可解释。输出共享几何契约与误差范围，删除各物理阶段重复推导开口／墙面积的规则。

### S2：局部气体替代集总演化

先给出每格气相库存、占据体积、组分、内能及与 MAC 面惯性的映射。压力由 EOS 和体积约束闭合；压力推进采用可消除主要声学时间步限制的半隐式形式，仍需处理输运、接触和反应造成的时间限制。气液共速描述可解析大界面；细小气泡相对液体的上浮不能据此承诺已实现。

实现设计必须同时交付：

1. 纯气格、纯液格、混合格和真空的同一状态定义；退化状态在同一离散中有明确极限。
2. 同一开放面上液气各自接受通量及总占容约束，物种、质量、携带内能和动量一致输运。
3. 气体压缩功与压力冲量的离散配对，低 Mach 压力与绝对热力学压力的关系。
4. 相变气源、外部注气、液封开启和固体排水对库存、压力与容量的共同响应。
5. 从旧腔状态生成空间初态，以及新状态的保存、查询、休眠和恢复；旧存档无需兼容。

先以 U 管、纯气通道脉冲、局部热源和两种气体注入共同评估成本；只测液体或只测压力内核不足以选择方案。目标能力包含局部组分前沿和温度差，不能用重新全腔均混来弥补性能。若局部设计成本过高，收缩活动规模或重设计压力自由度，但仍保留局部库存及有限输运。

S2 分为设计样机决策和生产替换两段，生产替换以样机回答下列问题为前提：

| 风险 | 必须给出的离散处理与证据 |
|---|---|
| 小干容与热压力刚性 | 采用沿真实气相通路的控制体合并或守恒更新量重分配等统一小控制体方法，并明确选择理由；封闭孤立小泡不得跨液封并入其他气体。以 99.9% 满液及更小残余量、受热与压缩输入检查容量、正内能和真实压缩功；温度物理上超出材料范围仍需报告，不得裁温隐藏。 |
| 同面气液逆流 | 单一面速度不能解析同面逆流。首批支持空间分开的气柱／液膜及可解析气泡；把单格通道逆流列为能力限制。若目标构型依赖该现象，先评估统一漂移通量或增加相对速度自由度，再决定是否交付；不能宣称共速已支持它。 |
| 高密度比压力 | 测典型气液密度比约 1000:1 下装配、预条件、迭代与完整步成本。现有 `VulkanPressureMultigrid` 针对液体七点算子，需评估新增储容和系数跳变，不能假定直接适配或必然失效。 |
| 库存和带宽 | 统计活动气格、每格实际组分、稀疏行、双代与临时数组的实际字节及读写次数；以实际布局和访问统计确定带宽成本。 |

样机复用现有资源、真实库存量化和计时，不另养长期实验后端。先沿备忘录以原 64³ 切格／32³ 颗粒输入判断完整成本，再集中物理验收；短风险场景用于定位。若完整实现无法满足约定场景预算，且瓶颈确来自新增自由度，暂停生产替换并比较“空间库存／温度输运＋聚合压力”的单一替代设计。该替代仍须闭合局部热压和气体通量。50 ms 是工程目标，不作为一次超时就自动回退的开关，也不在运行时并存两套气体算法。

完成条件：气体空间差异可持续并随流动传播，液封与 U 管仍有效，保存续算不丢局部状态；旧动态气腔演化、重编号及库存来源重映射已由新链完整替代；G3 暂留的宿主编辑静态气腔和动量交接完成迁移，容量、碰撞排水及颗粒重安置职责继续保留。保留用于查询或休眠的连通分组不代表保留第二套气体物理。

### S3：组成物性与有限热载体

集中一个混合物状态求值职责，输入相别、实际组成、温度与压力，输出该模型支持的密度、热容、黏度、导热和相平衡所需量。先采用明确的理想混合或简单混合律，互不相溶材料保留各自相身份；不能把油水同格直接视作分子互溶。首批材料必须有实际数值数据及有效范围。

墙体以有限质量和内能为权威状态，导热接触使用 `Q = G ΔT Δt` 的有限热容推进形式；大热导时复用已有稳定热交换求解。接触热导统一由面积、距离、两侧导热率及可选接触热阻派生。墙体可连接两侧不同物料，普通材料墙、已有有限换热器共用热载体与接触计算。墙体只有一个归属，拆除的能量去向在方块／物品操作契约中明确。

普通墙的热库存存于区域的墙热载体列，以位置和材料身份关联世界方块，无需给原版方块新增 BlockEntity。首次纳入／退出时按完整载体内能记显式环境源汇；替换时分别记旧载体移出和新载体按声明温度移入。若模型只保存相对环境的超额能，则另写清参考能项；不能只记温差能量却从账中删除完整 U。普通掉落保持原版堆叠，允许把墙的热量带出模拟系统，属于明确的玩法近似。专用蓄热元件沿既有热载荷与 WAL 拆装。S1—S7 一块墙只归一个区域，两个独立区域共享同一实体墙的情况须在区域登记时识别并限制，待 S8 共同归属方案交付，禁止复制两份热库存。

真实液体热膨胀为条件交付：若选择支持，先定义 `V = m/ρ(T,p,x)` 与 EOS 压缩性，体积源进入压力和容量，现有热浮力规则由同一物性推导，删除重复修正；完全满液闭壳必须有可解释的压力响应。若收益不足，保留当前固定液体体积与浮力近似，并从本轮验收中移除热胀体积和闭壳热压要求，记录明确取舍。不得实现半套体积热胀后靠丢量或任意压力上限维持运行。

完成条件：两侧流体通过玩家搭建的有限导热壁交换能量，墙温会变化，停热后仍能放热；物性读取同一组成与温度，取样和恢复一致。既有固定方向换热器专有热学规则被共享载体规则覆盖。

### S4：扩散与统一接触传质

同相扩散采用固定液体体积、允许净质量交换的体积平均近似。浓度梯度产生溶质交换提案，反向溶剂交换依据材料定义的有效组分体积配平。先选定首批体系的有效体积或等价交换系数，并在全部同相扩散中使用同一口径；离子交换保持所选电中性约束。各面按真实供体量共同限制接受批次，溶质与反向 H₂O 共同接受，携带各自能量。

按一次面接受的有符号整数物种量 `q_i`（A→B 为正）、每量子质量 `w_i` 和实际残余质量转移 `r` 更新：

`n_Ai' = n_Ai − q_i`，`n_Bi' = n_Bi + q_i`；

`R_A' = R_A − r`，`R_B' = R_B + r`；

`Δm = Σ w_i q_i + r`，`m_A' = m_A − Δm`，`m_B' = m_B + Δm`。

每格满足 `m = Σ w_i n_i + R`。当前水相明确登记 `H₂O` 物种，`massResidualUnits` 只是未由物种列解释的质量余量，不能自动把它当成全部溶剂或用它抵扣不存在的水。反向溶剂交换必须扣真实 H₂O；`Δm` 允许非零，按真实物种摩尔质量计算；质量余量只沿实际载荷交接。

同相扩散保持 `V_A′ = V_A`、`V_B′ = V_B`，质量按上式改变，机械密度直接为 `ρ_A′ = m_A′/V_A`、`ρ_B′ = m_B′/V_B`。本轮采用可加有效组分体积和固定载体占容近似，体积分配在交换提案中处理；整数配平的分数量余量留待后续批次，真实体积字段保持原值。给出该近似下的组成密度响应及量化误差，不引入扩散专用的全局体积源或 `pendingPhaseMotion`。混合收缩、过量体积暂缓；改变相占容的气液相变、固液转换及可选真实热膨胀沿各自共同容量交接处理。

MAC 面从同批实际转移准备新面质量 `M_f'` 和动量 `P_f'`，速度为 `P_f'/M_f'`。相间增质量与同相双向扩散的携带速度不同，复用共同质量／动量结算职责，不能照抄现有 CO₂ 零速加入的动量公式。计算前后动能 `P_f²/(2M_f)`，与携带动能、势能、压力功共同结算 U，避免把所有质量变化都当成耗散。接受量、固定体积、更新后的面质量／动量和温度在一个候选内闭合。

气液传质采用 `转移速率 = 接触面积 × 有效传质系数 × 平衡偏离` 的共享结构。Henry 稀溶质与挥发组分使用各自适用的平衡关系，复用相同的接受量、余量、库存及能量结算。接触表须能列出实际相对，处理覆盖油层和多个相邻气相；替换当前单格单节点／单规则选择及仅按体积分数估面积的限制。优先复用已计算 PLIC 接触，不为传质单独重建一套几何。

未解析混合只在实际场景证明平流与物理扩散无法支持有意义玩法时引入，采用统一有效扩散系数，明确它代表粗尺度混合。禁止按装置名称设置混合效率，也不承诺解析湍流产生的全部传质增强。

完成条件：静止浓度梯度能缓慢扩散，流动能携带局部浓度，隔墙保持隔离；增大真实气液接触面积提高吸收速率，接近平衡时净转移消失，有限气体可被耗尽并正确停止。整数转移余量保留，粗量子不会被静默清除。

### S5：混合相变与颗粒溶解

首批选一个理想近似合理且数据完整的双挥发组分体系，采用 `p_i^eq = x_i p_i^sat(T)` 的理想汽液平衡作为默认起点，气相用分压；超出适用范围的高压、强非理想体系暂缓。同一有限传质框架向平衡推进，接受量受库存、内能、压力和容量共同限制。纯组分由同一关系取极限，Henry 稀溶质只在其有效稀溶液模型内使用，材料定义避免同一组分被两条交换规则重复计算。

参考化学能、显热、潜热与压力功采用一份热状态定义，明确 U 与流动焓的使用位置；不能既通过物相参考能改变计潜热，又额外扣一次潜热。加热、相变及机械同步在同一候选完成；强反馈优先局部隐式交换或局部子步，并将实际体积源返回共同力学结算。

气液交换合并为唯一的接触表、交换提案、供体竞争、实际批次和能量／占容结算。Henry 与挥发性平衡只提供不同的材料平衡关系，相变体积变化由实际组分转移及选定的相密度／有效组分体积决定，稀溶气体按已声明的固定液体体积近似处理；不得让同一组分在 `VulkanGasPhaseChange` 与 `VulkanGasLiquidMassTransfer` 两次抽取。可以保留职责明确的平衡求值函数和分派内核，旧独立扫描与重复写账随迁移删除。

固液溶解使用温度相关平衡浓度和有限速率，接触面积来自代表粒子的物理粒径与代表质量，沉积床考虑实际可接液部分。代表粒子数变化不应直接改变总反应面积；首批允许简单可达面积近似，暂缓孔内扩散和复杂粒形。复用现有沉积、起动和 Darcy 阻力。

完成条件：双组分加热产生蒸气富集，冷壁冷凝并可独立取样；盐类随温度和浓度发生析出／溶解；各相总量与热量能从同一接受账重建。删除重复的纯物质转移和固定溶解阈值生产规则。

### S6：一般反应与实际功输入

反应统一表示为计量矩阵和反应进度：`n_new = n_old + S ξ`。默认按共同温度／组成对局部反应网络进行有限速率积分；速率由质量作用关系、温度相关系数及有限适用数据定义，可逆反应给出一致的正逆方向关系。快速酸碱与解离并入同一局部求解的快速极限，避免单独一遍“先消耗完再计算其他反应”。

首批采用小型活跃竞争组的统一速率积分与有界时段细化，按实际活跃规则组织工作批，避免每个格子运行通用多维 Newton／活性集框架。所支持组的大小依据首批网络与寄存器／完整步成本确定，不任意硬定 2—4 条。单一净反应只有在残差单调和热反馈可控时才使用一维区间求根；一般可逆网络不能假定都能这样降维。快速解离、有限反应和相转移的时间尺度及组内耦合规则在首批网络上统一确定。

量化后的反应批次向量 `b` 必须满足全部物种的 `n + S b ≥ 0` 及能量／容量限制。比例分配可用于单个共享受限反应物，但 `portion()` 不能独自解决多反应物竞争；按完整计量批次执行共同可行分配。整数平局用与注册顺序无关的稳定规则，量化尺度的产物差异明确记录，不承诺逐量子连续解。

例如只剩 3 quanta、两反应提出 1.8 与 1.2 批时，可先各接受 1 批并把剩余 1 quantum 留在真实库存，或在全部约束允许时按统一配额规则给一个反应。余量保存尚未执行的数值进度，每次执行按当时实际库存重新限制；供体耗尽、规则失活和反向反应时要清理／重算无效需求，不能把已经分配的第三量子再次兑现。物种与能量只按实际接受批次更新，能力完成条件覆盖低量竞争和恢复后的无重复反应。

机械输入先实现能复用现有规定运动耦合的基础驱动面／可动构件：几何、速度及对流体的作用共同进入压力和黏性，反作用与外功结算一次。阀门改变真实开口；可玩的流量调节首先使用可解析几何。若需未解析开度模型，以统一局部面系数表示并说明范围。有限质量旋转机构、轴系和复杂机械传动不作为本轮前提。

完成条件：同一反应网络更换注册顺序结果不发生物理选择变化，温度和投料能改变产物比例；反应生成气体或固体后继续流动与沉降；动力输入改变流场并有明确功来源。旧 DAG 顺序消耗与重复专用热账删除。

### S7：组合交付与范围声明

选用前述已支持的物质搭建三条玩家可改形状的流程：有限热壁连续加热／冷却；气液接触吸收与脱除；反应析出、沉降和液体取出。双挥发组分另用加热—冷凝收集验证富集，不把简单一次蒸发等同于完整多级精馏。

公开可用材料、温压范围、推荐通道尺度、是否支持真实热胀，以及当前未解析的效应。每条流程覆盖持续投料、停止输入、观察、取样、保存恢复，避免只有封闭初态演示。供能方块只提供有限功／热输入，产物和分离由共同模型产生。

### S8：按规模需求扩展区域与流场

先比较增大当前规则网格上限、同一区域稀疏分块和独立区域端口的真实收益。现有 shader 使用规则三维线性索引，跨块联立涉及压力、黏性、容量修正、输运、热学全部邻接与同步；不在单区域工艺完成前改造全链寻址。有限速率端口可连接确有独立运行语义的容器，需明确压差、流阻、携带能量和双方恢复；它与连续通道的差异须公开，不能用人为端口偷偷替代玩家的普通管道。

若规模场景确需连续计算分块，再实施以下职责。一个共享面只有一个规范身份和一次流量结算，两侧引用相反符号。压力迭代包含跨块项，输运包含跨块实际供体，热与扩散使用同一邻接。分块为存储和调度单位，连通活动组为同步推进单位；避免两块按不同步长各自近似压力后再事后对账。

优先由同一 GPU 执行上下文管理连通块及提交代，跨块通信作为普通设备读写处理。暂不增加多 GPU 或分布式求解。输入几何改变、活动组拆并、区块卸载和恢复均需迁移状态归属，不能重新初始化通道内物料。

完成条件：将同一通道放在分块内部和跨分块位置，流动及传热没有由分块位置产生的显著差异；接受流量只结算一次，保存成员完整，恢复继续。解除尺寸限制必须另给总活动量与显存预算，S8 本身不等于无限世界流体。

## 审阅和实现前需要裁决的细节

以下选项在编码前按目标场景和完整步成本形成明确决策，方案被选择后更新设计书及相应专题。

1. **气体离散：** 在 S2 局部气体基线内确定压力／温度耦合、混合格面惯性和小气容处理。若提出聚合替代，须说明如何保留目标空间差异，及可删除的完整计算工作。
2. **热膨胀与压力：** 选择能同时解释开放热膨胀和封闭受热增压的状态方程及压缩性。确定何时更新几何、压力和内能，以及浮力近似能否作为该方程的低温差形式。
3. **反应与相变：** 比较共享库存的联合局部求解与可控误差的分裂推进；定义共享反应物、相平衡、潜热、气压及受限容量怎样竞争，何时需要局部重复耦合。比较受热挥发且同时发生反应的场景，明确时间细化下的结果与性能。
4. **竞争反应：** 选择带速率的共同积分或具有明确热力学目标的受约束平衡；明确快速解离、有限速率和可逆反应如何同时参与。以反应列表重排、反应物耗尽与温度反馈检查结果的物理一致性，不能以固定顺序充当竞争规律。
5. **多组分相平衡与数据：** 确定首批可计算物质、温压与浓度范围、混合规则、汽液相平衡和固体溶解度；数据缺失时通过定义和查询暴露支持情况，保留状态和守恒，不静默替换为任意常数。
6. **跨区域协调：** S3 已确定区域持有普通墙热列和环境源汇拆装；S8 若启动，再裁决跨区域共享墙的唯一归属、流动协调者与可恢复共同提交，并估算活跃区域、邻接连接及持久化成本。

## 宏观验收与性能取舍

验收使用正常玩家入口和自动化场景，复用既有守恒、恢复及失败短重放；有 95% 把握的内容不重复检查。能通过自动化完成的场景不要求人工介入。涉及真实画面、复杂 `VoxelShape` 或跨游戏重启时，按验证指南提供单一场景和操作步骤。

| 场景 | 核心可观察结果与交接 |
|---|---|
| 方块水箱与通道 | 注水、绕障、排空和压力驱动流动持续发生；可分辨通道的墙摩擦有正确趋势，窄通道与解析限制可解释；容量、质量、动量与热收支闭合。 |
| 热膨胀和有限热墙 | 墙体与流体交换有限能量，冷却及拆装恢复后总账正确；若 S3 采用真实液体热胀，再检查开口容器体积变化与闭壳热压，否则明确保留浮力近似。 |
| 气体输送与液封 | 在串联容器、受限通道内注入气体，观察有限输运及温压变化；液封隔断、开启后恢复流通，组分与携带能量守恒。 |
| 混合和扩散 | 两种互溶液体经流动混合后停止，浓度梯度逐步减小；隔墙两侧保持隔离，加入油层后气液接触按几何变化；物种和内能闭合。 |
| 两组分蒸发冷凝 | 有限热源加热混合物，挥发性较高组分在蒸气和冷凝液中富集；冷却回收的物种、潜热与受热设备库存共同闭合；给定范围内步长细化趋势稳定。 |
| 反应与分离 | 两条反应竞争同一组分，调整温度或投料会改变产物比例；析出颗粒沉降、再接触液体后可溶解；重排定义顺序不改变物理选择，元素、质量和能量闭合。 |
| 跨区连续操作和恢复（仅 S8） | 若采用独立区域端口，检查双方库存只交接一次及未决事务恢复；若采用连续分块，检查切分位置不改变通道物理、共同代次和卸载行为。 |

性能按**相同仿真时长的连续完整步**衡量，计入几何、建表、输运、物性、热化学、提交及必要展示和世界交接。保留既有 64³ 切格与 32³ 颗粒原输入；新能力增加小型代表场景和对应完整成本。记录硬件、功能、网格、活动物种、接口数量、墙钟、GPU 时间、派发／同步、峰值显存和主要误差，按[验证指南](../maintenance/validation.md)登记。

64³、20 Hz 是待证明目标，已有功能约 35 ms 为全功能 50 ms 预留余量的工程目标；必须说明硬件、实际功能及精度，不能用减少模拟时长、关闭功能或缩小输入宣布达标。当一个能力引入全域多次扫描、频繁 CPU 等待、重复库存或每设备专用求解链时，先重新设计共享几何、稀疏活动和执行顺序；当成本主要来自确实需要的自由度时，比较可观察收益与误差，调整支持规模或采用经过说明的简化模型。结构性反例出现时整链换轨，最终只保留一套生产算法。

暂缓收益尚不明确或成本过高的能力：开放大气和海洋尺度全域求解、声波及高速可压缩细节、微观气泡群与成核动力学、复杂湍流谱、完整多组分高压非理想热力学、全化学网络、催化剂微观孔隙、弹塑性连续体和精细颗粒形貌。它们可在新增工艺确有可观察收益、具备物性数据和完整步预算后重新评审；颗粒沉降、有限传质、必要化学与基础相变属于上述必须交付能力。
