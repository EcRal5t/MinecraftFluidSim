# 当前实施计划

目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。采用适合玩法的粗尺度近似，守住物料与能量交接，集中共享规则，降低维护和理解成本。

本页维护当前交付和下一轮范围。模型、数据归属与代码入口见[设计书](../architecture/system-overview.md)，操作与运行命令见[验证指南](../maintenance/validation.md)，长期范围见[产品路线](product-roadmap.md)。

## 本轮工业玩法交付

本轮按[自由构造工业玩法计划](emergent-industrial-gameplay-plan.md)完成 P1—P6。物料箱与端口、阀门与传感器、世界方块及活塞耦合、筛分、固定表面吸附与催化，通过正式世界入口和共同 GPU 候选组成连续工艺。当前工作集中于三层蒸馏塔的回流开闭对照。

| 工作包 | 当前状态与剩余工作 |
|---|---|
| P1 物料箱与端口 | 三相有限批次、实际接触格、逐 tick 配额及持久事务已实现；持续投料统一由箱和端口承担 |
| P2 阀门与测量控制 | 五档真实开口、液位／温度／压力／流量测点及红石控制已实现；真实服务器控制与设置恢复已运行 |
| P3 世界动作与运动耦合 | 已完成世界方块与活塞交接、移动热墙、线／角冲量和轴向有限惯量；真实双阀泵送、闭格受阻与恢复续泵通过 |
| P4 筛与滤渣 | 粒径筛分、沉积阻力、真实排渣和清理后恢复流动已完成；有限冷墙结晶、实际收集与回投再溶解全程保持联合库存 |
| P5 固定表面 | 有限吸附库存、同面补充装填、拆装内能与接触催化已完成；连续穿透、再生再吸附、接触面积作用及封闭反应流程已运行 |
| P6 三维装置 | 共享布局与游戏建造入口已实现；连续控制、泵送、筛分结晶、吸附、催化、隔墙换热及单级蒸馏已完成；三层塔正在完成回流开闭对照 |

[工业装置操作规格](industrial-simulation-test-plan.md)规定 T01—T07 的构型、操作和可观察结果。每条职责链覆盖核心实现、调用方、正常操作、持久恢复和旧路径清理；针对实际失败修正对应机制，已有相关运行结果继续复用。

## 下一轮耗时工作

专项优化在本轮功能流程完整交付后集中开展。原 64³／0.5 m 完整生产步采用 50 ms 目标；同时整理 32³／256 颗粒、冷导入、容器编辑后重建、连续箱事务和长流程尖峰。物理推进、持久化、诊断导出与绘制分别计量。

出现规模成本失控时，按完整职责链替换算法、工作区布局或提交方式，合并重复规则并删除旧实现。空间精度优先沿现有统一网格与计算分块使用，是否采用 0.5 m／1 m 两级块状自适应网格由实际成本收益决定。

## 其他后续范围

展示工作包括普通渲染、Photon、Complementary 的画面、阴影、液下介质、显色、切换与重载，以及 GPU 绘制成本。原版玩法继续安排灭火、耕地灌溉和跨重启的游戏观察。区域动态扩容、独立区域合并、天然水体、冲刷、高温响应和能源系统按玩法收益另行交付。
