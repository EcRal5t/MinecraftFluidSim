### 当前整块替换：单元库存与全步联合结算

单元库存、MAC 动量与整批私有候选已替换生产采样点及逐笔全域事务。
相输运已改为固定开放连通分量上的粗单元有限体积计算，真实面扫掠限定跨格数量，统一数量结算守住真实容量。
八个微盒保存浮点液相占据，承担界面形状、通量偏好和气体来源；格内允许局部重排，逐微盒容量流图已删除。
粗网格 MAC 压力与单元整数库存继续共用；每个机械步进行一次有界有限体积推进，按实际供体库存分配质量、物种和内能。
动量按同一实际整数质量通量进行正权迎风混合，局部混合动能损失转热，与最终库存一次发布。
平方根质量中点、全域动量 CG 及高精度残量认证已删除。
删除库存输运后重新构造独立气片、再次求解来源资格的链路，保留已解析液塞、固定隔墙和有限孔流。
物质、物种、容量和热学账本继续精确核对。
正常跨格输运受实际面扫掠限制，固体预测位置给出实际排水量；外部固体插入采用明确的排水来源。
气体来源分配随实际干空间交接，有限气腔的库存与正容量一并保留。

- **液体库存与动量**：以 `(单元, 材料, 固定碰撞连通分量)` 保存质量整数、物种整数、库存体积与内能；MAC 面保存动量。
  持久微盒相占据提供标准 PLIC 与共同相面通量，气体来源随同一通量推进；局部输运直接分配当前供体库存，完整候选一次发布。
  删除生产步骤中的采样点到单元、面份额到新采样点、化学与内能整列重建；展示采样从已提交状态按需生成。
  单元平均温度和已解析速度梯度承担物理表现，未解析的格内温差、薄膜形状和细尺度运动允许平滑耗散，能量去向随转换结算。
- **气液相变**：按本步气腔收集接触单元的相变提议，联合处理库存、内能及饱和约束，一次分配整数批次，一次发布全部物相变化并准备拓扑后继。
  真实气腔容量、潜热、参考能与待处理机械功保持明确交接；时间分裂产生的一阶压力、温度误差由宏观响应评价。
- **有限孔流**：以状态方程储容和正孔口导通构造气腔网络的整体隐式通量，供体联合限制全部出边的物质和可携焓，成对提交同一通量。
  删除逐边寻找最大整数转移量时反复拆分库存、反演温度和重建全节点热账的路径；液封与有限孔口分别由图连接和导通系数表达。
- **正常后端步**：从已验证的权威内存列准备私有工作域，复用工作区；完整冷恢复继续验证存盘状态。
  正常步中的来源检查、候选计算与一次接管共同保持原子性，删除把普通每步执行组织成完整冷恢复的重复准备。

成本预期以消除重复的次数为依据：液体库存处理从多个数值采样点及两层份额分配改为逐单元、逐共享面一次处理；
相变拓扑从每个成功相变单元一次全域处理改为每个真实机械子步及联合相变后继各一次；
孔流从每条边的多次整数库存与热状态搜索改为一个稀疏网络求解及一次整数通量分配。
这些调整消除采样点数、相变单元数和逐边搜索次数的乘数，实际完整步仍按原 40/200 ms 预算验收。

先明确所替换职责的操作量，再完成生产调用迁移与旧路径删除，直接推进完整步生产预算。
有九成把握的改动跳过额外校验和测试；有具体未知风险时才用对应场景回答问题。
生产成本超出预算数倍时整块更换模型或数据流程，几何误差按可观测的宏观表现和是否发散评价。
当前共同主干已通过控制器与最大 demo 的完整步预算，原注液与 L 形连续恢复通过；沙床联合容量与后续综合流程继续推进，实际数据见验证指南。
原 5,000 步溃坝、完整容器、固定种子与盘上组合等待最终共同离散验收；运行状态及证据由验证指南维护。

## 精度与物理取舍

| 领域 | 交付要求 |
|---|---|
| 物质与容量 | 库存、物种、反应批次、单位换算及提交结算保留必要的整数与精确数量运算；物质转移按实际组成核对质量，容量遵守现有材料与占容模型。采样点数量和位置与化学整数份额解耦 |
| 几何 | 持久微盒相占据与标准 PLIC 提供湿干区域、共享开口和局部坡度，重建与积分采用浮点和标准离散。输运与气腔按粗单元固定开放连通分量结算，格内液膜、液滴允许简化形状或合并表示，物质、组分及携带内能完整交接 |
| 动量与流动 | 质量与动量使用一致通量；内部作用与反作用成对结算，外部反力明确。保持宏观惯性、旋转、冲击和分层，控制数值耗散；放弃单格高阶矩、全部亚格自旋及重采样前后动能逐项精确重现 |
| 气腔 | 按库存、实际容量与内能派生压力和温度，沿用现有状态方程与热容模型，处理压缩、膨胀、传热和相变。保持支持尺度内的液封、有限孔流及同格独立气腔，几何近似具有统一的开闭规则 |
| 能量 | 内能搬运、压力功、相变和反应热按现有热力学契约结算。新表示主动耗散的细尺度运动须明确能量去向并随转换结算，避免重复计入压力功或凭空补热；浮点误差与离散误差单独量化 |
| 事务 | 成功只提交一次；来源变化、无效输入与执行故障保留原状态。正常支持场景以实际完成为验收结果 |

生产热路径清理任意精度几何求交、积分、数值矩阵消元和高阶矩认证。当前已采用共同 MAC 与有限体积主干，`LiquidCellShape`、仿射压力分支及输运联合高阶矩反演已删除；
重采样协方差拟合、接触求解中的精确迭代及几何有理数权重认证已随调用迁移删除。必要的界面位置和流动信息由共同主干承担。选择能满足代表场景的最简单离散，低耗散传递按实测需要加入；
现有算法与内部表示仍可按连续运行和成本整体替换。

全域黏性、阻力与实体做功的热机械收支仍按产品路线安排；本轮引入或改写的表示转换、气腔做功及局部耗散随所属模块交付。M10 分别列出已结算能量与既有待完成项，禁止将数值能量残差整体补入内能来宣称闭合。

**当前入口：** `CellMacStage`、`CellMomentumTransport`、`MacMomentumAdvection` 及格面动量消费者。

**验收：** 常量流保持、静水稳定、宏观冲量与外部反力闭合；跨多个单元的旋转、惯性和冲击有合理持续时间与衰减。宏观角动量误差结合外部力矩量化；内部固定 rank、三轴亚格旋转零空间、二阶矩和单格最小动能反问题退出完成条件。局部算子对照服务于实际采用的离散，并与完整流程一起计时。

## M03 共同压力、黏性与气腔耦合

**当前入口：** `PressureSystem`、`PressureFaceGraph`、`PressureProjectionStage`、`LiquidViscosityStage`、`MechanicalStepPipeline`、`MechanicalStageAssembly`、`PressureBoundaryView`。

同代几何、质量与速度组装液体压力及黏性，固相惯性、阻力、占容和有限气腔响应按实际物理加入。纯液体与含固相区域共用主干及结果写回；远处加入无关固体保持局部液体的离散选择一致。

气腔库存、内能与容量通过实际可达来源交接；分裂、合并、完整迁移和多出口共用归属规则。保持液封与有限孔流，表示转换与物理压缩分别处理，避免重复做功。现有几何积分已采用浮点，继续简化分配权重处理与重复认证，并核对实际连通关系。

**验收：** 满液、自由面、薄层注液、切格、同格多气腔、微量气体及含颗粒流程连续推进；静水、黏性衰减、压缩升温与膨胀响应符合现有物性。保持现有共同 MAC 压力与黏性主干，完成耦合一致性与生产预算。

## M04 守恒输运与重采样

**验收：** 原注液、L 形第二步及后续流程持续完成；剪切交换、多密度分层、长距离输运和温度搬运保持预定物理表现。容量、物种、质量与内能交接守恒，宏观动量及数值耗散符合误差约定。
复用 `transport-moments`、`components`、`chemical-tails`、`handoff` 等入口；
`LiquidMacroscopicMotionValidation` 采用宏观位移、旋转和库存断言，其余采样与量子份额绑定的测试随表示调整。

## M10 集成验收与恢复产品主线

在同一构建完成原 600 步切格、5,000 步溃坝、完整分层/线性对流、沙床生命周期、正常操作序列、连续相变、分数抽取盘上往返及既有操作顺序/固定种子组合。原输入、装量和运行步数继续覆盖，新精度模型按下表调整断言：

| 验收对象 | 采用的要求 |
|---|---|
| 库存、物种、真实容量、热学结算、一次提交和恢复 | 保留相应物理与事务契约，精确账本继续精确核对 |
| 静水、分层、液封、气腔压缩、惯性、旋转和冲击 | 采用可观测量与有量纲或归一化误差，例如液面偏差、分层位移、压力/温度响应、总冲量、旋转衰减；先确定适用范围和容差，再运行完整场景 |
| 原粒子数、矩阵秩、形状对象相等、亚格高阶矩、预期拒绝 | 随实现替换删除或改为正常流程与宏观物理断言；原失败输入继续用于成功后继验证 |
| 完整步性能 | 沿用既有小控制器 40 ms、最大装量连续三步 200 ms 的生产预算判定，捕获、重建、求解和提交全部计时 |

容差由采用的离散、解析尺度和玩法要求给出，保留仍适用的旧物理精度要求。调整容差须说明对应的模型取舍，避免为通过某个失败样本反复放宽标准。

`production-live-budget` 报告代表负载、完整步耗时和各主要阶段成本，记录必要的规模与子步数。核对双轨及旧路径删除、恢复完整、设计书与专题准确，再恢复 D01。

## 验证与工作量控制

按完整职责链组织验证：开发中用相关短重放与必要编译定位问题，模块交付运行受影响的完整流程及预算，M10 汇总跨包验收。同一源码状态复用构建和已有有效结果，避免每次内部小改动重复全套测试。优先改写既有测试，新增常态测试对应新的失败模式。

离散改变时，相应调整残差定义、收敛尺度、迭代方式和子步策略，并核对连续场景误差及总成本。原 4096 子步和整数搜索结构随旧模型审查，禁止通过增加子步、搜索或迭代额度掩盖结构问题；40/200 ms 生产预算保持。

遇到表示冲突、双轨或规模失控时直接重新设计并替换。取消独立高阶空间研究和重复认证作为生产接入前置项；必要解析对照聚焦正在采用的离散。长期场景首次失败后复用短重放，修复完成再验证原流程。
