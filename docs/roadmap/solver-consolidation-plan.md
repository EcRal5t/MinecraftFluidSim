目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。本文保留当前交付状态与遗留事项。

## GPU 接入交付

2026-10-28，本轮按完整游戏操作职责链交付 GPU 演示。主模组默认使用 Vulkan，保留原场景规模、世界能力、实体耦合及连续三步超过 200 ms 暂停的规则。

已贯通场景初始化、调度、设备推进、常规观察与展示快照、宿主恢复、库存编辑和再次推进。控制器使用真实端口及容器 WAL；capture/takeover 复用采样、持久日志和恢复事务。演示与自动化共用初始化和操作逻辑，物理验收检查溃坝流动、油水分层、酸碱及生成水的当量、气压液位响应和相同初态的润湿差异。

液体容量分配与气腔压力预测共用状态，绝热功按实际接受的容积结算。气体交接保留同代成员与库存；环境交换和相间转移分别记账。质量与元素按整数守恒，能量使用工程浮点误差范围；常温场景同时检查整体水温，避免仅有账本闭合却出现异常热交换。

求解程序在世界启动阶段准备，区域编辑后的重导入复用编译与管线缓存。64³／50 ms 是待评估目标；本轮不继续进行广泛性能优化。命令、逐场景结果、完整步耗时范围和当前产物见[验证指南](../maintenance/validation.md#gpu-演示完整流程)。实机视觉、复杂 VoxelShape 与跨游戏重启仍按下列人工范围安排。

控制器界面与服务端交互已统一：普通玩家可暂停和继续；管理员在暂停后预览清理及移除；异步响应按目标和请求代次更新当前页面；空的气腔几何允许释放与移除。自动化覆盖协议、生命周期、GPU 容器操作及持久清空／排气／删除；实际窗口布局与输入观察保留在游戏内验收范围。
