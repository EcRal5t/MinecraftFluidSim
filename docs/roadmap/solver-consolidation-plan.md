# 求解器整合与维护改进计划

目标是让现有液体、气腔、颗粒和热化学计算具有一致的物理契约、明确的实现职责与可重复的验收入口，降低一次修改需要同时理解和调整的代码范围。保留 `api ← model ← solver ← app ← fabric` 的依赖方向，以及完整私有候选、区域 HEAD 和跨持久域 WAL 的提交规则。

当前起点为 `f991964`：路径整理已完成，前一提交 `e1b9629` 保存的仿射压力与双向输运处于待验收状态。执行前核对当前检出状态。产品顺序由 [产品路线](product-roadmap.md)维护，本计划细化恢复 D01 之前的求解器工作；完成后将稳定规则移入对应 architecture。

## 整合后的完成要求

1. 每个子步有明确来源状态、空间表示和速度结果，压力、写回、输运与碰撞能够逐项对应。
2. 精确库存、数值几何和显示数据各有明确含义；近似声明适用条件和可观测误差。
3. 气腔按真实微盒归属参与压力、相变、编辑与恢复，同格多个气腔分别保存库存与内能。
4. 颗粒体积核、液体面通量与压力反作用遵循同一离散，预览和发布共用联合占容计划。
5. 支持范围内的沉积、松弛、起动与反应能够完成；暂时不可表示的任务保留重试条件。
6. 物质编辑先准备完整候选，再发布相关列；拒绝时库存、账本、身份与调度任务符合各自契约。
7. 正式测试能从干净构建复现保留反例，默认生产负载满足原有完整步预算。
8. 代码精简落实为重复计算、重复规则和共享可变依赖的减少。

## M02 速度空间独立验证

**目标与入口：** 先确定所需速度自由度。涉及 `CellAffineVelocity`、`ExactCellAffineFit`、`CellAffineMacTransfer`、`CellAffineWallProjection`、`CellVelocityConstraintOperator`、`MarkerVelocityTransfer` 和 `MarkerPressureOperator`。

1. 明确粒子自由度、格内基底、面法向迹、惯性矩阵与压力行的关系；共同几何提供积分，实际载体质量提供惯性。同时校核速度积分与体积第一矩变化：完全湿润微盒内的零散度、零法向通量模式满足 `∫u dV = 0`。粒子积分与几何积分分别报告该等式的误差及支撑条件。静水对照核对均匀密度的空间前提、实际质量积分和几何压力功；来源矩或积分不相容的输入分别确定重建、近似误差或拒绝规则。
2. 用独立小矩阵验证平移、三轴刚体旋转、剪切及格内旋涡，检查整面迹约束与壁面是否过度约束内部运动。
3. 对单点、共线、近共面、薄层及断开分量分别确定可解析空间与压力源相容条件。设 `B` 为载体速度采样、`D` 为液体体积约束，在实际正质量下核对 `ker(B) ⊆ ker(D)`，等价的小矩阵检查为 `rank([B; D]) = rank(B)`；此条件成立后再考虑惯性零空间的消除。实际采样秩与舍入后的 Gram 秩分别检查。
4. 将现有仿射实现作为候选；若表示能力不足，再比较一次有明确自由度和成本的最小补充方案，记录选定表示及误差。面通量与内部运动分别验收，包括具有充分载体支撑的孤立微盒旋涡；补充内部模式时同步核对惯性零空间和压力相容性。
5. 分离常规数值路径与精度扩展路径，保留原方程及可验证舍入界，记录扩展触发数量和成本。

**验收：** 声明范围内同时通过常量保持、`C t = 0`、内部 `C R = 0`、转置虚功、静水与相容性对照；稀疏、薄层输入有明确处理规则；自由度有真实质量支撑。

**停止条件：** 独立模型无法同时满足表示能力和守恒时，保存反例、自由度计数与方案比较，结束生产扩张，下一增量从该设计问题继续。预条件优化以方程和相容性成立为前提。

## M03 液体与气腔压力生产接入

**目标与入口：** 实际载体速度、面速度和压力观察共享同一生产结果。涉及 `PressureSystem`、`MarkerPressureProjection`、`PressureProjectionStage`、`MechanicalStepPipeline`、`MechanicalStageAssembly`、`BodyForceStage`、`PressureBoundaryView` 和 `GridToParticleStage`。

1. 按 M02 的表示组装预测速度、已知气压、张力、壁面反力、液体约束与有限气腔储存项，每份物理作用有一个明确施加位置。
2. 按实际接触微盒映射气腔，同格多个节点分别组装；复用既有库存、状态方程和拓扑计划。
3. 从同一解生成载体速度、面速度与压力观察，预检实际写入精度；后续延拓和能量控制保持约束、冲量与力矩。
4. 明确预测、求解、发布和采样生命周期，覆盖位置编辑、恢复与表示切换后的旧场失效。
5. 迁移期间维护路径支持表与测试覆盖；最终共用液体基础算子，M05 加入颗粒未知量。

**验收：** 满液、部分充液柱、自由面、切格及同格多气腔通过真实流程；粒子冲量、力矩、压力功与再次映射连续性闭合。远处颗粒或 coherent 库存引发的路径差异在 M05 验收。

**验证：** 正式 Marker 入口、相关 `gas-liquid`、静水与张力短用例、过期候选和失败原子性。

## M04 输运重建与速度交接

**目标与入口：** 流出液体与其质量、运动量、组成和热量具有一致来源。涉及 `CellLiquidVolumeTransport`、`LiquidAffineFaceFlow`、`LiquidAffineSweepGeometry`、`ConservativeLiquidFlux`、`CellCarrierRemapPlan`、各矩与采样助手、`BallisticLiquidRemap` 和 `FlipParticleReseeder`。

1. 读取 M03 的同代速度表示及 M01 湿面几何，明确正反两个方向的出流与接收分量。
2. 延续共同正来源权重，结算体积、质量、动量、动能与空间矩；species 整数分配和热学反演复用既有规则，验证实际份额相容性。
3. 定义零通量、微量交换、完整出流、进出抵消、独立粒子到达和切格重映射各自保留的空间信息。
4. 将重建整理为输入汇总、份额分配、接收合并、积分点生成及最终预检，复用助手类并缩小 `CellCarrierRemapPlan` 的直接实现范围。
5. 分别量化空间近似、速度舍入、重建耗散与表示切换误差；精确库存和有误差的几何量分别验收。
6. 测量 `CellRemapTransportMoments` 的重复精确运算。相同微盒内来源共用出流权重时，评估先汇总原始微盒矩、再乘方向权重的等价形式，用精确基准证明结果与舍入一致后替换。

**验收：** 零净面流率的双向剪切正确交换；未运动方向空间惯性保留；材料质心及三轴旋转误差有界；容量、species 和内能闭合；输运及 reseed 保留后续压力所需支撑。

**验证：** `transport-moments`、剪切、旋转、`components`、`chemical-tails`、`handoff` 及热输运局部用例；长距离平移和 5,000 步场景用于集成关闭。

## M05 液体与颗粒共同压力离散

**目标与入口：** 孔隙变化、液体通量与颗粒反作用来自同一离散。涉及 `GranularPressureCoupling`、`GranularImplicitDrag`、`GranularCoupledPressureSolver`、`SweptGranularVolumeGradient`、`GranularMechanicalStage` 和 `PressureSystem`。

1. 在共同液体基础算子上加入颗粒实际惯性、体积变化和阻力，保持同一预测状态与正定线性子问题。
2. 统一连续核、孔隙面通量与压力作用的积分，覆盖完整核和外壳附近截断支撑。
3. 单独验证核结点零预测速度、压力后反向运动及碰撞改道，定义侧别选择、实际体积增量和收敛判据。
4. 单颗粒模型成立后接入多颗粒与有限气腔；同步平移、静水、成对冲量和功先于长运动验收。
5. 将颗粒、deposit 和 coherent 按各自职责作为附加占容或未知量接入共同空间模型。

**验收：** 内部同步平移保持相对静止；液固压力冲量与外部反力闭合；中性颗粒保持静水；反向运动的实际容量响应收敛；隔绝的远处库存保持目标液体分量结果和离散选择一致。

**验证：** 复用 `GranularCarrierValidation` 压力、虚功、阻力与静水用例，仅为新失败机制补场景。

## M06 联合占容与整数可表示性

**目标与入口：** 连续运动、整数固体与有限化学份额共同形成可发布状态。涉及 `GranularCouplingFields`、`GranularQuantizationError`、`GranularLiquidDisplacement`、通量、微面及恢复与编辑规划。

1. 将连续预测、最终 float 位置、SVQ 分配、液体通量和 species 份额纳入同一候选约束。
2. 固体整数份额与液体容量共同规划，保持精确 SVQ 总量，逐格报告连续几何表示差。
3. 预览、重建、恢复、初始化和增删共用分配规则或同一已提交分配数据；新原始列同步状态与 codec。
4. 区分连续离散误差、舍入、整数分配、供给不足和化学不可拆分，给出诊断及有限搜索工作量。
5. 用既有精确小域枚举检查可行解，再接入保存的高密颗粒台阶状态。

**验收：** 两格满液、3 SVQ 颗粒、相邻 float 位置变化的反例通过；可行解在预算内提交；失败保持原状态；捕获恢复保持容量解释。

## M07 活动颗粒与床层转换

**目标与入口：** 沉积、松弛和起动完成正常过程，空间质量与做功明确。涉及 `GranularSettlementGeometryPlan`、`GranularInventory`、`GranularDepositDynamics`、`GranularBedPotential`、`GranularBedShear` 和 `GranularTransitionStage`。

2. 复用跨接收单元的联合沉积闭包，将活动装填、最终床体及剩余颗粒合法性接入 M06。
3. 按实际来源和最终床层计算质心、势能、固定床冲量与耗散，保留暂时受限任务的重试条件。
4. 起动抬升位移与液体作用做功成对规划。必要的局部耗散热依赖纳入本包，全域热机械收支按产品路线独立推进。
5. 验收干式整桶沉积、湿沙床沉降/起动/再沉积，记录剩余活动库存与停滞原因。

**验收：** 有合法空间与能量来源时完成转换；质量第一矩、势能、冲量及相关能量闭合；平台、床层与切格保持真实可达性；预算耗尽后可继续。

**验证：** 复用沉积、床体几何、混材松弛和 `GranularBedWakeValidation`，保留完成时间与物理驱动条件。

## M08 反应与固液转移的空间信息

**目标与入口：** 库存重分配保留来源位置及运动量。涉及 `ChemicalReactionAllocation`、`ChemicalReactionStage`、`GranularReactionStage`、`GranularPhaseTransferEngine`、`PhaseChangeStageSupport`、合并及固液相变计划。

1. 由实际质量变化与位置规划质量第一矩、线动量、角动量及能量，保留 exact batch 与 species 规则。
2. 优先让多个现有载体承接空间信息；表示不足时评估必要的空间矩原始列，并定义恢复、碰撞与能量含义。
3. 分别覆盖共同速度、相反速度、三轴旋转、几何与数量受限；反应、析出、溶解和合并执行同一转移计划。
4. 明确生成位置改变的反力及做功来源，量化坐标与速度存储误差，联合验证正温和内能分配。

**验收：** 来源与接收共同闭合质量第一矩、线动量及角动量；失败保留库存与 dirty 任务；条件满足后正常执行；批次、组成、SVQ 和能量共同通过。

**验证：** 复用化学、颗粒反应、固液与合并测试，重点覆盖多来源相反速度反例。

## M09 编辑计划数值运算与代码职责

**目标与入口：** 用少量明确业务模块维护共同规则。涉及 `CarrierMutationCoordinator`、`FluidDomainInventoryTransactions`、单格替换、注液/提取气腔计划、`GasTopologyCoordinator`、`ThermalCellEnergyAssignment`、`ThermalCaloricInversion` 和 `ThermalDomainState`。

2. 存储预留、组成句柄准备与业务校验在首次发布前完成，提交执行已验证结果。
3. 核对基础列发布与 chemistry/thermal 后续发布之间的可失败操作，用既有原子性场景补齐真实遗漏。
4. 复用共同反演器、精确二进制数、单位换算和整数搜索，将实质重复的运算归入对应模块。
5. 按实测重复工作精简几何重建、精确矩求值与来源快照，保持一般比例的精确含义和舍入规则。

**验收：** 每个共同规则有明确入口，职责抽取实际减少跨模块字段访问或重复实现；相关编辑通过完整来源检查、失败保持状态和成功一次提交的对照。

| 层级 | 使用时点 | 内容 |
|---|---|---|
| 短契约 | 每个小增量 | 解析小矩阵、最小反例、身份及失败原子性，记录单例耗时 |

| 扩展研究 | 产品路线对应阶段 | 亚格压力、空间气体、完整热机械收支和更大区域分别验收 |

## 工作包执行规则

每包开始明确失败机制、代码入口、依赖状态、验收用例和预计验证成本。一次推进一个实现目标，交付可独立复现的小增量并适时提交。

结束时保留简短结果：提交号、入口、通过用例、失败输入和下一依赖。相邻问题映射到现有工作包或产品路线，按依赖顺序处理。

同一设计连续两次被独立反例否定时，先完成自由度、守恒、可表示性与成本比较，再开始下一方案。局部修补以共同模型成立为前提。

普通操作、已声明高压高温能力和现有持久化契约的反例进入对应包；范围扩展按产品路线另列。各包保持现有数量、误差和成本条件的物理依据。
