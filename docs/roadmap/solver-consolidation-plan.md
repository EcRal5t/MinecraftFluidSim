# 当前实施计划

目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。采用适合玩法的粗尺度近似，守住物料与能量交接，集中共享规则，降低维护和理解成本。

本页维护当前交付和下一轮范围。模型、数据归属与代码入口见[设计书](../architecture/system-overview.md)，操作与运行命令见[验证指南](../maintenance/validation.md)，长期范围见[产品路线](product-roadmap.md)。

## 工艺效能与验证反馈

蒸馏先使用生产物性生成单次和多次理想平衡参照，再评价实际气液接触、有限冷源、排气损失和回收比例。当前塔层采用池面接触；各层的组成、温度与相间转移决定有效分离能力。换热按实际出流的有效度、冷热容量流率和墙体蓄热评价。完整流程的方向性变化和工艺效能分别记录。

日常定位先用单工况短诊断，明确总步数并输出准备、端口事务、物理推进和观察耗时。完整工艺运行安排在相关机制和操作流程稳定后；已通过且未受影响的结果继续复用。成熟状态的局部故障沿现有 checkpoint 短重放定位，完整工况比较保留实际容器、控制与收支状态。

当前三层塔启动段的主要成本集中于端口事务及查询。每笔操作分别导出区域状态、准备宿主候选、保存 checkpoint 并导入设备，下一步按完整职责链集中同一代读取与多端口候选，保持实际接受量和 WAL 恢复。原 64³／0.5 m 完整生产步继续采用 50 ms 目标；同时整理 32³／256 颗粒、冷导入、容器编辑后重建、连续箱事务和长流程尖峰。物理推进、持久化、诊断导出与绘制分别计量。

出现规模成本失控时，按完整职责链替换算法、工作区布局或提交方式，合并重复规则并删除旧实现。空间精度优先沿现有统一网格与计算分块使用，是否采用 0.5 m／1 m 两级块状自适应网格由实际成本收益决定。

## 客户端展示与测量

客户端使用持久顶点与索引缓冲，相机移动重排透明索引；表面两侧通过独立朝向保留材质。主画面和阴影分别统计 GPU 绘制耗时，资源重载与区域生命周期统一使缓存失效。普通渲染、Photon、Complementary 的实机结果及成本集中记录在验证指南。

容器样品分析覆盖液体、颗粒与气体的实际组成、分数、浓度和热状态，支持同维度会话内的两份样品比较。传感器历史沿既有测量采样，以实际仿真时长绘图，暂停与不可用期间断线。两项功能的只读流程、协议及生命周期共同交付。

工业方块与工具已提供独立像素贴图，传感器测量方向和接口进出料随实际状态显示。稳定工具、容器及工业设备由原版材料合成，并通过配方书解锁；物料箱沿真实容器槽完成放入、取回、进出料与拆除。多人观察按客户端会话隔离，并覆盖关闭、重连和换维；自动化证据集中在验证指南。

Create 联动基础包括物料箱的 Fabric `ItemStorage`、测点只读摘要和外部规定平移结构。整只容器的模拟、嵌套事务、回滚和提交共用真实槽位，未决 WAL 及开放事务保护箱体；显示复用 MMM 已提交观测，运动段按 MMM 接受步消费并保留稳定分片身份。源码核对及测试侧提供器覆盖同步、分段、拒绝重试和恢复。后续按 [Create 适配计划](create-compatibility-plan.md) 完成流体交接、静态装拆、旋转及动力反馈；真实 Create 类型绑定等待匹配 26.2 / Fabric 的版本。
