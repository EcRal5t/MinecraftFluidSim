# 当前实施计划

目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。耗时优先，架构精简与算法泛用其次；接受适合玩法的粗尺度近似，守住物理守恒。

本页维护下一轮交付、依赖和未完成事项。现有模型与代码入口见[设计书](../architecture/system-overview.md)，命令与预算见[验证指南](../maintenance/validation.md)，长期范围见[产品路线](product-roadmap.md)。

## 后续工业玩法安排

按[自由构造工业玩法计划](emergent-industrial-gameplay-plan.md)推进 P0—P6：颗粒与长流程成本整理、物料箱和持续进出料、阀门与测量控制、世界方块和活塞适配、筛分、固定表面吸附与催化，最后交付三维组合工艺。每轮覆盖实现、调用方、正常操作、持久恢复和旧路径清理。

[工业装置测试规格](industrial-simulation-test-plan.md)规定连续流控制、活塞泵送、筛分结晶、换热、蒸馏、吸附再生和接触催化。按实际功能依赖分批加入现有测试，P1／P2 的宿主交互与事务可先推进；数值扩展同时满足受影响场景的预算。

冲刷、高温响应、天然水体及能源系统按产品收益另行选择。

## 交付要求

按完整职责链替换成本失控的结构。原 64³／0.5 m 完整生产步继续采用 50 ms 预算；颗粒、冷导入、编辑和世界绘制分别计量。复用已有构建和相关通过结果，仅对具体新增风险选择验证。视觉、复杂方块碰撞和跨游戏重启使用单一人工场景，提供操作及预期结果。
