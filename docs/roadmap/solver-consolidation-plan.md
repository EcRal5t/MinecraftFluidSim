# 当前实施计划：求解器整合

目标是以精简、通用的架构承载可玩的工业流体仿真，大幅降低维护与排障成本。纯液体与含固相区域共用液体几何、质量与动量输运、压力和黏性主干；颗粒、固体占容、气腔与热化学通过明确的耦合项和守恒交接参与计算。进度以正常流程连续运行、完整步成本和旧路径删除衡量。

本页统一维护当前进度、下一轮职责链、精度取舍及 M10 完成条件。[当前设计书](../architecture/system-overview.md)维护模型、跨模块契约与代码索引，[验证指南](../maintenance/validation.md)维护运行证据，
[产品路线](product-roadmap.md)保存后续阶段与长期验收目标。旧内部表示及其精确矩约束按本计划调整，保留 `api ← model ← solver ← app ← fabric`、完整私有候选、区域 HEAD 与跨持久域 WAL 的职责。

## 流体显色职责链

真实材料、物种、质量余量、体积与内能沿共同库存和事务处理。化学容器及转移账本按材料聚合，显示设置由客户端持有。

组分、pH、温度显色由客户端设置统一选择，默认组分。探针打开控制器界面后可进入显色设置，调整固定温度范围并查看图例；模式与色带改变复用当前快照网格，暂停区域立即换色。
pH 使用适用水相的体积与酸碱数量，逐相传输并区分中性和无数据；温度使用同代服务端凝聚相单元展示值。

共同主干的审查整改和空气成分化均已完成。显色验证与视觉待确认场景见[验证指南](../maintenance/validation.md#流体显色模式)。

## D02 网格、基础材质与 Iris 渲染

**状态：实现已接入，游戏内兼容表现待观察。** 凸片共享面生成一次，双侧材料和相机介质共用几何。液体及颗粒采用纹理、实际光照、法线和单批透明排序；诊断色带使用独立颜色管线。Iris 26.2 的材料映射、透明阴影和水下介质钩子集中实现，额外水面位移设置已登记。普通渲染与两个光影包的实际画面证据归 D03。

2. **基础材质**：补齐纹理坐标、光照和材料外观，处理透明排序、深度、剔除与液面内外观察。替换生产液面的 `DEBUG_FILLED_BOX` 和固定朝向明暗；调试外壳、气腔覆盖图保持独立绘制职责。

5. **生命周期与清理**：处理光影切换、资源重载、区域移除及 GPU 资源释放；删除旧网格启发式、重复材质规则和失去调用的绘制路径。

### 审阅整改的完整职责链

- **共同输运**：固定孔隙分量共享已接受通量，材料份额在容量结算后分配，消除少数相及低速流的固定取整死区。气体来源读取最终接受的液体通量。
- **自由面惯性**：没有解析湿接触的格面与同一开放单元内的同轴支撑共享速度，按实际质量与动量合并控制体，速度方差转热；库存继续积累和输运。
- **压力与液封**：固定床面孔隙率与 MAC 双单元惯量采用同一体积平均；液相查询和持久状态保存实际平均压力。气体开口按实际共享干区建立，未解析微量液体保留库存及携带能量，周围气体端口采用单元尺度近似。
- **状态准备**：相占据与面惯量跟随实际库存和几何变化；凝聚态物性与 LTE 按液体、颗粒修订准备，删除每步手动失效及重复统计。速度观察按需准备，气腔初始化留在明确的物理准备时点。
- **墙面交接**：正常输运、编辑、注液、颗粒排水与相变在最终动量上施加静止墙约束；反冲显式登记，停止动能转入同一库存候选的内能。
- **气腔实际容量**：气片存在性、几何缓存更新与热力学容量共用开放分量的 `pore−Stock`。满液分量直接生成全液几何，低于 PLIC 分辨率的正干容携带自身真实体积；拓扑显式保存整个分量的气体归属。
- **热化学**：复杂热容曲线的接触量具有正响应；反应按库存与能量允许的整数批次推进，受限余量继续等待；汽化按实际携走内能限定批次。
- **完整步成本**：来源分组与单元目标桶替代多层临时 Map，库存汇总和实际气容按不可变行共享；单材料分段热容直接反演，颗粒准入、沉积及碰撞工作区随实际数量增长。
- **共同压力算子**：液体面、颗粒和气体储容一次组装同一 CSR，PCG 与 IC(0) 共用全部耦合项；删除六邻近似矩阵及每次迭代的面收集、散射。
- **气体空间与归属**：每个固定开放分量保存一个干区对象和节点归属，接口、来源及容量沿同一分量交接；删除常驻微盒对象、微盒节点列和独立微盒容量模块，微盒视图及存盘索引按需派生。
- **相变准备与热写入**：候选复用单元载体索引和参考能，恒定熔点直接比较温度；气腔压力、温度、热容统一采样。固体能量目标在准备阶段匹配，整批热账一次汇总与发布，删除提交阶段的重复全域扫描。
- **数量与内能分配**：每个来源共用质量与物种份额准备，库存路由按普通双精度比例分配，最大份额承接整数余量；内能采用浮点分份和补偿求和，最终存储值一次精确汇总。真实机械热与数值舍入分别入账。局部热平衡一次生成载体内能，最大热容承接存储余量，删除反复选主元与逐载体温差认证。
- **跨相发布与恢复**：蒸发来源进入实际新生气容；颗粒起动先准备共同液流视图，形态转换后统一排水和发布；外部连续固体插入与热恢复均先准备完整私有后继，再共同提交。
