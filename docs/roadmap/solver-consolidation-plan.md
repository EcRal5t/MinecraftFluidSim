# 当前实施计划

目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。采用适合玩法的粗尺度近似，守住物料与能量交接，集中共享规则，降低维护和理解成本。

本页维护当前交付和下一轮范围。模型、数据归属与代码入口见[设计书](../architecture/system-overview.md)，操作与运行命令见[验证指南](../maintenance/validation.md)，长期范围见[产品路线](product-roadmap.md)。

## 空间选区与环境热场

[空间选区与环境热场方案](region-and-environment-heat-plan.md)的生产职责链已实现：探针指定两个角点并预览、确认创建，普通方块的碰撞决定流体空间。区域由 UUID 和名称标识，探针与过程传感器负责状态、操作和红石测量；演示和物料接口使用同一选区流程。原版水体通过世界归属事务接管和归还。

液体或颗粒接近计算空间外缘时，设备观察沿实际开放面给出扩展方向，外侧实体墙阻断该方向。区域按计算块扩展，候选迁移物质、动量、几何和待处理状态，采样新增方块及外邻面，并交接环境空气与新增原版水；预算、区块或区域重叠阻碍扩展时暂停并提供原因。用户处理条件后可刷新重试。

墙体和环境空气由维度级世界热场持有，邻近区域通过共享库存传热。环境内部按低频面交换推进，区域接触和开放气流随已接受的物理步骤交接热量；材料属性、绝热方块、设备、共同候选及世界 checkpoint 沿同一流程使用。控制器洪泛找腔、专用外壳判定及按区域重复保存普通墙的路径已删除。

验证继续以真实流体—墙体—有限空气和开放气流场景为入口，核对理论温度曲线、热流及完整物质和能量收支。构建、设备验证及完整步成本的结果集中记录在[验证指南](../maintenance/validation.md#environment-thermal-cost)。

## 工艺效能与验证反馈

各工艺按实际状态量建立定量参照：阀门与活塞核对控制体收支、扫掠容量和压力功，筛分比较粒径与孔径，结晶比较温度相关溶解度与有限速率析出，吸附比较局部分压下的占位和交换速率，反应比较有限时间动力学解析解。蒸馏采用小持液量、短气路的两次批式操作，按实际收集量进行 Rayleigh 平衡切割参照；第一次实际馏分携带组成与内能进入第二台。逆流换热采用真实窄通道和有限铜壁，以实际持液、流量、出口温升和蓄热释放评价，并列记录 ε-NTU 参照。液体端口按重力方向优先选择较低的可容纳接触格，压力传感器按实际开放体积加权。完整验证按馏分目标或温升目标结束，铜壁与石墙采用相同观察时长。

日常定位先用单工况短诊断，明确总步数并输出准备、端口事务、物理推进和观察耗时。完整工艺运行安排在相关机制和操作流程稳定后；已通过且未受影响的结果继续复用。完整工况比较保留实际容器、控制与收支状态，持久化与恢复由专门的实际事务场景检查。

单笔容器操作的接触选择、请求解析与执行共用同一代宿主候选，公开预览与正式提交分别持有各自候选。工业夹具批量安装固定几何；换热与蒸馏每个 tick 的端口操作顺序执行共同生产计划，共用一个宿主候选并统一提交，T01 承担真实 WAL、checkpoint 和恢复。原 64³／0.5 m 完整生产步继续采用 50 ms 目标；32³／256 颗粒、冷导入、容器编辑后重建、游戏端口持久事务和长流程尖峰分别计量。验证夹具提速与游戏运行成本分别记录。

出现规模成本失控时，按完整职责链替换算法、工作区布局或提交方式，合并重复规则并删除旧实现。空间精度优先沿现有统一网格与计算分块使用，是否采用 0.5 m／1 m 两级块状自适应网格由实际成本收益决定。

## 计算链简化与耗时

相变按全部活动格的实际供体、容量、内能与平衡状态接受物料。气液接触依次处理同格界面与相邻配对，每轮更新库存和携带内能并结算重力功；跨格转出与表面吸附共同受步初液气质量限制，本步流入质量从下一步参与转出。整批按已接受质量一次结算共同面动量与混合热，气液物料和能量沿同一候选交接。凝固和熔化先按平衡状态求转换需求，再检查实际容量与能量，按可接受批次更新库存。

工作区按执行阶段复用临时列，流动、导热和反应共用暂存空间，库存、持久进度与最终账目独立保存。液体反应与相变共用物种行；气液交换保留未发布液相行，凝固按当前行的实际组成与内能检查活动并继续处理，最后统一组装、检查容量和发布，前后阶段分别记录能量审计。`VulkanRegionReactions` 统一录制和调度热化学阶段，导热、相变与液相行使用阶段专用管线；导热接触图容量反馈汇总全部热浴需求。气液接触合并提案与接受量计算，接收库存和热量独立结算。气体压力功同格更新热状态和共同状态方程；黏性与气体输运按阶段使用专用管线。固液索引按实际规则分配，气体路由从库存推导质量余项；容量不足时重建候选。

颗粒与运动体改变占容后，设备沿源开放面执行多源搜索，生成关闭格目的地及统一的出入索引。搜索队列计数合入既有提交反馈，实际搜索期间回读小计数；整域几何下载、宿主搜索和整表上传路径已删除。普通网格索引在冷导入时初始化，后续同代候选复用有效路由。墙体环境导热、展示与外部结构继续使用共同生产入口。

64³／0.5 m 完整生产步以 50 ms 为预算。独占设备预热 5 步后连续测量 50 步，中位墙钟 45.328 ms、P95 49.108 ms、最大 60.878 ms，48 步不超过 50 ms；平均 GPU 时间 42.283 ms，每步推进 0.05 s 且均为单子步，上传为 0、平均回读 198.6 B，设备占用 4306.7 MiB。最大值对应 GPU 41.331 ms、墙钟等待 56.180 ms，另一个超时步为 50.287 ms。环境热场完整步普通耦合平均 37.7141 ms、P95 40.2814 ms，含扩散平均 38.7908 ms、P95 40.5204 ms。后续关注宿主等待尾延迟；32³／256 颗粒输入独立计量。

## 薄壁管道

金属、绝热、玻璃与绝热玻璃管，以及管阀和管筛，已接入独立有限管腔、真实几何、区域端口和世界环境热场。相邻管段按压差与高差交换库存，气液相变和床载沿同一有限候选结算；管道与普通区域共享材料定义、物种和能量参考。区块卸载冻结对应管段，管网与区域、环境共同存档，透明管显示已接受的液层与床体。模型、操作与验证入口见[薄壁管道](../architecture/physical-pipes.md)。

## 客户端展示与测量

客户端使用持久顶点与索引缓冲，相机移动重排透明索引；表面两侧通过独立朝向保留材质。主画面和阴影分别统计 GPU 绘制耗时，资源重载与区域生命周期统一使缓存失效。普通渲染、Photon、Complementary 的实机结果及成本集中记录在验证指南。

容器样品分析覆盖液体、颗粒与气体的实际组成、分数、浓度和热状态，支持同维度会话内的两份样品比较。传感器历史沿既有测量采样，以实际仿真时长绘图，暂停与不可用期间断线。两项功能的只读流程、协议及生命周期共同交付。

工业方块与工具已提供独立像素贴图，传感器测量方向和接口进出料随实际状态显示。稳定工具、容器及工业设备由原版材料合成，并通过配方书解锁；物料箱沿真实容器槽完成放入、取回、进出料与拆除。多人观察按客户端会话隔离，并覆盖关闭、重连和换维；自动化证据集中在验证指南。

Create 联动基础包括物料箱的 Fabric `ItemStorage`、测点只读摘要、外部规定平移结构及原位装配／拆解。整只容器的模拟、嵌套事务、回滚和提交共用真实槽位，未决 WAL 及开放事务保护箱体；显示复用 MMM 已提交观测，运动段按 MMM 接受步消费并保留稳定分片身份。源码核对及测试侧提供器覆盖同步、分段、拒绝重试和恢复。后续按 [Create 适配计划](create-compatibility-plan.md) 完成流体交接、跨区域结构库存交接、旋转及动力反馈；真实 Create 类型绑定等待匹配 26.2 / Fabric 的版本。
