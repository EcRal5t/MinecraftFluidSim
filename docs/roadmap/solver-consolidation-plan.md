# 求解器整合与维护改进计划

目标是以精简、通用的架构承载可玩的工业流体仿真，大幅降低维护与排障成本。纯液体与含固相区域共用液体几何、质量与动量输运、压力和黏性主干；颗粒、固体占容、气腔与热化学通过明确的耦合项和守恒交接参与计算。进度以正常流程连续运行、完整步成本和旧路径删除衡量。

[产品路线](product-roadmap.md)安排产品阶段；本计划规定本轮整合的精度取舍、依赖和 M10 完成条件。[流体求解器](../architecture/fluid-solver.md)等 architecture 记录当前实现，随模块替换同步更新；旧内部表示及其精确矩约束按本计划调整。保留 `api ← model ← solver ← app ← fabric`、完整私有候选、区域 HEAD 与跨持久域 WAL 的职责。代码入口与命令见[维护路由](../maintenance/routing.md)和[验证指南](../maintenance/validation.md)。

本次调整前的原文见[2026-10-17 备份](../archive/proposals/solver-consolidation-plan-2026-10-17.md)。

## 精度与物理取舍

| 领域 | 交付要求 |
|---|---|
| 物质与容量 | 库存、物种、反应批次、单位换算及提交结算保留必要的整数与精确数量运算；物质转移按实际组成核对质量，容量遵守现有材料与占容模型。采样点数量和位置与化学整数份额解耦 |
| 几何 | PLIC 或同等成本的界面表示提供湿干区域、共享开口和局部坡度，重建与积分采用浮点和标准离散。未解析液滴、薄层允许简化形状或合并表示，物质、组分及携带内能完整交接 |
| 动量与流动 | 质量与动量使用一致通量；内部作用与反作用成对结算，外部反力明确。保持宏观惯性、旋转、冲击和分层，控制数值耗散；放弃单格高阶矩、全部亚格自旋及重采样前后动能逐项精确重现 |
| 气腔 | 按库存、实际容量与内能派生压力和温度，沿用现有状态方程与热容模型，处理压缩、膨胀、传热和相变。保持支持尺度内的液封、有限孔流及同格独立气腔，几何近似具有统一的开闭规则 |
| 能量 | 内能搬运、压力功、相变和反应热按现有热力学契约结算。新表示主动耗散的细尺度运动须明确能量去向并随转换结算，避免重复计入压力功或凭空补热；浮点误差与离散误差单独量化 |
| 事务 | 成功只提交一次；来源变化、无效输入与执行故障保留原状态。正常支持场景以实际完成为验收结果 |

生产热路径删除任意精度几何求交、积分、矩阵消元和高阶矩认证。旧的 `LiquidCellShape`、仿射压力空间、联合空间矩/机械矩拟合均可整块替换；必要的界面位置和流动信息由新主干承担。选择能满足代表场景的最简单离散，低耗散传递按实测需要加入。标准 MAC、有限体积或轻量仿射传递可作为实现选择，具体算法由共同主干的连续运行与成本决定。

全域黏性、阻力与实体做功的热机械收支仍按产品路线安排；本轮引入或改写的表示转换、气腔做功及局部耗散随所属模块交付。M10 分别列出已结算能量与既有待完成项，禁止将数值能量残差整体补入内能来宣称闭合。

## 当前需要整合的部分

| 当前结构 | 本轮交付 |
|---|---|
| `PressureSystem`、`LiquidViscosityStage` 按有无固相切换液体算法 | 一套液体压力与黏性主干，局部耦合项随实际物相加入 |
| 压力湿几何、载体惯性和输运重建互相施加高阶矩约束 | 明确几何、库存、动量的权威数据与离散关系，减少相互反演 |
| 常速度平移保存形状，一般场后继尚未完成 | 通用输运及气腔交接连续运行，删除平移与一般场分别维护的路径 |
| 几何积分、重采样和机械拟合使用任意精度与联合认证 | 浮点几何和成本可控的守恒分配，保留账本所需精确运算 |
| 编辑入口和 `FluidDomain` 共享状态存在重复规则 | 沿实际业务集中准备、占容、热账与提交，减少跨模块字段依赖 |

M00 的正式入口和失败分类继续复用。M01–M08 的既有局部结果按新模型复核；M09 随职责链一起完成。既有局部测试通过记录保留其被测范围，M10 以替换后的同一构建验收。此次文档调整尚未完成生产算法替换。

## 工作包与依赖

M00–M10 是职责与验收索引。每轮交付一个完整生产模块或一条完整职责链，可跨多个 M 包，覆盖实现、调用迁移、连续运行与旧路径删除。数百至上千行集中删改可按实际需要进行，代码行数不作成果指标。

| 顺序 | 交付与工作包 | 完成条件 |
|---|---|---|
| 1 | 共同液体主干，M01–M04，并接入 M05/M06 必需耦合及 M09 提交 | 压力、黏性、输运和气腔后继接通；原注液、L 形一般场及含固相连续步实际运行；纯液体与含固相的整体算法分叉删除 |
| 2 | 固相完整生命周期，完成 M05–M07，持续应用 M09 | 满液插沙、高密颗粒、沉降—起动—再沉积及恢复后继完成，占容与液体位移规则集中 |
| 3 | 反应与相变交接，M08 及相关 M03/M06/M09 | 反应、析出、溶解与连续相变复用共同输运、占容和热学提交，删除专用重复路径 |
| 4 | M10 综合验收 | 同构建完成长期流程、恢复和生产预算，文档与实现一致，恢复 D01 |

第一段从最小完整流程直接切入共同主干：液体新表示同时带入颗粒占容/反作用和有限气腔，尽早暴露耦合冲突。M07 依赖共同输运与占容；M08 依赖相应转移和气腔交接；独立的编辑去重随其所属模块完成。

## 下一轮完整交付

围绕原注液、L 形一般速度场与沙床连续步，替换阻塞共同压力 → 输运 → 气腔更新 → 提交 → 下一步的表示链。先确定几何、库存、速度/动量分别保存什么，再迁移这条链上的消费者；取消强制复用扫掠高阶矩、联合机械矩拟合和专用形状的要求。

实现阶段复用短重放定位；交付阶段恢复相应正常流程的完整步数，包含恢复后的下一步及同输入的有固相对照。压力与黏性旧分支、专用形状规则、淘汰的拟合和认证随消费者迁移一起删除。临时实现切换仅用于开发过程，完整模块交付时清理。

从首个连续运行开始测量完整步成本。若结构性反例或规模成本表明方案不成立，立即调整离散与数据表示，并继续完成这条职责链；安全拒绝、回滚成功或首步加速单独记录其用途。每轮汇报统一的主干、删除的旧路径、跑通的原失败流程、完整步耗时及仍未完成的行为。

## M00 当前基线与正式验证入口

复用正式 Marker、载体修改、液体输运、颗粒和切格入口，以及现有首次失败快照。区分通过、断言失败、配置错误、超时和主动中止。测试选择器沿既有入口维护，过时的内部断言随模型替换一起改写。

## M01 共同空间输入与状态身份

**当前入口：** `PhaseLiquidGeometryEdit`、`PlicComponentGeometry`、`LiquidPressureGeometry`、`GasRuntimeGeometry`、`CellRemapMicroTopology`、`CellRemapPorts`。

统一压力湿面、气体干面、输运开孔和固体占容的几何来源，明确库存、位置、组成和碰撞改变后的失效规则。库存与数值采样采用各自合适的表示，数值节点可增减、合并；第一矩等几何信息按选定离散需要保留，删除将完整高阶矩正可表示性作为普通操作前提的约束。

气腔和液体归属遵守实际通路，支持尺度内的隔墙、液封及断开气腔可区分。浮点几何的容量、开孔和共享面采用一致规则，避免微小舍入使相邻单元给出相反拓扑。

**验收：** 未来候选、实际发布与恢复重建一致；正常输运能生成下一步几何。复用 `air-cavity`、`components`、未来几何及恢复容量场景，核对液封开闭、容量和归属，形状误差按新精度约定评价。

## M02 共同动量表示与低耗散传递

**当前入口：** `CellAffineVelocity`、`CellAffineFit`、`CellAffineMacTransfer`、`CellAffineWallProjection`、`CellVelocityConstraintOperator` 及速度传递消费者。

选择与共同几何、质量分配和压力算子相容的速度/动量表示，生产数据流明确权威速度及各采样视图。低耗散机制以常量流、旋转、射流和分层的实际表现决定复杂度。近壁和薄层处理采用成本可控的离散，清理为保留不可解析亚格运动而增加的自由度、求逆和认证。

**验收：** 常量流保持、静水稳定、宏观冲量与外部反力闭合；跨多个单元的旋转、惯性和冲击有合理持续时间与衰减。宏观角动量误差结合外部力矩量化；内部固定 rank、三轴亚格旋转零空间、二阶矩和单格最小动能反问题退出完成条件。局部算子对照服务于实际采用的离散，并与完整流程一起计时。

## M03 共同压力、黏性与气腔耦合

**当前入口：** `PressureSystem`、`MarkerPressureProjection`、`PressureProjectionStage`、`LiquidViscosityStage`、`MechanicalStepPipeline`、`MechanicalStageAssembly`、`PressureBoundaryView`。

同代几何、质量与速度组装液体压力及黏性，固相惯性、阻力、占容和有限气腔响应按实际物理加入。纯液体与含固相区域共用主干及结果写回；远处加入无关固体保持局部液体的离散选择一致。

气腔库存、内能与容量通过实际可达来源交接；分裂、合并、完整迁移和多出口共用归属规则。保持液封与有限孔流，表示转换与物理压缩分别处理，避免重复做功。用浮点几何及连通关系替换任意精度多面体重叠认证。

**验收：** 满液、自由面、薄层注液、切格、同格多气腔、微量气体及含颗粒流程连续推进；静水、黏性衰减、压缩升温与膨胀响应符合现有物性。`PressureSystem` 和 `LiquidViscosityStage` 按区域有无固相整体切换算法的路径删除。

## M04 守恒输运与重采样

**当前入口：** `CellLiquidVolumeTransport`、`LiquidAffineFaceFlow`、`LiquidAffineSweepGeometry`、`ConservativeLiquidFlux`、`CellCarrierRemapPlan`、`BallisticLiquidRemap`、`FlipParticleReseeder`。

供体扣除、出口、到达与保留份额由共同通量分配产生，质量与动量一致输运，物种及内能随实际物质交接。几何采样与整数账本解耦，统一处理微量尾数、完全流出、同时进出、跨格到达及切格排液。

重建以连续计算所需的信息为限。删除同时精确重现空间协方差、位置—速度交叉矩、亚格自旋和动能的联合反演；未解析形状可以合并，耗散遵守本计划的能量规则。常速度平移与一般速度场共用后继生成规则。

**验收：** 原注液、L 形第二步及后续流程实际完成；剪切交换、多密度分层、长距离输运和温度搬运保持预定物理表现。容量、物种、质量与内能交接守恒，宏观动量及数值耗散符合误差约定。复用 `transport-moments`、`components`、`chemical-tails`、`handoff` 等入口，将 `joint-moments` 中仍有价值的物理场景迁入新断言。

## M05 液体与颗粒共同压力离散

**当前入口：** `GranularPressureCoupling`、`GranularImplicitDrag`、`GranularCoupledPressureSolver`、`SweptGranularVolumeGradient`、`GranularMechanicalStage`。

颗粒实际惯性、占容变化、压力反作用和阻力接入共同液体主干。物相专有运动规律集中在对应耦合模块，保持成对冲量和一致的体积变化。现有核函数及求解形式可随共同离散调整。

**验收：** 中性浮力颗粒静水平衡、液固共同平移、压力后反向运动、近墙与高密颗粒连续运行；液固总冲量、外部反力和压力功按离散核对。基本耦合随第一段主干交付，完整颗粒负载随第二段关闭。

## M06 联合占容与整数可表示性

**当前入口：** `GranularCouplingFields`、`GranularIntegerAllocation`、`GranularLiquidDisplacement` 及编辑、恢复计划。

精确库存与真实容量共同约束颗粒占容、液体位移和物种分配；预览、运动、初始化、增删和恢复共用规则或已提交结果。数值采样布局可调整，以直接、有界的分配替换绑定固定节点和高阶矩的整数搜索。实际容量不足与内部表示限制分别处理，后者通过简化或更换表示解决。

**验收：** 两格满液、3 SVQ、相邻 float 位置余数翻转、部分提取、全量移除、满液插沙和高密台阶正常交接并可恢复；合法物质转移能提交，真实无容量及无效输入保持原子性。

## M07 活动颗粒与床层转换

**当前入口：** `GranularSettlementGeometryPlan`、`GranularInventory`、`GranularDepositDynamics`、`GranularBedPotential`、`GranularBedShear`、`GranularTransitionStage`。

沉积、床体占容、剩余活动颗粒及起动共用联合容量规划。按来源和接收位置核对物质转移、重力势能、床体反力与局部耗散，允许在声明误差内简化亚格质量分布。

**验收：** 沙床初始化后的第二步、干式整桶沉积、湿沙沉降—起动—再沉积与恢复后继完成；有空间和能量来源时正常转换。复用床层、混材与 `GranularBedWakeValidation`，检查生命周期完成时间和完整步成本。

## M08 反应与固液转移

**当前入口：** `ChemicalReactionAllocation`、`ChemicalReactionStage`、`GranularReactionStage`、`GranularPhaseTransferEngine`、`PhaseChangeStageSupport` 及合并计划。

反应、析出、溶解和相变复用共同物质转移、容量与热学提交。精确化学批次、物种、质量、内能及接收动量按实际来源结算；位置变化涉及的势能、反力和做功明确归属，亚格表示转换采用相同近似规则。

**验收：** 共同速度、相反速度及旋转流中的反应/固液转移保持宏观动量与合理耗散，连续 phase-on、容量变化和气腔响应完成。条件满足时待处理任务继续执行，失败保留原状态；删去单格高阶运动信息逐项相等的旧要求。

## M09 编辑计划与代码职责

**当前入口：** `CarrierMutationCoordinator`、`FluidDomainInventoryTransactions`、注入/提取计划、`GasTopologyCoordinator`、`ThermalCellEnergyAssignment`、`ThermalCaloricInversion`、`ThermalDomainState`。

沿具体业务集中来源、未来状态、代次、占容和热账准备，在首次写入前准备完整候选。复用稳定模块，按数据归属集中规则，直接删除重复调用与过时认证，控制助手类和抽象层数量。

**验收：** 调用迁移、旧实现删除及路由更新随生产模块完成；成功一次提交、失败原子性和恢复保持。候选内存提交与持久 WAL 继续承担各自职责。

## M10 集成验收与恢复产品主线

在同一构建完成原 600 步切格、5,000 步溃坝、完整分层/线性对流、沙床生命周期、正常操作序列、连续相变、分数抽取盘上往返及既有操作顺序/固定种子组合。原输入、装量和运行步数继续覆盖，新精度模型按下表调整断言：

| 验收对象 | 采用的要求 |
|---|---|
| 库存、物种、真实容量、热学结算、一次提交和恢复 | 保留相应物理与事务契约，精确账本继续精确核对 |
| 静水、分层、液封、气腔压缩、惯性、旋转和冲击 | 采用可观测量与有量纲或归一化误差，例如液面偏差、分层位移、压力/温度响应、总冲量、旋转衰减；先确定适用范围和容差，再运行完整场景 |
| 原粒子数、矩阵秩、形状对象相等、亚格高阶矩、预期拒绝 | 随实现替换删除或改为正常流程与宏观物理断言；原失败输入继续用于成功后继验证 |
| 完整步性能 | 沿用既有小控制器 40 ms、最大装量连续三步 200 ms 的生产预算判定，捕获、重建、求解和提交全部计时 |

容差由采用的离散、解析尺度和玩法要求给出，保留仍适用的旧物理精度要求。调整容差须说明对应的模型取舍，避免为通过某个失败样本反复放宽标准。

`production-live-budget` 报告代表负载、完整步耗时和各主要阶段成本，记录必要的规模与子步数。核对双轨及旧路径删除、恢复完整、architecture 与 routing 准确，再恢复 D01。

## 验证与工作量控制

按完整职责链组织验证：开发中用相关短重放与必要编译定位问题，模块交付运行受影响的完整流程及预算，M10 汇总跨包验收。同一源码状态复用构建和已有有效结果，避免每次内部小改动重复全套测试。优先改写既有测试，新增常态测试对应新的失败模式。

离散改变时，相应调整残差定义、收敛尺度、迭代方式和子步策略，并核对连续场景误差及总成本。原 4096 子步和整数搜索结构随旧模型审查，禁止通过增加子步、搜索或迭代额度掩盖结构问题；40/200 ms 生产预算保持。

遇到表示冲突、双轨或规模失控时直接重新设计并替换。取消独立高阶空间研究和重复认证作为生产接入前置项；必要解析对照聚焦正在采用的离散。长期场景首次失败后复用短重放，修复完成再验证原流程。
