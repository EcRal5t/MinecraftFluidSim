# 当前实施计划：求解器整合

目标是可玩、符合直觉物理、具备工业仿真特色且架构精简的流体 Mod。本文保留当前交付状态与遗留事项。

本页只保留当前工作、未完成项和完成条件，随实际发现调整方向。已实现模型与代码入口见[设计书](../architecture/system-overview.md)，命令、预算和实测见[验证指南](../maintenance/validation.md)，长期功能安排见[产品路线](product-roadmap.md)。历史交付与淘汰方案留在 Git。

## GPU 接入交付

2026-10-27，性能优化停止。已有设备常驻液气机械候选、共同压力、统一容量、精确库存输运、有限气体搬运与做功、导热与设备结算沿生产后端运行。

本轮接通 ServiceLoader 后端注册、规定运动实体占容／排水／压力／反力与外功，三个相变草稿合入共同液体库存发布。补齐局部整数批次的凝固／熔化、汽化／凝结内核；相变后更新固体占容、气腔拆分合并、固定能量重映射和机械待处理状态。

生产机械／热连续步、固液反应、四种热相变、实体移动、常规查询、展示和 checkpoint 恢复短链已通过，实际证据见[验证指南](../maintenance/validation.md#gpu-生产接入的最新短链)。主模组默认启用 Vulkan 后端，Windows x64 安装主 JAR 与 Fabric API 即可运行，说明见 [README](../../README.md)。

64³ 完整步 20 Hz 与十倍提速尚未达成。已有性能记录覆盖液气机械与导热，完整职责的性能尚无合格结果。气液膜传质已接入正常机械／热流程，覆盖有限气腔溶解与析气、外界交换、精确源汇及存档续算。本轮交付为包含 GPU 内核和运行库的主模组 JAR。
