# 材料、混合物与化学规格

本文保存 M3、M7 及后续热力学需要的未来数据约束。里程碑顺序与完成条件以 [产品路线](product-roadmap.md) 为准；当前纯水真值仍以 [流体求解器契约](../architecture/fluid-solver.md) 为准。

这些是设计约束，不表示 codec、存档或协议已经冻结。

## 单位与守恒账本

- `BV`：block-volume，一个完整方块体积为 1 BV。
- `MU`：质量单位。
- `AU`：游戏化化学物质量单位，不宣称与现实 mol 等值。
- `PU`：压力单位。
- M9 再增加 `TU` 温度与 `EU` 内能。

配置可以调整时间和重力尺度，但同一存档的基本比例不能无迁移改变。每个 species 必须声明 `mass_per_amount`，否则化学计量和流体质量无法同时守恒。

组分库存决定质量；材料/物相模型从组成与状态给出参考密度或比体积；marker `particleVolume` 继续表示实际占据体积。混合、反应或相变产生的膨胀/收缩必须成为显式体积源并进入压力步，不能暗改平滑 density。

## 三层数据定义

1. **species**：ID、显示信息、组成向量、电荷、每 AU 质量和基础颜色。
2. **phase/material**：允许组分、液/气/颗粒类别、密度、黏度、互溶组，以及后续表面张力、接触角和相变参数。
3. **reaction**：反应物与生成物计量、允许相态、是否要求界面接触，以及后续温度、压力和催化条件。

真实元素与虚构科技材料使用同一种组成向量；虚构材料可声明 `metal`、`oxygen` 等抽象守恒基元。装载器必须拒绝未知 ID、负质量、组成/质量/电荷不守恒、互溶关系矛盾和无界解离循环。

定义层次可参考 [Cantera YAML 输入模型](https://www.cantera.org/stable/yaml/index.html) 对 phase、species、composition、charge 和 reaction 的分离，但本项目只实现游戏所需子集。

## 稀疏混合物表示

不能给每个 marker 分配 Java `Map`。优先采用局部混合包与 palette handle：

- marker 只保存 `mixtureHandle`、体积、速度和少量标志；
- handle 指向排序后的稀疏 `(speciesId, amountPerVolume)`；
- 相同组成可共享，发生局部反应时 copy-on-write；
- 同格混合或反应后合并近似相同记录；
- 休眠时按 section 聚合，唤醒时从精确库存重新播种；
- 定点分箱或规范化产生的舍入余量必须进入 residual ledger，不能静默删除少数组分或电荷；
- 每区域统计活动 handle、创建/合并率、overflow 和 residual，并设置软压缩阈值与硬上限；
- 达到硬上限时暂停或拒绝新的复杂混合，不能继续分配至 OOM，也不能丢弃库存。

冻结 GPU 布局前，要在强搅拌基准中比较 canonical handle、定点分箱加 residual，以及固定少量槽加 overflow。第一版化学可以只在 CPU 的脏活动格运行。

## 互溶、分层与有限溶解度

- 同一互溶组连续混合，密度、黏度和基础颜色按材料规则派生。
- 不同互溶组保持相标签、形成液液界面并按密度自然分层。
- 反应物只有在数值混合已将其放入同一局部混合包后才能同格反应，不能隔墙或隔界面触发。
- 第一版不可互溶相仍共享一个局部速度场，只承诺分层、翻转和静水压力；不声称解析界面滑移、剪切不稳定、液滴破碎或乳化。
- 有限溶解度必须使用饱和上限、溶剂/溶质规则和析出，不能随机拒绝混合。

若玩法需要界面切向滑移或乳化，应单独验证双速度/多速度模型。

## 离子、pH 与指示剂

M7 首版只实现强电解质完全解离与显式离子库存，例如 `HCl -> H+ + Cl-`、`NaOH -> Na+ + OH-`、`H+ + OH- -> H2O`。旁观离子参与质量与电荷守恒，但不增加独立压力求解。

pH 是由局部 `H+`、`OH-` 相对浓度派生的游戏化 0–14 刻度，不宣称现实精度。通用指示剂使用独立 parcel 标志：

- 添加时只 flood fill 当前可接受指示剂的互溶连通液相，不跨固体或不可互溶界面；
- 连通体积超过 100 BV 时整次拒绝，不做部分添加，并反馈已测得下限和 100 BV 上限；
- 标志随原 parcel 移动，不自动复制到后来混入的未标记 parcel；
- 抹除器清除目标连通范围标志；
- 客户端可按可见标记比例混色，但该比例不是化学库存。

## 最小验收

- M3 同密度两材料严格退化为当前纯水解，质量与体积账本独立闭合。
- `NaNO3 + KCl` 与 `NaCl + KNO3` 完全溶解后得到相同离子库存。
- `HCl + NaOH` 中和，过量物正确剩余。
- 每步质量、组成基元、电荷和液体体积闭合；颜色只由客户端派生。

## M9 热力学扩展

- 物理真值增加内能和材料热容量，温度只从状态派生。
- marker/网格承担热输运，固体边界提供换热条件。
- 熔化、凝固、沸腾与冷凝必须显式转移相态、质量、组分和体积。
- 反应热以及气体压缩/膨胀温变进入同一能量账本。
- 热静止判据与速度休眠分离，避免静止但仍在换热的区域被错误冻结。

封闭绝热系统必须闭合总能量；相变前后质量和组分守恒；客户端颜色或温度渲染不能反写物理状态。
