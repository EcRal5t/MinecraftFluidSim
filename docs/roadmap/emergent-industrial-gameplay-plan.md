# 自由构造工业玩法后续实施计划

后续开发围绕连续物料操作、可控几何、有限能源、气固作用、跨载体反应和材料表面过程扩展。玩家用普通墙、通道、隔板、运动件和填料组织工艺，数值结果由同一份几何、库存、物性和接受通量产生。设备外形与设备名称均由玩家决定。

当前模型和源码入口见[设计书](../architecture/system-overview.md)，施工进度统一维护于[当前实施计划](solver-consolidation-plan.md)，运行证据统一维护于[验证指南](../maintenance/validation.md)。本文维护后续工作包、依赖、取舍和完成条件。[基础能力补全计划](simulation-capability-completion-plan.md)中的既有交付作为起点。

## 实施顺序与收益

| 次序 | 工作包 | 优先解决的玩法 | 依赖和成本取舍 |
|---|---|---|---|
| F0 | 现有完整步性能 | 已有工艺持续运行、给新增能力留预算 | 当前数值开发前置；沿用原场景及实际物理时长 |
| F1 | 端口自动进出料和测量控制 | 连续换热、蒸发冷凝、结晶、吸收、液位控制 | 复用接口、发射器、转移事务、控制器；以宿主交互为主 |
| F2 | 可构造直线运动件和开口 | 隔断、调流、切换、活塞排水、往复混合 | F0、F1；扩展现有驱动和运动占容 |
| F3 | 有限能源与受载直线运动 | 有限热源、低速活塞泵／压缩、浮板 | F2；每件仅一个平移自由度，复用共同压力和外功 |
| F4 | 统一气固阻力与床层接触 | 气体填料床、颗粒输送、气固分离和流化 | F0、F1；沿现有颗粒、孔隙率及阻力算子扩展 |
| F5 | 跨载体反应与首批燃料数据 | 实际燃料加热、炉排燃烧、简化气化 | F3、F4；复用既有计量网络与热状态函数 |
| F6 | 表面库存与接触反应 | 吸附再生、固定催化床、颗粒表面转化 | F4、F5；仅在具有实际表面的载体上分配状态 |
| F7 | 受约束旋转与机械功交接 | 自制搅拌器、低速风机／叶轮泵、水轮／蒸气做功、发电接口 | F3；复用相同运动件与有限能源，将单自由度扩展到转轴 |
| F8 | 材料和组合工艺扩充 | 多组分分离、催化反应循环、简化裂解／焦化 | 前述能力按工艺选用；一套材料数据对应一条可运行流程 |

默认依表推进，F1 的交互和配置整理可以先于 F0 完成。F2 及后续数值扩展在受影响场景具备运行预算后交付。F7 的收益以旋转与功回收需求决定；F3 已提供往复泵送，F4—F6 可独立形成大量工艺。F8 按材料数据和玩法收益选择批次。

完整步性能仍是当前优先项。本文安排未来施工，当前暂停状态和具体下一轮由主实施计划维护。

## 共同状态与算法归属

### 状态与交接

物料继续由现有各相库存持有。新增吸附物、燃料残渣、催化活性及运动件能量均须有明确载体和保存字段。温度、压力、孔隙率、表面积、传感读数由同代状态派生。

机械、传热、反应与表面转移共同生成一个区域候选。物料只按接受的整数批次交接；外部物品、能源和构件装卸通过现有事务共同恢复。失败候选保留已提交代，外部效果在采用后发布。

### 共同执行

每步沿“真实几何与运动目标 → 接触和物性 → 压力、阻力与运动 → 接受通量及功 → 热化学和表面转移 → 提交”推进。新增局部过程以实际活跃载体组成批次；无相关载体的区域沿现有路径执行。载体表、空间邻接和接触列表由对应模块持有，各过程引用同一数据。

热能 `U`、机械动能和可用外部能源分别保存，源与载体之间按实际功／热量交接。电或外部动力适配器仅连接这个能量接口。设备驱动规律由构件形状、负载和能源决定，工艺名称仅作为玩家显示信息。

## F0 完整步性能

**交付目标：** 为正式支持规模和已有连续工艺建立可持续运行的预算，再叠加新数值职责。

沿[验证指南](../maintenance/validation.md#simulation-capabilities)的原输入定位完整步、显存和提交成本。现有稀疏域、热化学和库存机制直接作为基线；新增计划沿用当前单元分辨率。

1. 集中核算工作区和双代数据、几何更新、压力／导热迭代、反应接触扫描及主机等待，优先消除重复状态、重建和提交。
2. 先处理主导成本，再回到同一完整场景；每轮写清实际删除的复制、扫描或派发。
3. 按真实支持规模确定代表工艺的完整步与长步预算，包含冷启动、编辑与保存的各自成本。64³／50 ms 目标和原机械输入继续按既定条件分别评估。
4. 复用现有水流、液封、结晶、冷凝及颗粒输入判断功能和物理时长；新工作包使用相同的计时范围和生产暂停规则。

**完成条件：** 主实施计划明确可用规模、各代表场景预算和新增能力可用余量，验证指南登记对应证据。后续工作包若超出预算，先减少重复计算、活跃状态与自由度，再调整该能力的支持范围。

## F1 端口自动进出料和测量控制

**收益：** 先把已实现的换热、蒸发冷凝、结晶和碱吸收组织为可以持续投料、提取产物和自动停止的流程。

### 实现范围

- 扩展现有 `fluid_port` 和发射器操作，提供持久的进料／出料、目标材料、实际数量、周期和红石启停设置。凝聚相交接沿现有容器和公开转移规则执行。
- 将当前绑定在线玩家主手的周期投料收敛为真实外部库存 actor。玩家容器、发射器、命令和界面使用相同的操作描述与调度；每个操作按实际内侧接触格取料。
- 补齐有限气体容器与端口交接。气体载荷保存组分、质量和内能；标准体积用于容器数量表达，实际气体占容由区域状态方程派生。
- 为同一接口增加受控通大气设置。端口的实际开口映射到共同面上的环境压力／组成／温度条件，复用已有外侧惯量、气体通量和压力功收支；外壳登记识别这个声明的开口。环境通量沿真实接触面计算，密闭容器模式保持有限气体。该入口供冷却塔、空冷通道和通风使用。
- 同一区域内部的连续流体走真实通道；容器接口承担物品和外部库存的装卸。连接独立区域若成为实际需求，再沿双方共同事务增加有限转移。
- 扩展控制器／探针的局部温度、绝对压力、液位和流量读数。流量来自接受的面转移量除以实际仿真时长，显示支持质量流率和实际体积流率。
- 首批控制采用阈值与滞环，驱动进出料启停；配置保存在既有控制器或接口上。F2 后同一输出调节开度，连续调节按真实响应再增加简单 PI。

### 状态与生命周期

操作配置与运行库存分别保存。到期检查保持轻量，实际转移调用正式事务；物理休眠期间到期输入继续唤醒区域，主动暂停和区块不可用时等待。无库存、目标容器装满时等待，接口失效时展示原因。重启后按持久操作身份及 WAL 继续，离线时段保持现有在线时间语义。

**删除范围：** 当前独立的玩家主手周期投料调度，迁入共同端口操作；命令复用其入口。测量与自动控制共用一次已提交观察，整合重复查询和发送。

**完成条件：** 发射器真实进料、另一接口真实出料，红石启停、液位／温度阈值和容器补充形成闭环；产物保留组成和内能；暂停、休眠、卸载及提交中断后恢复保持一次交接。已有冷凝和碳化场景各贯通一条连续链。

通风补充场景采用两个实际环境端口和内部热壁，观察进出气体、携带内能及环境功；关闭端口后保留当前有限气体。自由排液到原版世界的归属交接单独按实际需求实施。

## F2 可构造直线运动件和开口

**收益：** 用同一运动占容机制提供阀板、挡板、活塞和往复搅动。

### 几何与玩家操作

扩展 `mechanical_driver`，玩家使用探针选定连接的普通完整方块，绑定一个轴和有限行程。首批构件为这些方块组成的形状，限定一个直线自由度。界面提供行程、速度、目标位置或往复周期；红石信号映射到目标位置。

组装沿已有世界归属协议把所选方块转为唯一的运动件实例，保存原方块状态、材料、质量和局部形状。源位置的固定碰撞随采用一起移除；展示和碰撞读取实例的当前姿态。拆卸在可容纳的网格位置恢复原方块及热载荷，空间受阻时保留完整构件并显示原因。普通墙的热库存随相同材料构件移交，源墙和运动件共用一份 U。

首批运动件位于同一区域固定外壳以内，行程包络和内部相邻舱保持同一空间归属。阀板闭合可拆分物理活动组，重新开启后恢复连通；运动和接触涉及的组共同唤醒。可变外壳和跨区域构件待独立世界归属交付。

### 算法与调用

- 源／目标姿态、扫掠占容、真实开口和表面速度共同送入现有实体耦合；多块构件按统一身份合并实际占据。
- 扩展当前 AABB 请求到简单组合形状，压力与剪切沿真实表面结算逐构件冲量和外功。
- 碰撞缩容沿既有液气排水及受阻规则执行。关闭阀板允许流体流走或压缩，无法完成的行程停在有效位置。
- 阀板通过真实覆盖面积改变通道，端口观察读取同一面流量；保留当前网格和微盒解析精度。
- 当前规定往复运动作为相同构件请求的预设输入。F3 再加入有限质量和有限能源响应。

**删除范围：** 单格隐式驱动体的专用姿态／定位规则归并到运动件请求，玩家原有驱动入口迁移。阀门与活塞共用运动几何和占容。

**完成条件：** 玩家搭建的板件能连续调节通道，完全关闭后隔离；开启后恢复流动，阀板挤出的库存和功有明确去向。自制活塞腔可压缩有限气体，停止、卸载、拆装和恢复保留位置、物料与热量。渲染、玩家碰撞与设备占容使用同一形状。

## F3 有限能源与受载直线运动

**收益：** 将可控构件推进到负载响应，完成有限热源、往复泵、气体压缩和浮板。

### 受约束运动

每个构件保存轴、位移、质量和轴向动量，几何从 F2 复用。仅在该轴上接受流体冲量、重力、驱动力和端部接触反力；机械动能为 `p²/(2m)`。支座承担其余方向的约束反力。

流体压力与构件有限惯性参加同一机械候选，复用颗粒和规定物体已有的压力作用／反作用及耗散结算。设计时写出轴向速度响应和扫掠体积的共同离散，避免在候选采用后再追加一个未反馈孔容的位移。浮板沿竖直轴自由响应，活塞接受实际驱动力；两者使用同一方程。

压力算子中的构件体积散度与其转置压力冲量共用同一系数，新增惯性仅为每件一个标量自由度。端部限位采用同一单轴约束，接触后的实际位置决定最终孔容；流体与构件的采用保持同一时段。

### 有限能源

- 扩展现有热源、驱动器的能源输入，首批采用真实物品载荷的有限 J 库存，沿已有容器／设备装卸事务补充与取出。能源储存先集中在现有对象内。
- 热源向自身有限热载体输入功率，温度由 U 变化得到，再通过现有墙面接触传热。热接触、沸腾和冷凝沿已有算法推进。
- 驱动器配置目标位置／速度、最大力和最大功率，驱动力按可用能源限制；实际行程决定所做功。相反方向的外力可使构件减速，驱动损耗进入对应热载体。
- 先定义保守的单向供能、制动发热流程。F7 的双向功口再处理能量回收。
- 既有恒温源和规定无限驱动保留明确的创造源语义；普通玩法使用有限能源入口，展示实际能源与功率。

有限源的实际供功同时满足 `W ≤ E可用` 和 `W ≤ P上限 × Δt`。该约束进入同一机械候选的驱动冲量／位移闭合；先由实际力和位移计算功，再确定能源后继。实现以单轴受压活塞解决启动、零速和停转工况，局部细分保持请求总时长。F3 交付前同时完成能源不足时的受限运动，完整步成本含其耦合轮数。

**删除范围：** 有限模式下按固定温度重置热载体、先规定运动再无约束补功等专用处理，由有限能源与受载运动覆盖。

**完成条件：** 两个可控阀板与自制活塞腔完成周期抽入／排出；增加背压使流量降低或停转，能源耗尽后保留压力与位置。浮板随液位移动并保持自身质量；加热器停电后继续按有限 U 冷却。区域、构件、能源、世界和物品在恢复后联合闭合。

## F4 统一气固阻力与床层接触

**收益：** 一次扩展支撑通气填料床、颗粒夹带、沉降／旋流分离和流化床。

### 共同物性与响应

现有颗粒／床层阻力主要读取液体物性。扩展为接触相加权的流体作用：读取实际湿干占据、液相或气相密度、黏度、滑移及粒径；在液体、气体和部分浸润情况下连续归集到同一颗粒阻力算子。两侧作用和反作用参加当前有限质量速度响应，固定床将反力交给支撑。

稀颗粒与密床分别承担单粒阻力和多孔介质物理，统一在同一构成关系中按孔隙率与局部状态过渡。具体关系按所选颗粒和流速范围确定，密床沿现有 Darcy／床层数据扩展，保持当前颗粒身份、压力支撑和固体占容。气体黏度与混合规则进入现有材料求值。

### 接触与筛分

大颗粒由可解析格栅与几何接触截留。细粒捕集作为按收益增加的材料表面属性，接受粒子／沉积库存，阻塞后通过真实孔隙率改变流量。筛面与催化／吸附表面共享几何来源，固体量继续保存于现有颗粒／沉积库存。

**删除范围：** 纯气格跳过颗粒阻力的路径及重复液相物性缓存，替换为共享流体接触求值；床面起动和沉积复用同一受力来源。

**完成条件：** 气速提升使颗粒从静床进入悬浮／夹带，减小气流后沉降；气体通过固定床产生压降；旋流室内较大颗粒与随流细粒有可观察的分离趋势。以颗粒相对气流的运动和实际出入口收支评价，记录可解析粒径及粗尺度近似。常规液固沉降和孔隙液流继续沿同一算子运行。

## F5 跨载体反应与首批燃料数据

**收益：** 自由构造燃烧室、炉排和换热管，由实际燃料反应供热；后续接入气化和表面催化。

### 反应载体扩展

将当前单化学物相的局部计量网络扩展到气体、液体和实际接触的固体。反应定义引用参与载体、计量和速率所需的浓度／可达表面积，提案进入现有多反应物竞争与整数批次接受。各过程共同受实际物料、内能和空间约束限制。

气相反应读取同格气体组分；异相反应读取共享接触列表，固体只在真实可达表面消耗。气体产物、残余固体和灰分写入现有库存，固体减少导致的孔容变化及气体摩尔数变化沿共同状态方程和机械同步交接。扩展原 `ChemicalReaction` 的载体表达，相内反应保留所声明的零体积近似，跨载体转换按实际接受质量和相密度求占容，汇总为唯一的物相体积交接。

反应保留总 U，实际组成的参考能决定升温。燃烧速率采用明确温区的简化有限动力学；火焰前沿和高温流动以游戏尺度近似表达。热量通过现有气体输运与导热到达物料管。

### 首批数据与工艺

先交付一组数据完整的燃料体系，默认选择碳、O₂、CO₂、CO、H₂ 和 H₂O 的一致热化学数据，先做碳氧化，再做受限供氧及蒸汽参与的简化气化。气化的压力与温度范围随定义给出。物种及参考能一次登记，燃烧、气化和逆向过程共享相同参考态；将现有水、蒸气和 CO₂ 的相对参考能换算到同一基准后再组合网络，同步核对已有汽化、溶解和碱吸收的热效应。

**删除范围：** 本轮涉及的固体燃料到气体产物专用收支由共同计量提交承担；合并重复的相转换及热账写入。已有水合、中和和固液析出继续使用相同量值与候选协议。

**完成条件：** 炉排上的有限碳燃料经氧气流消耗，产物气体通过管外加热水，灰分／残余物可取出；断氧使反应受限。简化气化在对应数据和热量输入下产生可取样气体。元素、质量、参考能和显热按实际批次闭合；重启保持残余燃料及气体组成。

## F6 表面库存与接触反应

**收益：** 用可装填材料完成吸附再生、固定催化床和颗粒循环，扩展相同容器的用途。

### 表面状态

复用颗粒、沉积和固定材料的身份与实际表面积，仅为声明表面能力的载体保存吸附物种量、位点容量和必要活性状态。物理粒径及实体积决定面积，代表粒子数仅影响采样。载体搬运、合并、沉积和拆装同步搬运表面库存及 U。

首批吸附采用一种适用范围明确的竞争等温关系与有限接近速率。按实际分压／浓度、温度和空闲容量提出交换量；接受量受到可用气体／溶质和位点共同限制。吸附组分保存于固体表面，吸附热进入同一载体 U。升温或降压改变净转移方向，回到原有物料库存。

首批采用吸附组分额外占容忽略的表面近似，位点容量有限。接受的吸附物实际质量进入对应固体载体的总质量、惯性和热状态，流体扣除相同质量并重算状态；表面列保存的组成与载体总质量一致。吸附物的参考能已含吸附热偏移，接受后由同一 U 反求温度。

催化能力作为 F5 反应的接触条件和速率因子，引用可达面积与活性。失活状态只在首批反应需要时增加，结焦则生成真实固体组分；再生按同一反应和氧气库存消耗焦炭。材料自身的质量、表面组分与热量各有唯一保存位置。

**删除范围：** 合并颗粒溶解、表面转移和催化过程重复建立的接触／面积数据；同一物种的一次吸附或反应仅使用一份接受批次。

**完成条件：** 填料床对首批指定组分出现穿透，饱和后吸附减弱，降压／加热释放可收集物料；至少一条有数据依据的催化反应随填料面积变化，停留时间由真实流场决定。取出、换床、颗粒迁移及保存恢复保留吸附量和热量。吸附剂、催化剂用物料装填现有容器。

## F7 受约束旋转与机械功交接

**收益：** 将 F2/F3 的构件扩展到自制叶轮、搅拌器和转子，支持流体做功与机械负载。

### 运动与几何

同一构件支持绕固定轴的单自由度，保存转角、转动惯量和角动量。玩家仍选择普通方块组成叶片，锚定规则、组装／拆卸及热库存复用 F2。有限范围的固定轴转动与直线运动共用运动描述和候选接口。

当前 `MovingBodyFluidCoupling` 只有 AABB、平移速度和合力冲量。旋转交付须扩展局部表面速度 `u = v + ω × r`、实际旋转占据以及逐接触力矩 `r × J`。粗碰撞可以继续采样，但把旋转物体整体替换为外包 AABB 会改变叶片通路；实现使用运动后的可解析形状并记录扫掠误差。

### 功与传动

转子压力及剪切作用更新角动量，机械动能由实际惯量和转速得到。电机模式从 F3 能源取功，发电／制动模式施加负载并接收对应能量，损耗写入热载体。直接连接优先复用支座／驱动器的功口，实际需要远程轴时再引入一种轴连接件。传动比作为同一功口的速度约束，力矩与功同步变换。

转子、流体和负载在同一机械候选采用；外部能源输出沿现有事务提交。以水流或低速蒸气推动转子作为首批功回收场景，工业高速汽轮机效率另按数据和模型范围评估。

**删除范围：** 固定转速后追加无限功的旋转专用处理，以及按“泵／风机／涡轮”标签改变流体的路径，由真实运动面与功口承担。

**完成条件：** 同一组叶片可由电机驱动搅动／送流，也可在反向能流下被流体推动输出功；改变负载影响转速和流量，几何改变影响结果。停止、卡住、反转、断能源和恢复均保存运动件及流体状态。直线活塞、浮板及既有实体交互共用整理后的动量与功职责。

## F8 材料和组合工艺扩充

按下表逐条交付完整工艺，每次增加实际需要的物性、反应、观察和容器载荷。数据包及世界能力包沿现有定义体系登记。

| 收益顺序 | 工艺批次 | 复用能力和新增重点 |
|---|---|---|
| 1 | 单级蒸发、多级冷凝与回流 | 沿现有水—乙醇体系，玩家构造气道、塔板、降液通道；先交付实际富集与回流效果 |
| 2 | 气液吸收和再生 | 沿 CO₂ 水合／碱吸收及真实热壁，提高接触面积与停留时间；反应物和再生范围由数据决定 |
| 3 | 吸附循环与可换填料 | 使用 F6，切换 F2 阀板与 F1 取料，完成有限物料回收 |
| 4 | 炉加热、简单气化和颗粒分离 | 复用 F4/F5，气体与固体沿实际空间循环，取样核对产物 |
| 5 | 新挥发体系与非理想平衡 | 以实际共沸、压力依赖或目标分离收益选择数据；统一平衡求值替换当前理想求值，保留共同传质 |
| 6 | 简化催化裂解、结焦和再生 | 在 F5/F6 上补首批代理组分、反应及催化数据，完整保存焦炭与活性 |

先交付适合有限组分的简化过程，再按玩家需求增加原油代理组分。首批裂解、焦化工艺使用一套声明范围的简化网络。塔板效率、分离效率和产物分配由实际接触、反应与流场产生。

|---|---|---|

| 加热／制冷 | 普通导热墙、现有有限热载体与能源输入 | 独立制冷循环按后续实际需求安排 |

| 筛网和填料 | 普通几何、已有颗粒床及材料属性 | 细粒捕集有明确收益时增加可安装筛面物品 |

## 完整交付和验收安排

每个工作包包含模型／GPU、定义加载、正常玩家操作、观察、存档恢复及旧路径删除。新增状态同步进入候选、checkpoint、物品载荷和相应世界事务。命令与无头场景复用正式操作入口。

| 工作包 | 最小完整场景 | 必须回答的问题 |
|---|---|---|
| F1 | 发射器投料、冷凝或结晶、独立产物取出 | 接受量、组成、热量、控制启停和事务恢复 |
| F2 | 自制阀板与活塞腔 | 真实开口、排水、压缩、受阻行程、几何与展示一致 |
| F3 | 受背压活塞泵、浮板和有限热壁 | 有限能源、负载响应、位移与压力共同作用、恢复 |
| F4 | 固定床吹气、气流携粒及旋流集尘 | 气固反作用、床阻、粒径趋势与实际分离收支 |
| F5 | 有限燃料和空气加热水管 | 元素、物相、反应参考能、实际热输运及停氧响应 |
| F6 | 吸附穿透、降压再生、填料取出恢复 | 位点占用、竞争、吸附热及库存唯一归属 |
| F7 | 同一转子的驱动和功回收 | 力矩、角动量、动能、实际功和负载耦合 |
| F8 | 一条所选材料的连续完整工艺 | 可取样产物、材料范围及实际性能收益 |

复用已有区域、容器、热相变、反应、颗粒和稀疏域验证。仅对新增失败模式补充用例，检查选择和命令继续由[验证指南](../maintenance/validation.md)维护。视觉、复杂旋转碰撞和跨游戏重启按需要给出单一人工场景。

性能始终使用相同输入和仿真时长的完整步，物料转移、持久化、渲染分别给出实际成本。局部反应、表面过程和测量按活跃载体组织，新增简单材料不应自动增加一次全域求解。有限质量运动可能增加压力未知量，气固阻力可能加重速度响应，须在对应工作包先核算这些完整成本。
