# 空间选区与环境热场重设计

本文给出空间选区、原版材料和附近环境温度的实施方案。实施状态归[当前计划](solver-consolidation-plan.md)，成本实测归[验证指南](../maintenance/validation.md#environment-thermal-cost)。本文描述目标设计；当前运行代码仍采用控制器与区域有限墙库存。

## 玩家操作与计算空间

玩家用物质场探针指定两个角点，预览覆盖范围、所需区块、驻留预算和已有区域占地，再确认创建。选区包含其中的空气、容器、机器与实心方块；碰撞采样决定流体实际可用空间。区域使用 UUID 和显示名称标识，探针对选区内位置即可查询、暂停、继续和移除。

区域创建与物理容器相互独立。铁块、玻璃、石头、木材和绝热材料按实际形状阻挡流体、按实际接触传热。拆掉容器墙后，流体沿新开口进入计算空间中的其他位置。控制器洪泛找腔、专用外壳判定和墙体破损暂停由这套空间操作整体替换。液位与温度红石输出统一由现有传感器承担；演示、手册和管理命令使用相同的选区服务。

### 物质抵达选区边缘

当前开放计算域允许气体与外界交换，液体外排通量被阻断，颗粒将域外视作固体。新交互同时替换这项空间限制：初始选区确定机械计算的起始范围，液体和颗粒接近外缘时，按现有 8³ 单元计算块扩展所需方向。扩展在物质跨出旧网格之前提交，包含实际世界碰撞和新空气库存。

扩展受现有驻留预算、世界区块加载和机械区域互斥约束。到达预算、缺失区块或接触另一独立机械域时，暂停受影响区域并标明所需空间，保留物质、动量和内能。界面提供扩大预算范围或调整选区的操作。独立机械域的自动合并作为后续产品能力；共享热场已经支持它们相互传热。

扩展搬迁液体、逐格气体、颗粒与床层、MAC 面动量、固定碰撞、实体输入、热接触及待处理相变。既有空间块地址负责稳定寻址，新增共享面只生成一份。创建时选到原版水体继续执行现有世界归属事务；重叠的物料库存按同一规则处理。

## 世界热库存

每个维度维护一份按世界方块坐标寻址的热场。每个受管理的固体方块保存材料和总内能；求解域外空气保存标准组成的有限库存及其内能。温度和热容由物性与内能派生。所有区域引用同一坐标的同一份状态，因此邻近水箱可以通过共墙、地板和周围空气交换热量。

机械域内的空气仍由现有逐格气体库存持有。固定世界方块无论位于选区内还是紧贴选区外，都由世界热场持有。表面吸附物、催化装填和墙体共享内能，沿现有 `SurfaceThermalState` 状态函数迁移；有限换热器物品继续保存自身材料与内能，并通过同一热接触接口工作。

半砖、楼梯等部分实体允许同一方块同时持有固体和剩余空气；质量、热容与接触面积按实际占据体积计算。同格不连通的空气部分沿现有微盒连通关系分别登记，保持薄隔墙的隔热作用。机械域接管时交接空气份额，固体热库存继续保持唯一归属。预算按实际热载体及接触数计费。

空气物性沿用世界气体定义，以现有内能状态函数计算质量、参考能和热容。环境阶段保持其有限标准组成库存，采用热混合近似；压力与速度求解继续集中于机械域。这样首次创建和扩展可以直接按实际开放体积把环境空气分配给新气格，保持原有质量、组成与内能。方块对齐的区域和计算块简化这项交接；同一空气份额始终只有一个持有者。

### 有界的环境范围

起始温度场覆盖选区中的固定方块及选区外四个方块厚的附近空间，按世界坐标合并重叠范围。环境网格采用 1 m 格长和紧凑数组，拓扑只随范围与世界方块变化更新。采用固定分辨率可以保留一方块厚的绝热层，避免粗格混合材料造成穿墙传热。

机械域增长时，扩展事务先纳入新范围及其四格外层的环境库存，再交接新气格、重建接触并移动远场面。首次纳入的材料按定义初始化并记录来源；原热库存继续保存，释放时按完整能量交接。范围准备和气体接管共同提交，失败保持原区域和原环境代。

环境范围最外侧通过材料热阻连接远场基准温度，交换的实际热量计入远场收支。初始远场采用 293.15 K；局部空气和墙温持续由自身内能决定。该有限范围表达机器附近的热积累与扩散；封闭房间的整体保温效果要求房间和外墙落在所管理的温度场内。后续可独立增加环境范围，成本继续按实际格数计费。气候、昼夜和天气以后可提供远场温度输入。

区块卸载保存原内能并停止相应格及跨卸载面交换，重载恢复原状态。温度场移除先持久化库存，或在明确释放操作中结算全部源汇。自动把热格重置为室温会丢失能量，因此热场生命周期与保存交接一起实现。

## 热量如何传播

固体格保存 `C = m c`，由 `U` 反演 `T`。相邻固体以串联热阻计算热导：

```text
G_ij = A / (d_i / k_i + d_j / k_j)
```

`d_i`、`d_j` 为两侧格中心到接触面的距离；绝热材料的接触热导为零。铁、铜、金、石材、木材和玻璃各有材料类别，染色玻璃复用玻璃物性；未专门配置的完整固体使用默认材料。导热率、密度、比热和材质映射统一由 JSON 与方块标签定义。绝热方块和绝热玻璃具有正常碰撞形状及明确零热导，同时交付物品、合成、掉落和渲染。

固体与环境空气采用串联的固体内部热阻和表面对流热阻：

```text
G_wall,air = A / (d_wall / k_wall + 1 / h_air)
```

空气格之间采用有限的有效热混合率，将未解析空气运动折算为相邻格热交换。分子导热率和有效混合率分开命名；混合接触遵守实际开口，完整墙和绝热层隔断交换。环境阶段提供温差逐渐扩散、空气升温和冷却的玩法响应，热羽流、风向输运和房间分层属于该近似的可观测误差。

固体、空气、流体接触沿用现有有限热容交换关系：

```text
lambda_i = sum_j(G_ij) / C_i
q_ij = dt G_ij (T_j - T_i) / [1 + dt (lambda_i + lambda_j)]
U_i(new) = U_i(old) + sum_j(q_ij)
q_ji = -q_ij
```

每条接触生成一份热量，向两侧写入反号值。常物性节点预存热容和静态连接率；可变表面库存按同代状态重算。采用分段物性时继续使用现有最小正热容稳定条件。强接触与较长步长会减慢均温，验证按冷却曲线与时间尺度评价。

## 执行与成本

推荐在现有 Vulkan 设备中常驻共享环境热场，CPU 负责区块加载、方块事件和拓扑准备。`VulkanFluidSolverBackend` 已为多个区域共享一个设备上下文，可沿现有串行区域调度发布环境更新。

环境内部扩散以 2 Hz 为初始推进频率；区域与世界方块的稀疏接触随其已接受物理步推进，保留快速换热、墙面冷凝和表面反应的响应。拓扑静态时，环境扩散只需准备节点温度、计算每条面热量、按预存邻接归并节点三个线性阶段。每个面量只计算一次，归并读取面量数组，避免全域求解和原子累加。无热接触的区域无需生成环境候选。

CPU 数组成本探针已建立，具体结果见验证指南。它用来评估环境热网格的算术和内存成本。GPU 常驻方案的选择依据是完整数据流：流体、气体、相变和表面库存都已驻留设备，接触换热可以直接读取同代数据；日常 CPU 温度回读和流体状态回传从执行链中消除。GPU 调度、候选复制、热账和绘制竞争的成本留给首个集成切片测量。

环境自身扩散按加载期间的世界在线时间推进；区域接触按实际接受的区域仿真时长推进。性能降速会同步放慢该区域向环境的热交换。暂停和卸载期间停止区域接触计时，恢复后从当前两侧状态继续，采用明确的多时间尺度近似。

世界采样只处理新增与变更位置；创建和扩展采样分批执行。环境温度显色与探针查询按显示需要取样。初期运行完整的小型环境图，休眠与局部活跃格优化以实际成本为依据。

## 开放气流与温度场

开放气流同时携带物质和内能。固定环境空气与通过的气包之间交换有限显热，气包的实际组分继续沿现有外部源汇交接：

| 操作 | 区域变化 | 环境空气变化 | 外部收支 |
|---|---|---|---|
| 入流，气包初始内能为 U0，空气向气包给热 q | 接收气包及 U0 + q | −q | 来源记 U0 |
| 出流，离开区域内能为 Uout，气包向空气给热 q | 移出气包及 Uout | +q | 去向记 Uout − q |

气包与同格空气接触共同采用有限热容交换，多个气包共享空气可用热容，保证每批能量同时结算。气体参考能与实际物种继续沿气包保存；压力功沿既有机械账处理。环境场表达有限标准空气的温度，排放气体的污染物积累、组分扩散和外部气体力学作为后续独立能力。

首次创建、扩展和移除机械区域属于库存交接。环境空气转入气格时移除相同的环境份额，跳过该空间的默认新气初始化。退回环境时，标准组成空气可以原样承接；其他组成沿明确的排气操作完整交出，再由外界补入标准空气，两笔物料与能量分别记账。

## 候选、世界动作和保存

一次区域接触读取区域代和环境代，生成私有后继；主线程核对双方代次后共同采用。失败共同释放，已提交库存保持原样。其他区域在之后的事件读取新环境代，各自独立推进。环境内部扩散同样发布自己的后继代。设备状态采用现有双代库存与命令提交，不增加日常磁盘事务。

世界保存使用一份发布记录引用同一保存时点的环境 checkpoint 和各区域 checkpoint。先写完整不可变数据，再原子发布记录；恢复使用记录引用的整组代次。容器、方块变更和原版水体接管继续使用现有 WAL，并将涉及的环境库存加入同一交接。方块移动搬迁其热库存，拆除按实际内能交给明确的物品载荷或外部汇，新放置材料按定义初始化并记来源。

## 实现顺序与删除范围

以下工作共同构成完整交付。内部先完成最小的真实接触切片，测量完整步新增成本，再批量迁移其余入口。

| 工作包 | 主要入口及修改 | 同轮删除或迁移 |
|---|---|---|
| 空间操作 | `FieldProbeItem`、区域创建服务、`FluidRegionFactory`、`FluidRegionFootprint`、碰撞与可用性 | `FluidBoundaryScanner`、控制器洪泛创建、外壳破损暂停；控制器摘要与比较器迁到探针/传感器 |
| 空间增长 | `SpatialGrid`、`FluidRegion`、状态编解码及后端重建 | 固定控制器 footprint、液体/颗粒触及旧盒面后的隐形留存行为 |
| 世界热库存 | 世界坐标索引、环境材料、空气交接、`MinecraftWorldUpdates` | `OrdinaryThermalWalls` 按区域重复持有墙库存、`FluidRegionManager.sharedWall` 准入冲突 |
| 设备耦合 | `VulkanRegionThermal`、`VulkanThermalContacts`、气体外排与入流、有限墙与表面状态 | 每次普通墙刷新导致的全区域宿主导入；重复墙材料和接触规则 |
| 提交与保存 | `RegionApplicationService`、候选接口、checkpoint 捕获与恢复、世界发布记录 | 单独恢复区域却遗漏共享环境代的路径 |
| 玩家与演示 | 探针范围预览、绝热方块/玻璃、端口、传感器、`IndustrialWorkbench`、演示和手册 | 对控制器位置和专用围墙身份的操作依赖 |

端口仍可用于自动化进出料，目标由实际位置、朝向和相邻流体格决定。材料定义、完整物质库存、状态函数、实际湿面、有限热量公式和事务交接继续复用。GPU 执行原则备忘录保持原文。

## 交付判定

首先测量同一生产场景启用环境热场前后的完整步成本，包括新增节点/面、采样、命令提交、等待、复制、回读和存档成本。目标是主仿真每步新增耗时平均不超过 0.5 ms、p95 不超过 1 ms；低频扩散事件的完整新增成本 p95 不超过 1 ms。原 64³／0.5 m 完整生产步的 50 ms 目标保持。以上是集成目标，成本探针的实测范围见验证指南。

功能验证聚焦三个短流程：探针选区内热水经铁壁加热有限空气、绝热玻璃保持隔热并可观察内部、两个独立区域通过同一世界墙库存交换热量。沿这些流程检查一次方块拆改、一次范围增长和一次共同 checkpoint 恢复。热账包含区域、环境、气流及远场交换；旧逆流换热和既有库存测试按实际受影响范围复用。测试前先固定要判断的故障，编译与产物只构建一次。

## 建模依据

- [EnergyPlus 空气区域定义](https://energyplus.readthedocs.io/en/latest/guides/input-output-reference/1.10-group-thermal-zone-descriptiongeometry.html)使用集总空气热平衡表达平均温度，说明有限空气热容可独立于完整流场处理。本方案把这种简化限制在局部网格，并保留空间温差。
- [EnergyPlus 表面热平衡](https://energyplus.readthedocs.io/en/v26.2.0/guides/engineering-reference/3.6-inside-heat-balance.html)将固体内部导热和表面到空气的对流分项处理。本方案采用相同的职责分离，具体换热参数按玩法尺度设置。
- [MOOSE FVDiffusion](https://mooseframework.inl.gov/source/fvkernels/FVDiffusion.html)说明不连续材料导热系数采用调和插值可保持正交网格法向热通量连续；本方案按两侧串联热阻实现同一离散关系。

具体空间范围、执行频率、有限交换公式和多时间尺度处理属于本项目的工程选择，接受方块尺度近似并显式保留热量收支。
