# 生存模式入门

先取得铁锭、玻璃、红石、青金石、纸和皮革。用原版工作台制作桶、书、指南针、比较器和玻璃板；拿到相关材料后，模组配方会出现在配方书中。比较器需要下界石英，活塞还需要木板、圆石和红石。

1. 用书和玻璃板制作快速入门手册；用指南针、玻璃板、铁锭和红石制作物质场探针。手册可在手中使用，探针用于查看和配置区域设备。
2. 用铁块、玻璃、石头等方块建造容器，保持附近区块加载。手持探针潜行点击两个角点，检查选区与预算预览，再次潜行点击确认创建区域。选区包含容器壁和内部空间；原版方块按实际碰撞阻挡流体。用铁块、铁锭和青金石制作容器接口，安装在容器壁上，蓝框朝外。
3. 用桶和青金石制作混合液桶，用桶和燧石制作颗粒容器；气体容器由铁锭制成。手持水桶对准接口外侧投水，手持空混合液桶潜行点击接口取得局部样品。手持样品潜行对空气右击，可查看组成与温度，并保存基准进行对比。颗粒容器可收取区域中已有的颗粒，包括工艺析晶产生的颗粒；气体容器从接口装取气体。
4. 用木桶和铁锭制作物料箱，紧贴接口外侧放置。空手点击取回当前槽的容器，潜行空手点击选择下一槽；手持一个容器点击可放入或交换。物料箱的九个槽保存实际容器，出料前先放入对应物相的空容器。手持探针点击箱体选择槽位，点击接口设置物相、进出料速率和红石控制。
5. 用比较器、红石和铁锭制作工艺传感器，用铁锭和铁栏杆制作筛，用活塞、红石和铁锭制作阀门或机械驱动器。探针打开传感器和筛的配置；空手潜行点击传感器查看工艺曲线。阀门空手点击可切换开度，机械驱动器可让方块往复运动。

容器接口和工业方块使用石镐或更高级镐开采。拆除物料箱时，箱内实际容器会随箱体掉落；涉及区域运行的方块遵循区域保护和物料交接规则。

物料箱也支持使用 Fabric 标准物品接口的自动化设备，从任意面存取整只容器。每槽容纳一只，液体、气体、颗粒及样品数据跟随容器；交接恢复中的槽暂时等待。设备可以将空容器送入出料箱，再将装料后的容器搬走。Create 的版本与接入范围见 [Create 适配计划](../roadmap/create-compatibility-plan.md)。

羊毛与黏液球可合成绝热方块，绝热方块与玻璃可合成绝热玻璃；两者用于隔热。

部分水桶由实际转移产生，两个没有热状态的部分水桶可在工作台合并。创造物质源用于创造模式，吸附剂和催化剂沿其已有配方获取。操作细节见[命令与工艺操作](../maintenance/commands.md#工艺操作)。
